## 查看原型

- 打开 [index.html](index.html) 可本地查看，不需要安装依赖或连接业务后端。
- 当前 v0.6 为消费者端 26 屏、服务人员端 15 屏，共 41 屏，消费者 7 条核心流程；数量与浏览器总览已核验。这是原型屏幕数，不是业务入口数量。
- 三个视图：单页走查、核心流程、页面总览。
- 右侧说明区记录页面目标和待确认规则，可切换消费者“首次使用”“已登记产品”“服务进行中”场景，以及加载失败等通用状态。
- 表单支持演示必填校验、会话内输入保留、登记结果回显和审核退回后的重提反馈。
- 页面使用虚构数据。非主流程入口仅提供说明性反馈；扫码、拨号、定位、文件和业务提交均未接真实能力。
- 刷新页面会清除演示会话。不要填写真实客户资料。

当前消费者产品服务流程建议从首页依次试用：切换两件产品 → 选择维修或使用指导 → 填写问题 → 联系与期望时间 → 核对提交 → 查看同一申请的进度。安装入口支持选择一件或多件产品；消费者安装开放条件仍待业务确认。右侧切换场景会清除消费者的演示数据，普通返回和产品切换会保留各自草稿。

## 登记新流程怎么体验

从首页“登记其他产品”或[登记入口](index.html#c-register)进入。手动选择商品与产品标签码辅助选择统一使用编号卡片，卡片尺寸、配色、字体和箭头样式一致：

1. **手动选择商品**：分类 → 系列 → 商品 → 购买日期 → 个人信息 → 登记结果。右侧先切“首次使用”更容易观察产品从 0 件变为 1 件。
2. **产品标签码辅助识别**：输入 `DEMO-PRODUCT-003`，先核对识别到的商品，再补充购买日期及个人信息。识别结果只帮助选商品，不代表验证了某件实物或本人归属；相同商品码可以用于登记另一件同款产品。
3. **了解安装码**：打开[安装码使用说明](index.html#c-installation-code)，查看其在已有购买记录中的用途；[联系门店或客服](index.html#c-code-help)提供核实购买记录的指引。两页均不提供安装码输入登记或手机号找回表单。
4. **查看已有产品的安装码**：在“已登记产品”场景进入原本已关联安装码的产品资料，仅展示其既有码，供联系门店／客服查记录；新登记结果不生成、借用或自动关联安装码。

标签码识别页保留识别失败和码类型不符的演示。旧安装码页面链接仍可打开使用说明，旧登记方式或提交路径不能恢复认领成功链。v0.3 的安装码登记与双码同实物假定已由 v0.4 取代；当前路径与边界见[设计说明第 12 节](01-两端小程序设计说明.md#12-消费者-v04--按当前码关系调整登记原型)。

## 查找服务网点怎么体验

v0.6 从“服务 → 查找服务网点”或[网点查询入口](index.html#c-outlets)进入，以地图为主界面，保留查询、地区选择、详情 3 屏；电话与导航改为浮层。当前范围与验证见[设计说明第 14 节](01-两端小程序设计说明.md#14-消费者-v06--地图主界面与原生能力模拟)。

1. 顶部单行选择地区、输入关键词，再切换“授权门店／维修网点”；默认上海市为手选示例，不表示已定位。
2. 点击示意地图点位，底部摘要同步名称、地址及电话／导航动作；距离只在模拟定位成功后显示。展开列表与收起均在本页，选中一行回到地图查看该网点。
3. 进入详情查看营业时间、服务范围与到访信息，再返回保留查询上下文；点击定位可在评审面板选择成功、拒绝或失败，拒绝或失败后仍可手选地区。
4. 电话和导航打开浮层模拟原生能力；导航说明是“打开微信位置页”，不表示已经开始路线导航。旧电话／导航 hash 转到网点详情；空结果及加载失败仍可调整条件或重试。
5. “首次使用”尚无产品时也能查网点。维修网点详情可进入原维修申请路径，所浏览网点不自动成为承接站；登记要求、已有服务判断和后续联系仍沿用原流程。

本地 HTML 使用虚构示意地图，不接真实地图、拖拽、定位、电话或业务 API；机构、地址、热线、时间与距离均为示例。正式小程序拟使用 `map` 标记选点、按需 `getLocation`、`makePhoneCall` 与 `openLocation`，权限、隐私和原生样式须在真实开发时验证，不能以此稿认定真机能力已完成。

v0.6 保留 v0.4 的手动登记、标签码辅助识别及安装码说明，不恢复安装码认领或手机号找回演示；本轮不改变业务接口、开放状态或验收计数，也不生成图片。

## 本地浏览器预览

在 Finder 中双击本目录的 `index.html`，或在 VS Code 中找到它并通过浏览器打开，即可查看。也可以从文档仓库根目录启动本地预览服务：

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

然后打开 [本地预览](http://127.0.0.1:8768/05-%E9%A1%B5%E9%9D%A2%E5%8E%9F%E5%9E%8B/%E5%B0%8F%E7%A8%8B%E5%BA%8F/index.html)。已有服务从文档根目录运行时，无需重复启动；端口被其他服务占用时，可换一个未占用端口并同步修改网址。

`assets/` 中的 `wireframe-*.jpg` 和 `prototype-preview.jpg` 是 v0.1 的结构截图，供留档参考；当前效果以 `index.html` 为准，截图不会随代码自动更新。
