## 当前可评审内容

- Gaia 售后子系统外壳，包含顶栏、视角切换、一级导航和分组侧栏。
- 总部首页核心指标、近 30 天工单趋势、当前关注、工单队列、服务质量摘要和快捷入口。
- 客服首页的连续受理路径、四类待办队列、投诉提醒、行内办理与辅助查询。
- 服务站首页的今日履约队列、已配置排班时间线、人员／排班／配件资源入口。
- 门店首页的购买登记起点、最近顾客接续办理、三类购买记录与页面内申请安装。
- 指标联动、搜索、侧滑办理、四种列表状态、快捷搜索、菜单收起、刷新、深浅主题和全屏。
- 分层入场、数字计数、微型柱形生长、时间线和状态变化动效，兼容减少动效偏好。
