# 后台原型地图数据

`china-data.js` 复用 `frontend/gaia-ui/src/assets/echarts/map/json/china.json` 的中国省级地理数据，仅用于 `headquarters-map.html` 在浏览器中绘制可交互地图。它是地理数据资产，不是生成图片，也不包含业务数据。
