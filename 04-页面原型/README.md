两端小程序共享现有工作台和交互代码，在“小程序”内维护；后台原型的页面、样式和资源在“后台系统”内维护。各目录使用固定入口名称，版本与日期记录在各自说明中。

当前小程序原型待用户逐页评审和修改，用户最终确认后再进入视觉设计。后台岗位视角已补充第二版关键流程，当前可按角色逐页评审。
