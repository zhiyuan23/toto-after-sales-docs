# 页面原型

[打开后台与小程序统一预览](index.html#administrator)。各页左上统一显示“蓝鲸数字｜售后服务”与当前视角下拉，直接切换系统管理员、总部运营、客服作业、服务站作业、门店业务、消费者端、服务人员端七个视角。专业页与小程序方案收进下拉内“其他页面与方案”。切换保留本次预览中的页面状态；刷新保留当前视角与小程序页面定位，示例表单和临时业务数据重新初始化。

| 后台系统 | [系统管理员工作台](index.html#administrator) | 五角色最新工作台、服务质量、运营报表、配件管理、会员档案、服务站卡片样式；[后台说明](后台系统/README.md) |
| 消费者小程序 | [商品首页 v0.17](index.html#consumer) | 完整消费者页面、核心流程、页面总览与独立品牌产品中心；原有小程序方案对照保留；[小程序说明](小程序/README.md) |

## 文件与运行方式

```text
04-页面原型/
├── index.html / prototype.css / prototype.js   # 唯一维护的跨应用预览入口
├── prototype-catalog.js                        # 页面目录、视角归属与旧入口映射
├── perspective.js / perspective.css            # 各页面共用的左上标题与视角下拉
├── checks/                                    # 跨应用入口、视角路由及资源链接检查
├── 后台系统/                                  # 最新工作台、专业页、共用样式和检查
│   ├── administrator.html                     # 系统管理员紧凑版 V2
│   ├── headquarters-map.html                  # 总部最新地图版
│   ├── customer-service-v03.html               # 客服 v0.17
│   ├── service-station-v02.html                # 服务站今日安排与配件版
│   ├── dealer.html                            # 门店工作台
│   ├── index.html / workbenches.html           # 仅跳转的旧链接入口
│   └── README.md                              # 页面清单及业务边界
└── 小程序/                                    # 消费者与服务人员共用的原型工作台
    ├── index.html                             # 完整页面／流程／总览及原方案选择
    ├── brand-center-v1.html                    # 消费者独立品牌中心方案
    └── README.md                              # 版本说明与当前基线
```

从 `04-页面原型/` 启动静态服务后打开 `index.html`，以同一来源加载后台和小程序。不需要业务后端；也可单独打开各 HTML。统一入口只负责装载页面，不显示额外工具栏；各页自身顶栏共用管理员样式的视角下拉。专业页从“其他页面与方案”选择，地址直达及浏览器前进／后退保持一致。小程序侧栏只保留当前端的页面与流程导航，应用与版本选择统一收进左上视角下拉。

2026-10-19 导航修复：下拉内全部视角、专业页与方案使用指向统一入口的原生顶层链接（`target="_top"`），点击由浏览器直接更新顶层地址，不依赖消息投递。消息仅辅助同步内部页面定位与非链接跳转，不读取内嵌页面的 DOM。地址示例 `index.html#consumer/c-brand-catalog`、`index.html#worker/w-schedule`；刷新恢复相应视角及页面，配件页签同样支持定位。页面目录以外的链接继续沿用原页面行为。

所有页面均为虚构演示数据，不代表新增正式需求、真实接口接入或业务验收；不填写真实客户资料。后台与两端小程序的完整需求、Spec 及正式源码继续分别维护。

## 文件归属

后台和小程序各自按 `设计说明/`、`当前原型/`、`备选方案/`、`assets/`、`scripts/` 组织，检查保留在对应 `checks/`。当前入口与实施基线以统一目录中的用途标识为准；文件名含版本号不等于历史作废。共享版本参数继续使用同一套控制器，页面、脚本与资源的相对路径应同时验证。
