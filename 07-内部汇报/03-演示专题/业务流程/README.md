## 格式与使用

采用 **独立 HTML + 原生 SVG**。HTML 承载阶段导航、节点说明及文档依据，SVG 承载流程图，放大后保持清晰。页面不使用第三方库、外部字体、CDN 或接口，可直接打开本目录 `index.html` 离线查看；分发时携带整个 `07-内部汇报/` 及所需原文目录，保留相对路径。Markdown 中的 Mermaid 图继续作为可编辑的原流程来源，汇报版对其做重点编排，不是逐节点原样复制。

- 先看全流程，再按 01～07 展开；08 是跨阶段条件专题，不是所有工单必经的第八阶段。
- 左侧阶段或底部上一／下一阶段切换视图；键盘 ←／→ 翻页，Home／End 跳首尾。
- 点击节点查看本阶段规则，带交接目标的节点可进入相关阶段；“依据与口径”提供原文与后续契约入口。
- 适应屏幕显示整图；＋／− 放大缩小，放大后在图区域滚动查看。“全屏”或 F 隐藏侧栏和讲解摘要，突出流程图，仍可翻页。
- 地址的 `#overview`、`#registration`、`#application`、`#qualification`、`#dispatch`、`#fulfillment`、`#review`、`#exceptions`、`#fees` 可直接定位阶段。
- `?from=original`／`color`／`keynote` 只选择返回汇报的本地链接，不接受任意外部返回地址。由汇报新窗口打开时，可直接切回原汇报窗口继续讲解。
- 浏览器打印提供当前阶段的流程图与讲解要点；不是九页批量 PDF 导出。

## 内容与确认边界

本地图是内部汇报阅读入口，业务步骤不等于工单状态枚举。角色名称用于责任讲解，不新增岗位授权，不替代需求、Spec、源码或业务验收。

整理时采用后续已确认契约修正早期示意中的歧义：

1. 消费者手机号同步或有效唯一码绑定的可信本人商品直接建工单，不进入前置人工受理；其他渠道按相应契约办理，免费权益仍独立判断。
2. 无承接能力的两级退回按[工单两级退回 Spec](../../../specs/03-服务工单与调度/2026-10-03-工单两级退回与重新分配.md)表达，保留前置条件、原单与历史、人工待办和重新确认预约。
3. 远程服务按[三类服务契约](../../../specs/04-服务履约配件与费用/2026-09-26-安装维修指导三类服务流程.md)不支持原单直接转上门；需另行申请或联系服务中心。
4. 审核通过直接办结，退回重提新版本；回访和评价独立，不要求二次交单。收费／风险转人工，净实收等于应收且当前费用核对通过才能办结，未收齐不能后付办结，见[线下收费最终契约](../../../specs/04-服务履约配件与费用/2026-10-03-服务工单线下收费开发计划.md#offline-fees-delivery)。原文早期关于后付的建议不作为现行规则。
5. 收费采用人员记录口头同意、线下收款及消费者只读；全免费无新增必办费用操作。正式价格由配置维护，不编造 TOTO 收费标准。
6. 复开原单仍标为待确认方向；取消、投诉、再次服务和退款不互相自动替代。

本任务仅修改汇报材料与导航，不更新业务入口计数、开发进度、验收状态或功能版本，未提交、推送或部署。
