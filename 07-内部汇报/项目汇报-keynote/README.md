## 设计与播放

采用 1600×900 的 16:9 演示画布，按窗口完整等比缩放；非 16:9 窗口留边，不裁切正文。默认石墨黑主题，银白文字与品牌蓝强调；可切换浅色用于明亮会议室。排版以大标题、开放式分栏、单一重点和简洁的关系图组织，首页改为六角色环绕工单，平台页改为能力模块，流程页改为六个大节点，交付页采用四个并列工作安排。

动效用于介绍内容层级：标题入场、模块错序展开、手机轻微归位、流程线展开、结果随后出现、尾页品牌定格。除首页七阶段协同演示外，正文入场后保持静止。翻页立即响应，旧页动画取消；目录、备注及后台标签页暂停动画，关闭后恢复。系统“减少动态效果”时仅保留 150ms 淡入，首页不循环。无第三方脚本、远程字体或联网资源。

直接打开 `index.html` 即可离线使用，也可通过静态 HTTP 服务打开。演示工具在鼠标移动或键盘操作时出现，静置后收起，键盘焦点位于工具栏时保持可见。

| 操作 | 快捷键／方式 |
| --- | --- |
| 前后翻页 | 方向键、PageUp／PageDown、滚轮；空格或点击正文进入下一页 |
| 首尾页 | Home／End |
| 目录 | M |
| 讲解备注 | N；Esc 关闭 |
| 全屏 | F |
| 暂停／继续动画 | P；首页暂停按钮与全局按钮同步 |

选中文字、操作按钮或链接时不触发正文点击翻页；备注打开时保留阅读位置，不响应翻页键。第十四页与目录沿用原相对链接，配套材料在新标签页打开。页面中“查看任务”保留交互示意，不接入真实业务办理。
