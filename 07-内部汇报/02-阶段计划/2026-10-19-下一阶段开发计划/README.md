## 四项重点

1. **让测试人员正式参与。** 按实际使用流程测试，发现问题后及时修复、再验证。
2. **把剩下的功能补齐。** 重点完善服务时效（SLA）和付费服务，把相关流程做完整。
3. **完成数据同步接口。** 对接外部系统，同步蓝鲸数字主数据，确保数据准确、完整。
4. **完成后台四类角色的小程序端开发。** 支持渠道、服务站、客服和总部通过小程序处理日常工作。

贯穿本阶段的要求：开发过程中，持续优化业务流程，让操作更简单、更顺畅。
