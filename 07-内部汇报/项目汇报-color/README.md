## 设计方向

采用明亮的冷白底、深蓝灰正文与蓝／青绿／珊瑚／紫／金色信息分组；浅色背景承载大面积分区，较深同色文字承载标签和重点。角色名称、图标和说明同时保留，不仅靠颜色传达含义。章节数字作为辅助视觉，不进入屏幕阅读器正文。

页面主题色在既有色板内轮换，相邻内容页保持区分：01 蓝鲸数字平台用品牌蓝，02 系统全景用紫色，03 服务全流程用金色。标题重点、章节标识、章节数字及背景装饰同步使用页面主题色；正文角色与业务信息保留原有语义配色。

带章节编号的 13 页统一使用距逻辑画布顶部 132px、左侧 80px 的标题起点，大标题固定两行：深色第一行、主题色第二行。完整标题区右侧只保留章节数字，业务主体全部在标题下方排布。封面与结束页保留各自的居中构图。

每页按内容关系重新构图：

- 开场：双侧六角色与中央工单组成协同图，七阶段状态依次高亮。
- 背景与平台：问题／方向对照色块，六类平台能力横向展开。
- 应用与流程：左侧 Web 后台与右侧两台竖版手机并排，手机包含听筒、圆角机身和底部横条，消费者／服务人员分别沿用青绿／金色；服务全流程采用从左到右的六步单行流程，隐藏数字编号，卡片之间以垂直居中的箭头连接，业务图标独立居中；完工审核为蓝色、工单办结为青绿色，底部说明卡图标跨两行对齐。
- 变化与追踪：三类变化场景与追踪记录分栏；配套能力在完整标题区下方，以左侧椭圆主线搭配右侧两行两列卡片，保持无横线。
- 防窜货：上方四张关联资料卡与下方整体核验面板形成区分；核验区使用统一浅灰蓝背景，撑满正文剩余高度以对齐页面底部留白，内部以竖向分隔线、彩色图标和标题划分四项依据，各列内容居中并对齐，不增加物流办理含义。
- 体验与智能：体验页在统一标题下方排成三栏，视觉设计与交互体验两张主卡等宽、示意窗口同高；工作台示意包含窗口栏、侧边导航、任务行和操作步骤，保留“查看任务”反馈。消息提醒以浅灰底承载三条白底提醒卡，后台／微信／短信采用蓝／青绿／紫色图标与标题。上方完整留出章节数字。智能环节分别突出条件与结果。
- 知识与演示：知识来源连接双端用途，角色介绍后并列展示两条演示主线。
- 未来与交付：未来页以左侧浅蓝“品牌产品中心”主卡为视觉重点，沿用主题蓝大标题、深色正文及白色图标底，品牌／产品／内容三项分行整理，可选商城入口用白底收在卡内；右侧四项扩展采用统一白底和彩色图标，弱化状态标签，移除底部重复建议路径。交付工作在完整标题区下方采用四张等宽并列卡片，卡内列出安排与目标，材料链接另起底部一行。
- 结束：顶部使用与左上角相同的 `brand-logo.png`，保留感谢文案，底部平台名与 TOTO 以细竖线分隔，采用明亮的居中收尾构图。

页面使用 1600×900 逻辑画布，按浏览器窗口等比缩放，适合桌面与 16:9 投屏。正文页面入场后静止；动画包括模块展开、横向归位、协同连接线展开和重点结果随后出现。首页保留可暂停的七阶段协同演示。目录、备注及后台标签页暂停动画；快速翻页取消旧页动画；减少动态效果时只保留短淡入。

## 播放与维护

直接打开 `index.html` 即可离线使用，也可通过静态 HTTP 服务打开。移动鼠标显示底部工具栏，静置后收起。

| 操作 | 快捷键／方式 |
| --- | --- |
| 翻页 | 方向键、PageUp／PageDown、滚轮、底部上一页／下一页按钮；空格下一页 |
| 首尾页 | Home／End |
| 目录／备注 | M／N；Esc 关闭 |
| 全屏 | F |
| 暂停／继续动画 | P；首页暂停按钮同步 |
| 重播本页 | R |

点击正文或空白区域、选中文字均不翻页；按钮与链接仅执行其对应操作。备注打开时不响应翻页键。材料入口在新标签页打开，“查看任务”保持交互示意。

- `content.js`：以原版内容快照为基线，仅维护用户明确要求的文案变更。
- `foundation.css`：本目录独立保存的播放器、对话框和基础排版样式。
- `color.css`：浅色彩色体系、逐页构图及最终光学对齐。
- `presentation.js`：原内容渲染、图形重排、动画与演示操作。
- `brand-logo.png`：原品牌运行资源，不更改图形。

不加载其他版本的文件，不依赖外部脚本、字体或在线图片。CSS／JS 修改后同步更新 `index.html` 中的 SHA-256 前十位缓存参数。
