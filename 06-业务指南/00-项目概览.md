# 项目概览

本项目面向商品售后服务，首先兼容 TOTO，再通过通用的商品登记、服务受理和履约规则覆盖其他商品。当前仍在持续讨论与实施，流程和原型中的待确认内容不代表已定档。

[页面原型](../04-页面原型/README.md) · [完整业务流程](../05-业务流程/00-售后全流程总览.md) · [角色与操作指南](01-角色与操作指南.md) · [项目进度](../03-开发管理/00-开发进度与下一步.md)

## 三个应用载体

| 应用 | 主要用途 |
| --- | --- |
| Web 管理后台 | 总部运营、客服作业、服务站作业、门店业务共用一个后台，按岗位和授权展示功能 |
| 消费者小程序 | 登记自己的产品、申请服务、跟进处理、确认与反馈 |
| 服务人员小程序 | 接收任务、联系顾客、履约、提交完工资料 |

“TOTO 客服助手”目前只有计划名称及仓库意向，功能与应用关系尚待确认，不据此新增一套已确认范围。

## 先分清三个对象

| 对象 | 说明 |
| --- | --- |
| 商品档案 | 型号、分类、系列等通用产品资料 |
| 产品实例 | 某件产品的登记档案；手动选择商品与购买日期创建的是申报记录，不能单凭建档证明真实购买 |
| 本次服务记录 | 围绕某件产品提出的一次安装、维修或指导需求，按本次适用政策核验并组织服务 |

消费者可通过已有凭证、实物唯一编码或手动选择商品及购买日期登记产品。TOTO 的安装码方式与分类—系列—产品—购买日期方式均纳入讨论方案。登记成功与是否享有免费安装、保修权益分别判断；三条路径和核验衔接见[注册绑定流程](../05-业务流程/01-商品注册与绑定.md)，完整解释见[注册与服务资格核验细则](../02-技术设计/08-商品注册绑定与服务资格核验.md)。
