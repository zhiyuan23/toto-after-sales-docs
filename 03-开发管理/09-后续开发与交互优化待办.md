## 3. 实施约束

- 关联列只在目标 API 可读、目标菜单可达且 ID 合法时显示链接；否则保留原文本。
- 关联跳转按字符串传递长整型 ID，不通过名称、列表位置或显示编号反查。
- 动态表头不得隐藏多选、关键标识或操作列；不得因个人配置改变后端字段白名单、权限或数据范围。
- 分页数据不做“仅当前页”的客户端假排序。后端未支持排序契约时，表头保持无排序状态。
- 新增通用能力时回归 `EsTable`、商品分类范例及本文关联模块，分开记录隔离验证与共享环境验收。
