# 首批测试用例准备说明（2026-10-18）

本页说明首批种子文件的范围和导入方法，不维护日常测试进度。后续用例及执行记录由钉钉维护，协作规则及测试入口见[测试人员使用说明](../01-测试协作与钉钉AI表格使用说明.md)。

## 1. 交付与导入

| 文件 | 用法 |
| --- | --- |
| [完整导入工作簿](TOTO首批测试用例.xlsx) | 三张工作表：测试执行、用例库、缺陷；按平台导入界面逐表核对，首行作为字段名 |
| [用例库 CSV](用例库.csv) | 60 条用例的 UTF-8 BOM 种子文件，可单独导入用例库 |
| [测试执行 CSV](测试执行.csv) | 48 条首轮候选执行记录，均未执行 |
| [缺陷表 CSV](缺陷.csv) | 仅字段头，不含示例或实际缺陷；若平台不接受空数据导入，按结构文件手动建字段 |
| [钉钉表结构](钉钉AI表格结构.json) | 字段类型、单选枚举、视图筛选、权限职责及统计约束；供建表人配置，不是可以直接调用的 API 请求 |

XLSX 和 CSV 是同一份种子数据的两种导入方式，选其一，不重复导入。建表人使用 `TOTO售后服务测试协作` 作为建议名称；先检索组织内是否已有相同用途的表格，复用时按稳定编号查重，不以整表覆盖已有执行结果。

操作顺序：创建／选择 Base → 导入三张表 → 按结构文件配置单选和成员字段 → 配置视图及本轮统计 → 核对主键与记录数 → 分配真实成员、版本和数据 → 用两个账号验证查看／编辑 → 在[使用说明](../01-测试协作与钉钉AI表格使用说明.md#2-测试入口与启动条件)登记真实链接。

首列必须保留为文本编号，避免长整型业务 ID 和版本标识被改成数字。来源字段是仓库相对路径，测试人员从自己的文档仓库根目录打开；如团队有统一可访问的文档网页，可另加阅读链接，不使用建表人电脑的绝对路径。数据中的步骤／预期包含换行，导入后抽查是否完整。

初期用稳定文本编号建立关联即可，测试执行已带用例快照，测试人员无需来回跳表。确需钉钉关联／查找字段时，在文本编号导入核对后配置，不让查找字段覆盖历史步骤快照。成员初始为空；工作簿中的数据验证、颜色和筛选不等于已配置钉钉权限或视图。

## 3. 首批覆盖与限制

| 归属 | 首轮候选 | 条件成熟后安排 | 重点 |
| --- | ---: | ---: | --- |
| Web 管理后台 | 20 | 4 | 主档、购买、两级分配、退回、审核、回访、投诉、导入、角色／日志／报表，以及三端协同与库存调拨 |
| 消费者小程序 | 12 | 5 | 协议／会话、扫码、申报边界、可信商品建单、重试、三阶段、评价／投诉、资料和客服／网点 |
| 服务人员小程序 | 16 | 3 | 登录、任务、预约／改期／缺件、开始、草稿／上传、完工、退回、领退料和反馈 |
| 合计 | 48 | 12 | 60 条用例；不是完整需求覆盖率或已确认的本轮计划数 |

条件用例单独保留正式手机号验证、撤回／注销、第二消费者身份、跨午夜、微信真机能力、多会话共享库存竞争、真实非空资料、收费政策、延保资料、问卷、消息推送和未发布字典。已知未实现／待确认范围不当成已实现功能提测；历史外部阻塞需重新核对，不声称当前仍然故障。DWH／正式码源、完整防窜货及迁移等另按需求成熟度补用例，不由本首批替代。

所有用例初始“待评审”。48 条首轮候选仅表示已有功能及证据可支持准备，账号、数据、版本仍需逐条核对；12 条条件用例不生成初始执行记录。新增条件成熟后，由测试负责人评审并纳入明确轮次，不自动扩张首轮分母。所有负责人待分配，未执行任何测试，不沿用历史研发通过作为本轮结果。

推荐执行顺序：先账号／范围及主档 → 购买／扫码 → 建单及两级分配 → 联系／履约／配件 → 退回重提 → 审核办结 → 评价／投诉／抽样回访。免费主线优先；配置和并发场景在约定窗口准备，真实文件与真机按解除条件专项安排。业务单据互为前置时在执行记录填写单号，不假设旧报告中的示例单号仍可复用。

## 4. 已校准的关键预期

- 手机号匹配可信购买或有效唯一码扫码绑定的商品，消费者申请直入工单和现有分配队列；服务受理菜单已退役，历史自报待核验数据不自动放行。
- 可信关系不自动授予保修或免费权益，首轮免费兼容用例必须使用开发确认的 FREE_ONLY 专用政策／单据。
- 审核通过写 CLOSED；消费者评价、抽样回访分别记录，不负责关闭或复开工单。消费者“服务完成”阶段与后台审核终态按三阶段契约分别核对。
- 退回／收回遵循未开始、无阻止交接的配件单据及权限门禁；旧承接历史只读脱敏，不恢复操作权。
- 仅补资料重提保留版本且不重复耗用；领退料拒绝／撤销不生成已完成出入库流水，预留按契约释放。
- 服务人员当前“我的”企业切换入口隐藏，不为测试强行要求显示；底层多企业隔离需专用账号及开发支撑。

每条用例附直接来源。需求不清或发现新冲突时停在相关用例，提出待确认，不从旧 UAT 表或实现日志推导新的业务承诺。
