## 本阶段入口架构证据

- `pages.json` 已注册 31 个页面：C01～C17 对应 28 个业务路径，另含“我的”Tab、开发 Demo 和 404；集中路径常量、页面文件、返回关系和实际壳页绑定一致。
- 正式 Tab 恰为“首页、服务、我的”；Demo 仅作为开发验证入口。C16/C17 仅注册为隐藏建设中路由，未配置号码、外链或渠道，也不出现在首页、服务或我的可见入口。
- 登录拦截由未来身份适配器注入，默认不臆测登录状态；页面未创建业务 API、认证 Store、角色或响应模型，未接 API 的入口均显示诚实空态或建设中状态。
- `pnpm type-check`、`pnpm eslint`、`pnpm stylelint`、`pnpm test:routes`（8 / 8）、`pnpm build TOTO`、`pnpm build:h5 TOTO` 和 `git diff --check` 均通过。H5 已检查桌面、390×844、暗色和减少动态；微信仅完成构建，未执行开发者工具或真机验收。
- 完整实现与验证见[第一阶段验收记录](../specs/2026-09-07-第一阶段菜单路由与页面UI架构.md)。

## 本系统完成条件

- C01～C17 的 Tab、路由、返回路径、空态、登录拦截和权限可见性在微信小程序/H5 适用范围内验证通过。
- 微信身份、产品注册、购买信息、安装码、预约、记录和评价均调用真实接口，不以演示交互或静态数据计完成。
- 本人数据隔离、重复提交、弱网重试、媒体上传失败、会话失效和隐私撤回等关键场景通过验收。
- 微信开发者工具、真机、真实接口、上传/提审/发布分别记录；构建通过不代表发布完成。
- 对应 Spec 和项目总览已同步更新。
