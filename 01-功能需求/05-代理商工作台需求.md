# TOTO售后服务代理商工作台需求

版本：V1.0  
更新日期：2026-09-08  
文档状态：需求基线草案  

本文件定义代理商和门店的顾客登记、商品登记、隐私授权、安装预约、查询和退货功能。

2026-09-08 已补入全部代理商截图的可见信息，见[截图补充](#screenshot-details)。截图证明旧系统页面存在；未展示的权限、校验和提交结果仍需在对应 Spec 确认，不因按钮可见而默认开放权限。

代理商工作台已确认是 `gaia-ui` 中的角色门户，与统一管理后台共用“TOTO 售后服务”一级顶部菜单。沿用 Gaia 登录；登录后的授权门店选择作为业务上下文，不作为独立侧栏菜单。菜单和目录见 [`gaia-ui` 目录与菜单设计](../02-技术设计/03-gaia-ui目录与菜单设计.md)。

## 10.2 代理商工作台

| 编号 | 功能 | 优先级 | 需求说明 | 核心验收点 |
| --- | --- | --- | --- | --- |
| DLR-001 | 登录和门店选择 | P0 | 用户登录后选择所属直营或授权门店 | 不得选择未授权门店，记住最近门店可配置 |
| DLR-002 | 门店信息 | P0 | 查看当前门店类型、状态和送安一体标识 | 只读数据来自主档 |
| DLR-003 | 线下门店顾客登记 | P0 | 创建购买和顾客记录 | 支持顾客填写或店员填写 |
| DLR-004 | 虚拟门店顾客登记 | P0 | 创建线上或内购虚拟门店记录 | 区分来源和虚拟门店性质 |
| DLR-005 | 商品编辑与确认 | P0 | 增减商品、编辑品番组合和数量 | 确认后锁定，修改需保留版本 |
| DLR-006 | 顾客扫码填写 | P0 | 生成二维码供顾客填写 | 二维码短时有效、一次性或绑定会话 |
| DLR-007 | 店员填写 | P0 | 手机验证后录入使用者资料 | 验证码限流并校验授权 |
| DLR-008 | 隐私政策与签名 | P0 | 展示隐私政策并采集同意签名 | 保存政策版本、签名图片哈希和时间 |
| DLR-009 | 顾客信息查询 | P0 | 查看本门店购买记录 | 支持查看、编辑、编辑商品、预约和退单 |
| DLR-010 | 安装预约 | P0 | 对未预约或部分预约产品发起安装 | 支持期望时间和附加服务 |
| DLR-011 | 再次预约 | P0 | 对未完成预约或符合规则的产品重新发起 | 不产生非法重复活动工单 |
| DLR-012 | 退货操作 | P0 | 整单退货或删除退货商品 | 已有服务记录时按规则限制并提示 |
| DLR-013 | VIP 标识 | P1 | 标记是否 VIP | 现状依赖销售政策人工判断，规则待确认 |
| DLR-014 | 查询与导出 | P1 | 按代理商、门店、顾客、日期、状态查询 | 数据范围强制过滤 |

代理商顾客登记已确认字段：产品分类、机能部型号、底座型号、水箱型号及扩展商品型号、数量、VIP、备注、购买人手机号、短信验证码、使用方式、使用者姓名、使用地址省市区和详细地址。

| DLR-007 店员填写 | SS-10 显示“隐私授权确认：已确认”；购买人手机与验证码有必填标记，支持发送短信验证码和“下一步”；下方显示自己使用／朋友购买、使用者姓名、省市区、详细地址，后三项有必填标记 | 截图呈现先授权、再手机验证、再完善资料的页面状态；需确认是否为唯一允许顺序、代填人权限、发送限流和验证有效期 |
| DLR-008 隐私签字 | SS-08 隐私正文底部有“显示签字栏”；SS-09 弹窗“签字并同意隐私授权”说明姓名、电话、产品使用地址用于售后服务，提示正楷签字，提供手写区、“清空、同意、不同意”和关闭入口 | 空签名是否可提交、拒绝／关闭后的保存行为、签署人与使用者关系未展示。历史条款提及撤回与注销，但其产品实现和现行条款需另行确认，不能直接把历史文字作为当前政策 |

### 10.2.2 截图补充：顾客查询与安装预约

| 对应需求 | 可见信息与补充 | 开发边界／待确认 |
| --- | --- | --- |
| DLR-009、DLR-013、DLR-014 顾客查询 | SS-11、SS-13 筛选含代理商名称、门店名称、购买日期起止、顾客手机、顾客姓名、登记状态、安装码、预约状态、备注、是否退单、VIP、家装订单；预约状态显示“未预约、部分预约、已预约”复选项，是否退单显示是／否 | 登记状态下拉值未展开；日期匹配口径、多个状态组合规则、家装订单来源及适用范围待确认 |
| DLR-009 查询结果与动作 | 单行选择后可见“查看、编辑、预约安装、编辑商品、退单”，另有“查询”；列分为商品信息、顾客个人信息及预约状态／VIP。顾客手机、姓名和详细地址在列表中有脱敏显示 | 列表与详情的数据可见范围、脱敏策略、允许编辑字段、退单条件由角色和业务 Spec 定义。截图未展示代理商导入或导出按钮，DLR-014 的导出仍是既有目标需求 |
| DLR-010 安装预约 | SS-12 可逐行／全选本次安装商品；可见产品分类、机能部型号、底座型号、水箱型号、商品型号4～8；顾客手机号、顾客姓名有必填标记，并有备用电话1、备用电话2；顶部有“提交、取消”，右侧预留“服务状态、满意度” | 型号4～8是旧字段名，业务含义与新产品组合模型需对齐；下半页未拍全，不能认定预约字段只有这些。服务状态、满意度仅有标签，值域及回传来源未展示 |

SS-11、SS-13 是不同记录状态下的同类列表，不能据两张静态图推断退单或预约提交成功。SS-06 仅在侧栏显示虚拟门店登记入口，没有该表单的独立截图，因此不能声称两类门店登记规则已全部核实。管理员权限树 [SS-19](../00-项目资料/04-原始资料索引与需求核对.md#ss-19) 将线下、线上、虚拟门店登记分列；既有 DLR-004 描述中的“线上”不能据此认定与线上登记完全等同，入口归并及流程差异见 Q-SS-09。
