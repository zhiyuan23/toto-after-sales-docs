# TOTO售后服务服务人员小程序需求

版本：V1.0  
更新日期：2026-09-08  
文档状态：需求基线草案  

本文件定义服务人员的任务、状态、签到、扫码、完工、配件、资料和个人中心功能。

2026-09-08 已审阅全部 41 张服务人员截图（含重复视图），字段和操作细节见[截图补充](#screenshot-details)。截图事实与既有目标方案分开使用；静态图未展示的权限、校验、状态迁移和费用规则须在对应 Spec 确认。

菜单采用原始截图的“任务、配件、应用、我的”4 个 Tab。“应用”承载延保/技术资料和领料/退料/调拨记录。见[页面清单](08-页面清单.md) W01～W16；逻辑目录和建议路由见[小程序目录与页面路由设计](../02-技术设计/04-小程序目录与页面路由设计.md)。应用仓库归属尚未确认，该目录不直接等同于“客服助手”的技术基线。

## 10.4 服务人员小程序

### 10.4.1 任务

| 编号 | 功能 | 优先级 | 需求说明 | 核心验收点 |
| --- | --- | --- | --- | --- |
| WAPP-001 | 任务搜索与排序 | P0 | 按任务号、联系人或地址搜索；截图补证“任务排序”入口，具体排序项待确认 | 只查本人或授权任务；搜索字段为目标要求，排序规则按 Spec 确认 |
| WAPP-002 | 状态页签 | P0 | 待完工、待发布、待审核、待交单、断联任务、取消任务 | 列表按已确认状态口径筛选；计数与列表一致 |
| WAPP-003 | 任务卡片 | P0 | 显示任务号、地址、客户、电话、产品、服务项目、期望时间和沟通记录 | 敏感信息按权限展示 |
| WAPP-004 | 任务地图 | P1 | 在地图中查看任务分布和任务详情 | 只展示当前可见任务 |
| WAPP-005 | 联系客户 | P0 | 拨打电话或复制号码并记录联系结果 | 不自动录音，录音需单独授权 |
| WAPP-006 | 状态变更与取消恢复 | P0 | 已预约、取消、断联、改期和缺件；截图补证“恢复取消任务”入口 | 原因和备注按状态要求必填；恢复权限、前提和目标状态待确认 |
| WAPP-007 | 修改任务 | P0 | 修改备用电话、地址补充和任务备注等允许字段 | 禁止修改来源关键字段 |
| WAPP-008 | 上门签到 | P0 | 到达后基于时间和位置签到 | 定位权限拒绝时走人工说明流程 |
| WAPP-009 | 服务过程 | P0 | 记录检测、处理方案、服务项目、照片和配件 | 草稿可离线保存并续传 |
| WAPP-010 | RFID 或 QR 扫码 | P0 | 扫描并回传产品码 | 支持扫码失败手工输入和复核 |
| WAPP-011 | 完工 | P0 | 提交服务结果、照片、客户确认或签名；旧系统四步为图片上传、产品信息、单据信息、确认费用 | 缺少必填证据时禁止提交；四步字段、费用范围及校验以截图补充和已确认 Spec 为准 |
| WAPP-012 | 交单 | P0 | 查看和提交待交单任务 | 交单定义和凭证待客服调研确认 |

现有任务卡片已确认展示：预约上门地址、期望上门时间、客户联系方式、历史沟通记录、产品或组合品番、服务类型、附加服务和备注。现有完工页面可见产品、序列编号、RFID、购买渠道、经销店名、购买日期、工厂代码、用水、服务类型和服务方式等字段。

### 10.4.5 截图补充：完工四步与产品信息

来源：[SS-24](../00-项目资料/04-原始资料索引与需求核对.md#ss-24)，对应 WAPP-009～WAPP-011。

1. 旧系统步骤条依次为“图片上传 → 产品信息 → 单据信息 → 确认费用”，当前拍到第 2 步；底部有“上一步／下一步”。本批只有这一步的表单，不能认为图片类型、单据内容及费用明细都已核实。
2. 产品区展示产品序号与组合型号，并有编辑图标；“制造编号”和“RFID”分别有扫码图标，RFID 旁有“无RFID”入口。旧文档概括为序列编号，本图原标签为制造编号，数据字典应核实两者是否同义后映射。
3. 其他可见字段为购买渠道、经销店名、购买日期、工厂代码、用水、服务类型、服务方式；带选择箭头的样例值包括实体店、水道水、安装、免费。样例不是完整下拉字典。
4. 本页面“服务方式”显示“免费”，与核心流程中远程／上门的服务方式含义不同。接口设计前需区分收费属性与履约方式，禁止共用一个未经确认的枚举。
5. “无RFID”的适用条件、是否仍要求制造编号、扫码失败补录、产品型号修改权限以及跨步草稿保存均未展示。最下部另有被固定按钮区遮挡的控件，标签不可读，不推测业务含义。

“确认费用”仅证明旧系统存在此步骤。首期费用、支付、退款和结算仍受 Q-007 约束；不得因截图出现费用页而自动扩大交付范围。签到、离线草稿、签名和媒体上传策略继续按既有目标需求及 Spec 使用，不标成这张图已证实的旧行为。
