# TOTO售后服务页面清单

版本：V1.0  
更新日期：2026-09-11
文档状态：需求基线草案  

本文件汇总管理后台、代理商工作台、消费者小程序和服务人员小程序的页面范围。

本页唯一维护页面组和需求入口 ID，不维护开发状态。原统一管理后台和代理商工作台属于同一个 `gaia-ui` Web 管理后台，按角色工作视角展示；正式菜单名称、层级、代码、路径和页面目录见 [`gaia-ui` 目录与菜单设计](../02-技术设计/03-gaia-ui目录与菜单设计.md)。进度统一从[开发进度总览](../03-开发管理/00-开发进度与下一步.md)进入，并在对应应用入口明细更新；需求和任务依赖见[AI 开发需求索引](09-AI开发需求索引.md)。

## 11 页面清单

### 11.1 Web 管理后台主体页面

1. 登录、首页、个人中心。
2. 代理商列表和详情。
3. 门店列表、详情、批量导入。
4. 服务站、服务区域。
5. 商品分类、商品、系列、图片、配套品。
6. 窜货查询、条码异常、异常复核、安装码管理；安装码也在相关业务记录中检索和查看。
7. 顾客列表、顾客详情、预约安装列表和详情。
8. 客服受理台、工单列表、工单详情、派单看板、异常队列、回访和投诉。
9. 服务人员、排班、技能和服务质量。
10. 配件、仓库、库存流水、领料、退料、调拨和盘点。
11. 会员、标签、问卷、推送和结果。
12. 角色、用户、权限、字典、参数、通知模板和日志。
13. 报表中心和导入导出中心。

### 11.2 Web 管理后台门店业务视角页面

1. 登录和选择门店。
2. 门店信息。
3. 线下门店顾客登记。
4. 虚拟门店顾客登记。
5. 商品编辑和确认。
6. 顾客扫码填写二维码页。
7. 隐私政策和签名。
8. 顾客查询和详情。
9. 在顾客购买记录内发起安装申请。
10. 退货确认。

### 11.3 消费者小程序页面

1. 首页。
2. 服务聚合页。
3. 产品注册和购买信息。
4. 产品注册成功和安装码。
5. 维修或指导预约。
6. 网点列表、地图和详情。
7. 客服入口。

9. 个人信息、偏好、隐私条款和注销。

11. 客服热线、了解更多咨询：脑图导出明确名称，C16“我的／客服热线”归入 CAPP-009；C17 的内容、渠道和需求编号待确认。

### 11.4 服务人员小程序页面

1. 任务列表、搜索、地图和详情。
2. 状态变更、修改任务和沟通记录。

4. 我的配件、配件详情和领退料。
5. 领料单、退料单和调拨单。
6. 延保资料、技术资料和资料详情。
7. 问题反馈、修改密码、切换企业和退出。

## 12 菜单入口定义

当前将同一个 Web 管理后台组织为总部运营、客服作业、服务站作业、门店业务四个视角，菜单与查看角色见[后台菜单与角色权限手册](../04-业务阅读/05-后台菜单与角色权限手册.md)。跨视角共用同一功能 code/path；工作视角不是独立应用端，本页入口 ID 与需求模块归属保持不变。

历史清单共规划 96 个需求入口组：Web 管理后台 63 个（历史 `Axx` 55 个、`Dxx` 8 个），消费者小程序 17 个，服务人员小程序 16 个。A05、A13、D08 已退出当前 Web 产品范围，但保留编号和原需求关系用于变更追溯；它们不再对应功能注册、路由或页面。A38 安装码管理于 2026-09-12 按用户要求恢复至总部、客服的业务查询组，恢复查询切片见[实施记录](../specs/2026-09-12-安装码管理恢复与标识关系核查.md)。当前有效范围为 Web 60 个、全项目 93 个入口。编号仅用于需求追踪，不是路由、数据库菜单编码或权限标识。一个入口可包含列表、详情、表单和操作，也可能合并到另一个菜单或作为隐藏流程页，因此入口组数量不等于侧栏菜单数量。Web 管理后台统一沿用 Gaia 登录及个人中心，不另建售后登录菜单。

来源“原始”表示原图中能识别入口主题，不代表该行的所有扩展规则已确认；“建议”是目标草案补充；“待确认”表示详细业务或范围未定。C16 客服热线已归入 CAPP-009，号码与配置待确认；C17 更多咨询尚无正式需求编号。均保留入口，不虚构外链和渠道。
