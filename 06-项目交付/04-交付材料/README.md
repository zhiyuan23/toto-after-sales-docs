# 交付材料

[HTML 交付清单](index.html)与 [内容源](00-交付清单.md)共用 39 项材料及交接核对、9 个培训场景。版本 v0.1（2026-10-10），业务复核稿。按项目说明、角色培训、应用环境、技术运维、范围边界五类组织。

网页支持类别、材料状态和关键词组合筛选；打印输出完整清单，不因当前筛选遗漏项目。材料状态与交接结果分开，实际批次、环境版本、接收人、培训、验收及签收待据事实填写。网页不持久保存签收结果，正式记录另行归档。

项目小组继续运维，客户资料交付不表示责任转交。内部测试账号手册、密钥及本地配置不进入对外包，凭据仅按约定安全渠道交接。尚未生成正式签收 PDF 或对外压缩包，按确认范围再制作。
