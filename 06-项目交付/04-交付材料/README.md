# 交付材料

以[交付清单](00-交付清单.md)为入口，核对本次交付的材料、应用与环境、培训及持续运维安排。项目小组继续负责运维，客户侧资料交付不表示运维责任转交另一个团队。清单引用角色手册和项目说明，不复制两项正文。

## 后续产物结构

| 产物 | 内容 | 当前情况 |
| --- | --- | --- |
| 清单内容源 | 交付范围、材料入口、交接项目及核对依据 | [00-交付清单.md](00-交付清单.md)，已有骨架 |
| 清单网页 | 分组阅读材料，按实际范围组织核对 | 后续制作，本轮不建立空页面 |
| 可打印清单 | 同一清单的打印视图，供线下核对与交接 | 后续制作，本轮不生成签收件 |

清单按“项目说明 → 角色手册与培训 → 应用与环境 → 技术运维 → 范围及待确认事项”分组。最终交接时再补实际材料标识、接收对象和核对结果；未准备、未培训或未验收的内容不默认勾选完成。
