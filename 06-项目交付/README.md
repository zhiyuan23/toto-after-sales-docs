# 项目交付

本目录统一组织简明业务指南、详细角色手册、项目说明和交付材料，面向项目理解、系统使用、岗位培训和交接。内容按完整项目与完整需求编写；项目说明基础大纲已补充八部分讲述顺序、内容要点及展示建议，供持续调整后制作 PPT 或网页。角色手册、管理层／客户专项大纲和交付清单当前为写作骨架，正文后续逐项补充。

```text

```

## 编写口径

- 内容覆盖完整项目与完整需求，不按当前开发进度裁剪；本轮不设置核对日期、适用版本或实现／验收状态字段。
- 项目按 Web 管理后台、消费者小程序、服务人员小程序三个应用组织。总部运营、客服作业、服务站作业和门店业务属于同一 Web 后台的工作视角。
- 角色手册按操作场景编写，结合完整需求、技术规则与对应功能契约核实步骤、权限和交接条件；需求中的讨论内容不因整理材料成为新的业务决定。
- 项目说明基础大纲承载共同内容，管理层和客户大纲分别组织表达重点。后续选择展示形式后，相关文件存放在“03-项目说明”中；多次正式交付的说明材料需要留存时按日期建立子目录。
- “01-业务指南”保留简明项目与岗位导读，通过链接进入“02-角色手册”；目录合并不将两类正文混成一份，也不复制完整权限或实时进度台账。
- [协议演示文稿](01-业务指南/协议文稿/README.md)保留原有演示和未正式生效的说明；测试账号手册保留为内部测试参考，不作为对外交付正文。
