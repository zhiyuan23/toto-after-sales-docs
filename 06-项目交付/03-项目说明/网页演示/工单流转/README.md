# 工单流转网页演示

[打开演示](index.html) · [返回项目说明大纲](../../00-项目说明大纲.md)

本样例用于评估网页汇报的视觉、交互与动画效果，以口头讲解为主。画面突出四个角色、一张工单、流转线路和一句当前提示；详细业务说明由大纲、角色手册与讲解者承接。

## 展示与交互

- 全幅 SVG 舞台：放大角色和移动工单，移除长段说明、单号、下一动作和卡片进度，只显示工单状态与负责角色。
- 五段导航承载七个动作：申请 → 分站派人 → 预约履约 → 审核 → 办结。其中分站／派人、预约／履约分别保留独立动作，可用左右按钮或方向键逐步讲解。
- 消费者、客服、服务站、服务人员分别使用青绿、蓝、柔紫和暖金；背景使用浅色衬托，当前交接线路保持最高对比度。
- 沿线路流动的点阵表示方向，背景线路低对比度流动；角色节点扩散、工单移动与一句提示同步变化。办结时展示闭环并停止点阵，保留清晰的完成画面。
- 点击“播放流转”连续播放，随时暂停／继续；暂停同时冻结点阵、工单与节点动效。点击角色或阶段可跳转，切换人工／智能分配保留当前动作。
- 人工模式适合逐步点击讲解；智能模式连续播放时加快分站和派人的衔接。播放速度仅为演讲节奏，不表示实际业务耗时或效率测量。
- 保留深浅主题、全屏、方向键与空格控制。减少动态效果时去掉点阵和位置动画，方向箭头、角色色彩与状态提示仍可阅读。

## 本地打开

页面由 HTML、CSS、JavaScript 和内嵌 SVG 构成，无第三方依赖、外部字体、网络图片或构建步骤。直接用浏览器打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

随后访问 `http://127.0.0.1:8766/`。服务器仅用于查看演示文件。

## 演示场景与业务口径

页面使用示意工单状态，交互仅切换演讲画面，不读取或写入真实业务数据。

- 消费者已有可信商品时申请直接建单，客服人工受理不作为全部工单的必经步骤。
- 分站与站内派人是两个动作；智能模式表达系统按适用策略辅助分配，人员联系、预约和实际服务仍保留人员责任。
- 两种分配模式均由授权客服人工完工审核。审核通过直接办结，消费者评价和抽样回访独立办理，汇报主画面不展开这些分支。
- 商品故障知识、配件建议和消费者智能助手由项目说明大纲另行介绍，避免在本模块叠加详细文字。

## 实现选择

使用原生 SVG、CSS 状态过渡和 Web Animations API。按线路弧长一次性采样点阵位置，动画使用 transform／opacity，线性速度与错开的点阵相位形成连续流动；交互可中断，暂停与继续统一控制。仅在当前交接线路提高对比度，角色配色一致，背景流动保持克制。

## 检查说明

七个动作与五段导航映射、人工／智能切换、角色与键盘跳转、播放暂停和继续，以及点阵暂停一致性在本地浏览器核对。深浅主题与全屏控制检查通过；1024×768、1280×720、1440×900 和 1920×1080 桌面尺寸下页面完整显示，控制台无错误或警告。JavaScript 语法、文档链接与资源检查一并执行；演示检查不作为业务验收或新增功能进度记录。

截图保存在已忽略的 `.local/verification-artifacts/work-order-presentation/`。实际投影设备与离线文件打开尚未单独检查；本机未配置 Lighthouse，未运行性能评分。减少动态效果的降级已实现，但浏览器工具未提供该系统偏好的切换能力，未进行偏好模拟实测。
