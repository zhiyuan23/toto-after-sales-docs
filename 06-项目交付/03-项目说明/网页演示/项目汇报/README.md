# 完整项目 HTML 汇报

[打开汇报](index.html) · [项目说明大纲](../../00-项目说明大纲.md) · [独立工单演示](../工单流转/index.html)

本版覆盖大纲的十一个模块，共 21 屏，供领导汇报、客户说明和演讲内容优化。页面以短标题、关键词和关系图为主，详细解释放在默认收起的内部讲解备注。内容按完整项目需求组织，不维护日期、版本、完成率或验收状态台账；延保活动按用户要求明确标注为预留功能、尚未开发。

## 打开与讲解

所有资源均为本地 HTML、CSS、JavaScript 与 SVG，无外部字体、图片、模型接口或构建依赖。可用浏览器打开 `index.html`；也可以在上级“网页演示”目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8766/项目汇报/`。相邻的 `/工单流转/` 仍可单独打开。

整体图形采用统一的 Tabler 线性 SVG 图标，已随页面离线保存，许可见 `TABLER-LICENSE.txt`。封面以商品、客户、服务、结果环绕工单；角色与服务主线以语义图标辅助识别，平台、知识库、消费者助手与配件准备采用浏览器、档案、手机和工具场景。图形只辅助既有讲解，不改变内容、顺序或展开步数。

- 点击“继续”依次展开当前页，展开完成后按钮变为“下一页”。“上一步”先收回当前展开，再返回上一页。服务主线总览之后以“看工单协同”进入独立演示，再以“看异常与追踪”进入补充页，最后转到关键能力。
- 开场按“项目来源与建设思路 → 业务痛点与建设方向 → 蓝鲸数字平台与产品能力”讲述。来源页只展示 TOTO 的需求依据和全流程梳理思路；痛点页逐行先显示问题、再展开对应方向；平台页以蓝鲸数字框内的售后系统为主画面，展开可配置、可复用、可扩展，再展示更多品牌与场景的复用方向。两页分别讲来源与产品结果，不重复演进图。
- 方向键或空格逐步推进；PageDown／PageUp 直接翻页；Home／End 回到首尾。
- 顶部“目录”可跳到任意页面；“讲解备注”仅用于内部准备，默认关闭；支持深浅主题和全屏。快捷键 M／N／F 分别打开目录、备注、全屏。
- 工单页只保留一个随步骤更新的标题，人工／智能分配切换与标题同一行；全屏统一使用顶部“全屏汇报”。动画内部保留角色和阶段跳转、播放暂停。焦点在工单内时方向键控制工单动作；使用外层“下一页”离开工单页。离开后暂停点阵与播放，再进入时保留工单位置。
- “协同中的变化与追踪”打开即完整显示三块异常处理路线与下方的四类追踪信息，无须再展开；防窜货在 08 配套业务的“产品与渠道”专题单独介绍，不与工单协同异常混讲。
- 08 按“配套业务总览 → 防窜货 → 保修与延保”连续讲述。防窜货以产品流向与核验依据示意；延保页区分现有办理与预留活动，未提供活动交互或自动发放演示。
- 防窜货“核验依据”卡片按当前源码与已确认契约简述四项判断：有无购买登记、入库／登记门店是否一致、安装地址是否在登记门店销售区域、是否在出库经销商销售区域。上方为资料关联示意，不作为四个判断步骤；判断结果为疑似线索，缺失适用数据时保留未判断。
- 每页有独立地址锚点，例如 `index.html#knowledge`；刷新保留所在页，分步展开从本页起点开始。

## 后续怎样修改

- `content.js`：按顺序维护每屏的 `id`、章节、标题、摘要、讲解备注和图示 HTML。`steps` 是最大展开步数，`nextLabel` 可设置展开完成后的过渡按钮文案；`data-reveal="0"` 初始显示，`1`、`2` 等由讲解者依次展开；同一编号可控制多个元素。
- `styles.css`：维护整套字体、色彩、页面布局与图示。主色为品牌蓝，青绿、柔紫、暖金分别承接消费者、服务站和服务人员相关内容。
- `icons.js`：保存 [Tabler Icons](https://github.com/tabler/tabler-icons) 的 SVG 图形，采用 MIT 许可；在 `content.js` 中复用 `icon`、`mark`、`svgMark` 帮助函数，保持线宽、尺寸和色彩一致。装饰图标不参与焦点导航，原有文字继续承担信息表达。
- `app.js`：管理翻页、目录、展开、备注、地址锚点、主题和全屏。
- 工单仍复用相邻“工单流转”中的三个源文件；嵌入样式隐藏独立演示的标题和顶部工具。父子页受控消息核验来源窗口和同源关系（本地文件模式核验窗口），用于暂停、主题与分配模式控制，以及步骤标题和模式同步。

后台工作台、手机和问答均是**交互或场景示意**，可在后续替换为真实页面截图。消费者助手不实际调用模型；配件建议不虚构型号、库存或数量。服务申请、两级分配、审核办结以及评价回访的业务口径沿用大纲。自有 SaaS 平台统一称“蓝鲸数字”，售后服务系统作为平台内的业务系统承载；多客户复用、扩展与业务收益按演进目标表达，同类 SaaS 产品的比较仍按通用类别表述。

材料正文入口：[角色手册](../../../02-角色手册/00-手册索引.md) · [交付清单](../../../04-交付材料/00-交付清单.md)。

## 验证与限制

开场合并为 19 屏后，核对目录与页面数量一致、独立目标页已移除；痛点页六次展示状态按“问题 → 方向”依次展开，上一步可收回最后一项；产品能力页随后进入三个应用，末页显示 19 / 19。两张调整页在以上三种桌面尺寸下无溢出，讲解备注与页面内容一致。

01 与 03 区分优化后，来源页一次展开建设思路，再进入痛点页；平台页先展示平台内的售后系统，再显示三个产品特点，最后展开更多品牌与商品场景。两个页面在三种桌面尺寸下无溢出，分步显示与开场顺序已核对。平台包含关系、深浅主题及封面、结束页与大纲的名称一致性已核对；01 只讲 TOTO 的业务依据，平台与复用价值由 03 承接。

工单布局调整后另行核对：嵌入页只有一层标题和一处全屏入口；人工／智能切换、逐步推进、连续播放及返回工单时的标题同步正常。以上三种桌面尺寸下标题与切换按钮无重叠、页面无溢出；独立演示仍保留原有标题与工具。
