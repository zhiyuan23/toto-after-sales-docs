第二版按七章、十三屏组织，适合以现场讲述为主的领导汇报与客户交付演讲。第一版二十屏及其资源、大纲和独立工单演示完整保留；第二版的 HTML、CSS、JavaScript、SVG 图标与动画控制器均在本目录独立维护。

## 打开与调整

直接在浏览器打开 `index.html`，或在上级“网页演示”目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8766/项目汇报-v2/`。目录中可打开第一版和完整工单演示。

- 方向键／空格逐步展开；PageDown／PageUp 直接翻页；Home／End 跳到首尾。
- 第十二屏为真实演示过渡页：在此切换到真实应用，演示完成后返回汇报，再进入最后的交付安排。末页材料菜单保留，后续按实际材料配置链接。
- M／N／F 分别打开目录、内部备注、全屏；支持深浅主题。
- 首页支持暂停／继续，离页、打开目录或备注时暂停；保留第一版已确认的工单移动与审核节奏。
- 修改 `content.js` 调整内容、顺序、备注与展开步数；修改 `styles.css` 调整布局。动画在 `cover-motion.js`，翻页及演讲工具在 `app.js`。
- 本地 SVG 图标沿用 Tabler，许可随 `TABLER-LICENSE.txt` 保存。页面没有外部字体、图片、模型接口或构建依赖。
