# 总部运营操作手册

面向总部业务管理、运营及授权只读人员。使用 Web 管理后台“总部运营”视角，管理商品、渠道、服务网络和业务规则，查看服务质量与经营数据。版本 v0.1 · 2026-10-10 · 业务复核稿；具体环境开放情况须在交付时核对。

## 1. 岗位职责与工作入口

登录后选择“总部运营”，先看工作台，再进入对应业务。视角、功能、按钮与数据范围分别控制；查看权限不包含修改、审批或导出。

| 工作领域 | 菜单入口 | 主要职责 |
| --- | --- | --- |
| 服务治理 | 服务运营 | 查询工单、投诉、人员反馈、服务质量与运营报表 |
| 商品与购买 | 商品资料、购买信息 | 维护商品主档，核对实物、购买记录与安装码 |
| 渠道与网络 | 销售渠道、服务网络 | 维护代理商、门店、服务站和适用区域 |
| 会员运营 | 会员档案、会员分析 | 查询授权会员资料与分析 |
| 库存与渠道线索 | 配件库存、防窜货分析 | 查询台账、耗用及疑似窜货线索 |
| 业务治理 | 业务配置 | 按权限维护服务设置、评价标签、业务标签与协议 |

每日关注异常、投诉及人员反馈。兼任客服或仓储岗位时，需另授相应视角、数据范围与动作。

## 2. 维护商品、配件与服务资料

**前提与入口：** 取得主档写权限，进入“商品资料”。分类、系列、商品档案、实物档案和配件档案分别维护。

1. 检索现有记录，核对是否重复，再新增或编辑。
2. 按页面必填项维护分类、系列、型号及适用资料，核对启用状态与关联关系。
3. 在商品档案维护适用服务资料、常见问题与故障处理、配件建议等已开放内容。区分对客知识与内部资料。
4. 保存后回读详情，确认授权岗位可查询，版本与发布状态正确。

**结果：** 型号资料与单件实物可以对应，消费者仅引用允许对客且适用的知识。配件建议是准备依据，不能代替实际耗用。

**异常：** 删除提示业务引用时保留记录并核查关联单据；不改写历史消除引用。价格缺失或为零应标明待维护，不能解释为免费。

## 3. 维护渠道、服务网络与区域

**入口：** “销售渠道 → 代理商管理／门店管理／销售区域”和“服务网络 → 服务站管理／服务区域”。销售区域与服务区域用途不同，分别配置。

1. 检索组织，核对上下级、名称、启用状态与必要联系方式。
2. 按职责新增或编辑，确认属于渠道还是服务网络。
3. 配置实际负责的行政区域，核对层级及已保存范围。
4. 保存后通过列表、详情或地图复核，以实际保存数据为准。

**交接：** 向客服调度、站点负责人说明新增站点或区域调整，确认人员与排班具备承接条件。资料保存不等于业务已经开放。

## 4. 查询购买、产品与会员

**入口：** “购买信息 → 顾客购买记录／安装码查询”“会员运营 → 会员档案／会员分析”。

1. 按授权范围定位客户或单件商品，核对门店、购买日期及关联服务，区分正式购买与自行申报。
2. 安装码仅用于查询和详情核对；该入口不发码、不修改、不核销、不建单。
3. 查看会员与购买、产品、服务关联；可信商品来源不自动证明保修或免费服务资格。
4. 敏感信息明文、下载及导出须专项权限。归属或权益冲突交客服核验，保留记录编号和依据。

## 5. 服务治理、投诉与人员反馈

1. 在“服务运营 → 服务工单”查询进度与审核结果；兼任客服且有办理权限时才操作。
2. “投诉管理”在总部视角只读，查看列表、详情和历史；跟进及办结交授权客服。
3. “人员反馈”查看问题、联系方式与附件，取得回复权限后记录明确回复。读取和回复分别授权。
4. “服务质量／运营报表”先确认时间、区域等筛选条件和口径，再比较数据。

**结果核对：** 工单办结与抽样回访独立。回访未完成不改写已办结结果；报表附数据时点，不承诺未经测量的提效比例。人员反馈的回复不代表已转需求、知识库或已通知本人。

## 6. 配置服务规则、费用与协议

**入口：** “业务配置 → 服务设置”。客服渠道、服务站分配规则、服务人员分配规则、完工审核规则、费用政策五页签各有独立读写权限。

1. 记录当前配置、修改原因和受影响业务。
2. 按确认政策修改；服务人员分配采用总部统一规则，适用现有及新增服务站，不维护站点例外。
3. 使用智能或 AI 模式前核对候选资源、策略与外部服务条件；AI 完工核对按保存的核对要求执行。
4. 保存后回读，用授权岗位及适用场景复核，再通知使用人员。

**收费边界：** 线下收费链路已有首版，正式收费项目及政策仍待确认，当前按免费业务核对。报价版本、客户同意、实际线下收款分别记录；调价、减免、退款与纠正需专项权限。首版不含在线支付及服务商结算。

服务评价标签、业务标签与用户协议在对应入口维护。演示协议不等于正式生效文本；发布由业务责任人确认内容、对象和生效安排。

## 7. 库存、防窜货与服务权益

总部库存入口为“库存台账／工单耗用”查询。日常入库、领退料、调拨和盘点由有仓储权限的站点岗位办理，总部查询人员不直接补登记耗用。

防窜货查看疑似统计与明细，核对四项依据：是否有购买登记；入库门店与登记门店是否一致；安装地址是否在登记门店销售区域；是否在最下级出库经销商销售区域。审核通过后异步判断，缺少适用资料可能保留未判断；疑似不等于窜货定论。

保修与延保以有效政策、单件产品及人工审核为准。延保提交、审核等动作分别授权，不能审核本人申请。可记录活动或合同依据，但延保活动管理与自动发放尚未开发；延保不等于全部维修免费。

## 8. 交接与常见问题

| 事项 | 接收岗位 | 信息 |
| --- | --- | --- |
| 工单／投诉需办理 | 客服 | 记录编号、问题、现有进度与待核实事项 |
| 本站履约／配件问题 | 服务站 | 工单、人员、配件单据及后续安排 |
| 规则／资料变更 | 业务负责人、使用岗位 | 原因、有效配置、范围与复核结果 |
| 账号／权限问题 | 系统管理员 | 账号、视角、对象、动作与提示，不发送密码 |

### 为什么看得到菜单却没有编辑或导出？

查看、写操作、敏感信息与导出独立授权，先确认职责和数据范围再核对权限。

### 为什么总部不能审批领料或办理投诉？

总部以治理查询为主。仓储需要站点视角与动作，投诉办理需要客服授权；切换视角不会增加权限。

### 疑似或未判断怎样处理？

核对来源、区域和关联记录，组织人工核实并留依据。首版不把外部追溯全接入、正式复核工作流和自动规则治理视为已交付。
