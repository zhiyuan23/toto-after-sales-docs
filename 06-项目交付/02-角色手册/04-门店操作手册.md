# 门店操作手册

面向代理商管理员与门店店员。使用 Web 管理后台“门店业务”视角，登记购买、代客发起安装或维修并查询进度。版本 v0.1 · 2026-10-10 · 业务复核稿；具体环境开放情况须在交付时核对。

## 1. 身份、范围与入口

代理商管理员按授权查看所属门店，店员仅处理当前门店。业务前核对企业、门店及工作视角，切换视角不会扩大数据范围。

| 入口 | 用途 |
| --- | --- |
| 工作台 | 主要待办及常用业务 |
| 顾客购买记录 | 查询购买、新增购买登记、从记录发起服务 |
| 服务工单 | 查看授权门店进度与关联详情 |

不另设安装预约管理、维修管理或脱离购买记录的报修入口。表单可选商品不代表有商品主档管理权限。

## 2. 新增购买登记

**前提与入口：** 有购买创建权限，在“顾客购买记录”点击“新增购买登记”。

1. 先检索顾客及购买资料，核对门店与产品，避免重复。
2. 选择授权门店，填写真实顾客、购买日期、商品、数量及页面必填信息，单件标识按实际填写。
3. 核对联系方式与购买依据后保存。
4. 回读购买、商品实例与门店归属，错误按可用修改流程处理。

**结果：** 正式购买资料满足可信关联条件后可供消费者同步。登记不等于已登录、已安装或所有权益已确认。

## 3. 查询购买与关联资料

1. 按允许条件检索当前门店记录，打开详情查看商品实例、标识、安装及服务。
2. 区分型号与单件商品，核对购买和实际客户。
3. 仅在已授权关联详情查看必要会员信息，不等于获得全量会员或修改权限。
4. 下载、导出及敏感明文分别授权；无权限交职责岗位核实。

**异常：** 消费者同步不到产品先核对手机号、正式记录、归属及绑定，交客服核验，不直接承诺申报商品获得正式权益。

## 4. 发起安装

**前提：** 购买及商品实例有效，有相应创建权限，不存在阻止申请的活动服务或有效安装记录。

1. 打开购买记录，点击“发起服务”，选择本次商品实例。
2. 选择安装，填写真实联系人、地址和期望安排；期望时间不等于确认预约。
3. 核对后提交一次，查看关联工单。
4. 将编号和客户需求交客服受理，查询后续进度。

**结果：** 客服分站、服务站派人，门店不指定服务站或师傅。

**异常：** 已有安装或活动申请先查看原记录。新故障按维修条件处理，不重复安装；改已确认商品、退单或重开预约须另有权限与业务条件。

## 5. 发起维修

**前提：** 有独立维修动作权限，商品符合实际维修条件。

1. 同一“发起服务”入口选择实例，再选择维修。
2. 描述故障、影响及联系方式，按页面提供材料。
3. 核对地址与期望安排后提交，查看服务工单。
4. 由客服核实资格及费用，门店解释当前阶段，不承诺未经确认的免费或到达时间。

安装与维修入口共用，权限、类型和契约分别控制。只有购买登记权限不一定能发起维修。

## 6. 查询进度与客户协同

1. 从“服务工单”或购买详情关联服务检索，核对当前阶段与确认信息。
2. 客户要改联系人、地址或时间，将变化与原工单交客服核实，不重复新建绕过条件。
3. 延误、缺件或投诉记录工单及问题交客服，办结由授权客服办理。
4. 安装完成以有效审核结果为准，不以口头说明或提交材料视为办结。

## 7. 岗位交接与信息保护

| 事项 | 接收岗位 | 信息 |
| --- | --- | --- |
| 安装／维修申请 | 客服 | 购买、商品实例、工单、需求、地址及期望安排 |
| 购买／绑定冲突 | 客服／主档责任人 | 原记录、冲突与依据 |
| 变更／取消／投诉 | 客服 | 原工单、客户意愿、原因与已有安排 |
| 账号范围错误 | 系统管理员 | 账号、企业门店、目标动作及提示 |

客户信息仅用于本业务。凭据、完整地址和手机号不进入演示材料；导出按约定接收人交接。内部测试账号手册不进入对外包。

## 8. 常见问题

### 为什么没有安装或维修独立菜单？

统一在购买记录“发起服务”，后续从服务工单查询。

### 可以直接指定师傅吗？

门店提交客服受理，客服分站、服务站派人，门店没有对应调度动作。

### 同一商品为什么不能再申请安装？

核对有效安装和活动申请；已安装商品按维修条件处理，资料不清交客服核验。
