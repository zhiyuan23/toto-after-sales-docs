# 服务人员操作手册

面向安装、维修及指导服务人员。使用“TOTO客服助手”小程序，查看本人任务、联系预约、履约、处理配件及反馈问题。版本 v0.1 · 2026-10-10 · 业务复核稿；具体环境开放情况须在交付时核对。

## 1. 登录、首次改密与企业上下文

**前提：** 已由服务站建立有效人员资料，取得本人登录手机号与独立初始密码。

1. 使用手机号与密码登录，首次登录按提示强制修改初始密码。
2. 核对当前企业与服务站，进入本人任务；多企业切换须重新认证，不混用旧企业草稿。
3. 在已开放的账号入口修改密码时验证当前密码，完成后按要求重新登录。
4. 使用结束退出本人账号，不共享账号，不把密码填写在工单或反馈中。

**异常：** 登录失败先核对手机号、账号状态和企业，联系服务站或管理员处理。已有账号不会因本次手册生成而重置密码。

## 2. 查看任务、日程与地图

任务按“待处理、待补资料、审核中、历史”等当前类别查看；已开始任务优先展示，勿因排序变化重复开始。退回或改派后的旧记录只读，保留必要历史，不再继续操作。

1. 查看当前任务的服务类型、商品、联系人、地址和下一步动作。
2. 区分已确认预约、期望时间待确认及无日期待安排；日程按真实排班与安排，不从任务数量推断出勤。
3. 地图辅助查看授权任务位置及导航；只使用当前本人／本站可见范围。
4. 开始操作前重新核对任务仍由本人承接，按钮以服务端允许动作为准。

**地图边界：** 不提供连续人员跟踪、多点路线优化或到达时间保证；未授权定位时按页面提示处理。

## 3. 联系与预约

**入口：** 当前任务详情“联系与预约”。现场服务确认上门时间，远程指导确认联系时间。

1. 联系客户，核对需求、地址与方便服务的时间。
2. 选择“客户已确认时间”，填写日期与时间。首次为“确认预约”；已有有效预约为“修改预约”，需填写改约原因。
3. 客户稍后回复或本次未接通时只保存联系记录，不改变预约及任务状态。
4. 缺件或无法联系任务恢复安排时使用“重新预约”，仍在同一表单办理。

**结果：** 查看最新预约及联系记录。改期只在此办理一次，不再到异常处理重复改时间。单次未接通不等于持续无法联系。

## 4. 服务处理与现场准备

**前提：** 当前由本人承接、状态可办理，需求与必要配件已核对。

1. 查看具体型号适用的服务资料与配件建议，确认版本和实际故障，不把建议当作必须更换。
2. 与客户核对产品及服务内容，必要时按当前费用规则记录报价与客户同意。
3. 现场履约按系统要求取得有效定位；定位失败按提示重新获取或联系站点，不能手填坐标替代。远程指导不要求现场定位。
4. 按真实处理填写记录，实际用了什么配件就记录什么，不先凭建议扣库存。

**标识边界：** 当前履约不要求扫码采集 RFID、商品二维码或序列号。工单中的可选安装码不等于现场产品扫码能力已经开放。

## 5. 证据、客户确认与核对提交

服务内容按“服务处理 → 证据与确认 → 核对提交”三阶段整理。

1. 完成真实服务说明和所需材料，确认附件上传成功；上传中或失败不算有效证据。
2. 明确选择客户确认结果。正常情况说明可选，异常确认需填写原因。
3. 检查本次实际耗用、报价版本、客户同意及线下实收，收费动作须具体权限。当前正式收费细则待确认，免费场景也按实际记录。
4. 在核对提交页检查必填与材料，提交一次后回读状态及当前提交版本。

**结果：** 进入审核中后等待授权审核岗处理。通过即工单办结；退回则在待补资料查看具体缺项，补齐并重新提交，不覆盖旧审核结论。

**失败处理：** 草稿按企业、人员、工单及版本隔离。网络或上传失败先检查已保存内容与服务器结果，不重复消耗库存。未完成应收处理会阻止后续审核。

## 6. 领料、退料与个人库存

**入口：** 当前任务配件相关操作或已开放的配件入口；优先核对个人可用库存。

1. 从任务发起领料时固定关联当前工单，选实际配件和正数数量，核对本站可用库存。
2. 全局领料优先关联可用任务；确实无适用任务时按备货规则填原因。网络查询失败不能当成无任务。
3. 领料批准后库存从站点转本人，拒绝或撤回不转移；核对系统数量与实物。
4. 退料只能退个人可用量，待审退料会占用可退数量，批准后返回站点。
5. 实际耗用随服务提交校验，草稿与建议不扣库存。记录中分别查看进行中、已完成、已关闭及真实处理状态。

**价格边界：** 可见配件参考零售价不等于正式报价，不展示成本或虚构总价；未维护价格不代表免费。

## 7. 调拨与配件异常

1. 按可用入口选择发送／接收对象，核对配件、数量、理由及可用量后提交。
2. 按状态分别完成发送出库、接收入库，实物与单据相符后确认。
3. 仅当前允许状态可撤回，先查原记录再重试，避免重复入库。
4. 缺件、数量不足或型号不符先联系站点，必要时办理缺件异常并重新预约，不填写虚假耗用。

**结果：** 领料、退料、调拨及耗用使用各自流程，不能用一种单据替另一种转库存。

## 8. 异常、退回与取消

**入口：** 任务“异常处理”，按当前权限提供客户无法联系、缺少配件、退回服务站重新派人、取消服务。

1. 核对现有预约、服务与配件状态，选择真实异常。
2. 填原因和后续安排；异常入口不修改预约时间。
3. 缺件恢复后在“联系与预约”重新安排；持续无法联系与单次未接通分别处理。
4. 退回站点后由站点重新派人，本人旧任务只读；取消须确认不再继续服务，需恢复联系服务中心。

**限制：** 服务、库存或状态阻止退回时按提示交站点核实，不能自行删除材料或替另一人员继续办理。

## 9. 产品资料与问题反馈

资料入口优先呈现任务相关产品，再查询已开放的全部产品及本站资料。按商品和有效版本看服务指南、故障处理与配件建议，不能把未确认的独立延保资料页当作现有入口；当前任务权益只读。

“我的 → 问题反馈”记录真实问题、联系方式及最多三张图片。避免上传密码或无关个人信息，确认上传后提交，再从“我的反馈”独立列表查看内容与回复。反馈首版待处理／已处理，不保证自动转需求、生成知识或主动消息通知。

## 10. 岗位交接与常见问题

| 场景 | 接收岗位 | 内容 |
| --- | --- | --- |
| 缺件／安排冲突 | 服务站 | 工单、配件、原因、客户意愿及后续安排 |
| 完工审核 | 客服审核岗 | 当前版本、服务、证据、客户确认、实际耗用与费用 |
| 退回重新派人 | 服务站 | 真实原因及已有履约、配件和材料 |
| 登录／业务问题 | 服务站／管理员 | 企业、任务、提示及必要截图，不含密码 |

### 电话未接通要取消吗？

单次未接通留联系记录；持续无法联系才标异常，确认不再服务时再按条件取消。

### 退回后能继续填写吗？

原任务转为只读，由站点安排新承接人。先确认当前承接再操作。

### 提交完成为什么还未办结？

提交进入审核，审核通过才办结；退回补资料需查看本次原因并重新提交。
