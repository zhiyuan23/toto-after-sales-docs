ROLE HANDBOOK

服务站管理员操作手册

面向服务站管理员及取得本站仓储权限的人员。使用 Web 管理后台“服务站作业”视角，承接工单、派人、排班和管理配件。具体环境开放情况须在交付时核对。

适用：服务站管理员v0.1 · 2026-10-10业务复核稿

没有匹配内容，请调整条件或点击重置。

01

本站职责与每日入口

先看工作台的待派人、异常及领退料待办。“本站工单 → 服务工单”默认关注待分配；“工单看板”按人员与 24 小时时段辅助安排，日视图定期刷新，不能当作实时人员轨迹。

业务 入口 边界
工单派工 本站工单 本站承接、派人、改派与异常
人员排班 人员与排班 本站人员、日容量和排班
配件收发 配件库存 按独立权限和单据状态领退调盘
服务支持 服务知识库、服务分析 适用知识及本站质量、报表

服务站不做完工审核，不全量检索消费者会员；跨站分配交授权客服。

02

承接工单与站内派人

前提： 工单已分本站，有派人权限，人员属于本站且有效，满足能力、排班和容量条件。

  1. 打开待分配工单，核对产品、服务类型、地址、联系人、预约及说明。
  2. 查看可用人员及已有日程，按总部统一规则系统分配或授权人工选择。
  3. 保存后回读承接人员、状态与安排，核对人员端可见；无实际回执不写已短信通知。
  4. 改派前核对原人员的履约、配件和费用，满足条件后办理并交接已有进度。
异常：

无人可派先查启用、能力、排班、容量和范围，不擅改其他站点或临时扩大权限。

03

维护人员、容量与排班

入口： “人员与排班 → 服务人员／排班管理”。日容量在人员档案，排班维护实际出勤与可安排时段。

  1. 核对人员企业站点、手机号、能力和状态，避免重复账号。
  2. 维护已确认排班，核对当日出勤与既有预约。
  3. 请假、停用或调整容量前处理已承接任务，保存后复核可分配候选。
  4. 初始密码通过安全渠道给本人，首登强制改密，不在材料存密码。
结果：

人员正确企业可登录，看到本人任务，日程与排班一致。期望时间或无日期任务不是已确认预约。

04

缺件、两级退回与再次安排

人员退回服务站重新派人后，阅读原因与既有材料再安排承接人；原人员历史只读，不能继续履约。

本站无法承接时按状态及配件、服务限制“退回客服重新分站”，提交明确原因与影响。已有库存、耗用和费用不因退回抹掉，先按对应业务处理。

缺件先核对需求及站点、人员可用库存，协调领料或调拨，再由履约人员联系重新预约。单次未接通留联系记录，持续无法联系再按异常办理。审核退回补资料由审核岗说明缺项，站点协助，不代替审核。

05

配件入库与库存查询

入口： “配件库存 → 库存台账／配件入库”，区分站点库存、人员库存和可用数量。

  1. 按配件与单据查询台账及流水，核对可用数量。
  2. 有入库权限时建立单据，填写实物配件、数量和来源，检查重复。
  3. 按页面状态确认，回读单据与库存；草稿不等于已入库。
异常：

单据错误按允许的纠正动作处理并留依据；库存差异交仓储责任人，不改其他记录凑账。

06

领料、退料与工单耗用

  1. 在“领料管理”核对人员申请、工单或备货原因、正数数量及本站可用库存。
  2. 审批通过即从站点转人员库存；拒绝或撤回不发生该次转移，回读两侧数量。
  3. “退料管理”核对人员可退量与待审占用，批准后从人员回站点；已耗用或占用数量不可重复退。
  4. “工单耗用”核对实际已提交耗用，建议配件和草稿选择不代表库存扣减。

实物交接： 按单据型号、数量点收。系统审批与实物交接都核对，不用审批按钮替代点收。

07

调拨与盘点

入口： “调拨出库／调拨入库／盘点管理”，动作分别授权。

  1. 核对发送、接收对象、配件、数量及可用库存后申请。
  2. 分别完成发送方出库、接收方入库，回读各步库存；提交申请不等于完成调拨。
  3. 仅在允许状态撤回或关闭，已接收入库不重复办理。
  4. 按实物与有效单据盘点，记录差异依据，由授权岗位按流程处理。
异常：

重复提交先找原单；保存失败或状态已变先重新读取，不反复收发。

08

知识、质量与岗位交接

知识库按商品和有效版本查询；质量与报表限本站，注明日期及筛选条件。配件档案查基础信息，修改另有写权限。

方向 交接内容
客服 → 本站 工单、需求、产品、地址、预约与资格说明
本站 → 人员 当前任务、联系要求、已有进度、资料与配件
本站 → 客服 不能承接原因与履约、库存、费用影响
本站 → 仓储岗 单据、配件、数量、审批结果与点收要求
09

常见问题

为什么看不到完工审核？

完工由授权客服审核岗办理，服务站查询结果和协助补材料。

有人员为什么不能派工？

查企业站点、状态、能力、排班、容量和工单状态；人员规则总部统一，站点无例外配置。

批准领料还要等出库吗？

领料批准即转移库存，仍须实物交接；调拨则分别出库和入库，不要混用。
