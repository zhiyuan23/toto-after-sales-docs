ROLE HANDBOOK

系统管理员操作手册

面向负责售后账号、角色、授权及平台配置的管理员。使用统一认证与权限平台，按授权进入售后工作视角。业务办理权限和实际环境须在交付时核对。

适用：系统管理员v0.1 · 2026-10-10业务复核稿

没有匹配内容，请调整条件或点击重置。

01

管理职责与系统边界

售后有 Web 管理后台、消费者小程序、TOTO客服助手三个应用。Web 包含总部、客服、服务站、门店四个工作视角，系统管理员不是第五套业务菜单。

统一认证、租户和权限平台复用，售后商品、渠道、门店及服务业务数据独立持有。管理员能管理身份不等于能审批业务、跨组织读数据或调整库存。

02

账号与组织上下文

入口： 授权视角“系统管理 → 用户管理”。售后主档的门店、服务站等在各业务入口维护，账号组织绑定需核对真实业务关系。

  1. 核对人员、所属企业、组织与职责，检索已有账号避免重复。
  2. 按平台提供的流程建立或维护账号，关联正确组织与角色。
  3. 凭据走约定安全渠道，不附在交付 HTML、邮件正文附件清单或演示中。
  4. 登录核对企业、默认视角和实际数据，停用或离职先核对承接任务及交接。

服务人员使用手机号及独立初始密码、首登强制改密；多企业切换重新认证。消费者身份与手机号业务关联不同，不能随意修改身份解决归属问题。

03

角色、视角与功能授权

入口： “系统管理 → 角色管理／菜单与权限”。用户、角色及菜单管理按身份管理门禁开放；业务字典、导入导出模板按各自业务授权。

  1. 根据真实职责选择对应视角，核对菜单查看范围。
  2. 分别授予必需功能、动作和数据范围，避免直接复制高权限角色。
  3. 对审核、派单、投诉办结、库存收发、费用例外、导出及敏感明文单独核对。
  4. 保存后分别用允许账号和拒绝账号验证同一业务，不能只看菜单是否出现。

权限核对： 客服专员不默认派单或审核；服务站无完工审核；总部投诉只读、库存以查询为主；门店不派站不派人。管理员确需兼任业务时另授具体动作。

04

数据范围与多角色验证

对象 应核对的隔离边界
总部与客服 授权区域、队列及租户
服务站 本站工单、人员及库存
门店／代理商 当前门店或授权所属门店
服务人员 当前企业、本人承接与个人库存
消费者 本人产品、订单及对客资料
  1. 登录确认当前企业与组织，准备授权内及授权外对象。
  2. 查询列表与详情，并核对可见按钮和实际请求结果。
  3. 对拒绝对象核对不能读取、修改或下载，记录复现信息。
  4. 切换视角、企业或重新登录后再次确认范围，清除不适用的草稿与旧上下文。

关联会员读取不等于全量会员权限；投诉读取不自动包含原工单读取；表单受限选择器不代表主档管理授权。

05

菜单、参数与导入导出

售后稳定功能注册和视角投影应统一维护，显示位置变化不复制第二套功能。原服务受理、独立门店安装／维修入口等退役能力不重新开放；未完成骨架保持隐藏。

导入导出任务在工作台右上角宽抽屉，模板在总部“系统管理”。导入、导出、下载分别授权。先按模板检查文件、组织与字段，查看任务结果和失败明细；提交文件不等于处理成功，不盲目重复导入。

业务规则在总部“服务设置”五页签，读写分别授权。服务人员规则总部统一；外部 AI、地图和消息服务的密钥及运行配置由项目组按环境管理，不放进公开文档。

06

环境、外部服务与安全交接

  1. 明确本次目标是测试、微信开发版本或正式环境，记录应用版本、部署回执及实际访问入口。
  2. 核对 Web 前后端与两个小程序的发布范围，微信开发上传不等于提审或正式发布。
  3. 核对地图、AI、微信订阅、短信及客服渠道的账号主体、配置、授权和运行证据，配置存在不证明调用成功。
  4. 凭据与密钥单独安全交接，材料仅记录接收岗位、渠道和确认结果。

运维责任： 项目小组继续负责运行维护、问题响应与版本更新，客户资料交付不转移运维责任。部署与数据库操作由对应技术规程执行，本手册不提供密码或生产变更命令。

07

审计、故障与版本协同

  1. 收集应用、环境、账号职责、时间、记录编号、实际动作及错误提示，必要截图脱敏。
  2. 权限问题先查身份、功能、动作与数据范围，业务错误交对应岗位和项目组。
  3. 查可用操作记录及审计结果；审计范围与日志开关以实际配置为准，不宣称所有操作已有完整审计。
  4. 跟踪修复版本与部署证据，再由业务确认结果。代码提交、测试通过或环境发布都不替代业务验收。

备份、恢复、监控和应急安排按正式交付范围逐项确认；已有部署文档不等于已实施备份演练或满足某个 SLA。

08

交接与常见问题

事项 接收岗位 核对信息
新增／变更权限 业务负责人和使用人员 职责、范围、动作及允许／拒绝结果
业务配置调整 对应业务岗 有效配置、影响、时点与复核
环境／外部服务 项目组 环境、版本、回执与未解决事项
离职／停用 组织负责人 任务、凭据、数据及实际接收人
管理员可以自动审批所有业务吗？

不能。身份管理与业务动作分开，业务职责需专项权限与状态条件。

菜单隐藏就算没有权限了吗？

还须验证实际接口、详情和下载拒绝；只看界面不能证明隔离有效。

开发版上传成功就是交付了吗？

不是。还须核对范围、环境、业务验收、材料接收及遗留事项。
