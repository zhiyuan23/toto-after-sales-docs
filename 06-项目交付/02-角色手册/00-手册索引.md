# 角色手册索引

角色手册按完整项目需求组织。本轮仅建立各岗位的写作骨架，后续补充具体操作说明、示例和必要插图。

| 手册 | 面向人员 | 主要内容 |
| --- | --- | --- |
| [总部运营操作手册](01-总部运营操作手册.md) | 总部业务管理、运营及授权只读人员 | 基础资料、顾客与产品、运营分析、服务质量及业务治理 |
| [客服操作手册](02-客服操作手册.md) | 客服主管、客服专员 | 受理核验、工单跟进、授权调度与审核、回访和投诉 |
| [服务站管理员操作手册](03-服务站管理员操作手册.md) | 服务站管理员 | 本站工单、人员排班、派工、配件和异常协同 |
| [门店操作手册](04-门店操作手册.md) | 代理商管理员、门店店员 | 组织与门店上下文、购买登记、代客服务和查询 |
| [服务人员操作手册](05-服务人员操作手册.md) | 服务人员 | 本人任务、预约联系、履约、配件、资料和反馈 |
| [消费者使用指南](06-消费者使用指南.md) | 消费者 | 产品管理、服务申请、进度查询、评价投诉及客服 |
| [系统管理员操作手册](07-系统管理员操作手册.md) | 系统管理员 | 用户、组织、角色、授权、平台配置和审计 |

客服主管与专员共用一本手册，在相关操作中说明岗位权限差异；代理商管理员与门店店员同样按职责区分。授权只读人员在总部手册中说明查看与导出边界。

每本手册按“岗位与入口 → 日常操作 → 岗位交接 → 异常处理 → 常见问题”展开。详细权限引用[完整岗位权限矩阵](../../02-技术设计/09-后台菜单与岗位权限矩阵.md)，流程条件引用[业务流程](../../05-业务流程/00-售后全流程总览.md)。
