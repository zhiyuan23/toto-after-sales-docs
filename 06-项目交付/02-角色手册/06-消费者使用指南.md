# 消费者使用指南

面向购买并使用 TOTO 产品的消费者。通过消费者小程序管理本人产品、申请服务、查询进度和反馈结果。版本 v0.1 · 2026-10-10 · 业务复核稿；具体开放功能以实际使用页面为准。

## 1. 登录与个人资料

1. 按小程序提示登录，需要同步购买信息时完成官方手机号验证。
2. 核对本人手机号和资料；不要使用他人账号申请自己的商品服务。
3. 在个人资料中按需设置性别和完整出生日期等可选信息，保存后查看结果。
4. 修改手机号或发现归属冲突时联系客服核验，不重复建立商品解决归属问题。

**说明：** 账号不以手机号作为永久身份，手机号仅用于经过核实的业务关联。可选资料不应成为正常服务申请的额外前提。首版不把尚未确认的注销、撤回隐私同意流程写成现有操作。

## 2. 添加与查看我的产品

**入口：** 产品管理的添加页面，按当前页面选择同步购买、扫码或手动输入有效码、无有效码申报。

1. 验证手机号后同步正式购买商品，核对型号、单件产品及购买信息。
2. 有有效唯一码时扫描或手动输入，服务端核验后绑定；归属冲突按提示联系客服。
3. 没有有效码时按页面选择商品并填实际购买日期，属于自行申报／待核验，不自动获得正式服务资格。
4. 在产品详情查看购买、安装、服务与保修信息；不把估算展示直接当作权益认定。

**异常：** 同步未找到先核对门店登记手机号及购买资料；安装码与产品标识以核验结果为准，勿上传编造信息。

## 3. 申请安装、维修或指导

**前提：** 本人关联商品有效，满足相应服务条件，没有阻止重复申请的活动服务。

1. 从本人产品查看当前可申请服务；已有进行中服务优先查看原单。
2. 无有效安装记录且符合条件时申请安装；有效审核安装后按条件申请维修。安装资料不明先核验。
3. 填写联系人、完整地址、问题描述及页面要求材料；期望时间由后续联系确认，不等于已预约。
4. 检查后提交一次，在服务记录查看编号及进度。指导仅在商品及服务资格允许时提供。

**结果：** 手机号同步正式购买或有效唯一码绑定的可信商品直接创建服务工单，进入现有分站策略。可信来源不等于免费或保修结论；手工申报商品先完成核验。

## 4. 查询进度、预约与服务结果

1. 从本人服务记录打开订单，核对预约、承接进度与当前状态。
2. 等待服务人员联系并确认安排；需要改期、改地址或取消时通过当前提供的联系渠道说明原单和原因。
3. 现场核对产品及本次处理结果，真实确认完成情况；有费用时先核对报价与同意，再核对线下实际支付。
4. 以审核办结结果查看服务完成，缺件或补资料等情况按当前进度继续协调。

**费用说明：** 正式收费细则仍待确认；首版采用线下收款记录，不提供线上支付承诺。权益、报价及收款不能互相替代证明。

## 5. 评价与投诉

**评价：** 本人审核办结订单可评价一次，分别填写是否解决、评分、适用标签和文字。低分与高分的标签类型不同，按页面最多选择四项；评价不等于投诉，不能重复代填。

**投诉步骤：**

1. 从本人订单进入投诉，写清具体问题与诉求。
2. 核对后提交；同单已有处理中投诉时查看原投诉，勿重复提交。
3. 查看处理中／已办结及对客回复。首版不提供投诉附件上传，内部处理备注不对外显示。

问题未解决时继续联系服务中心并提供原编号，不用重复申请安装或维修代替投诉。

## 6. 智能售后助手与人工客服

**入口：** 首页“帮助与支持”中的智能售后助手，以及实际配置的客服渠道。

1. 选择本人产品，描述真实故障，可按页面参考问题发问。
2. 阅读适用商品的对客常见问题和安全处理建议；不自行拆机或实施不安全操作。
3. 未解决时核对可编辑问题摘要，按资格转维修申请，或复制摘要后联系人工渠道。
4. 提交申请前仍核对产品、地址与问题，不能把对话直接当作已建单。

**边界：** 助手基于适用公开知识匹配及辅助回答，未知问题会转人工，不保证费用、保修或到达时间。客服渠道页面打开不等于消息已经转发或客服已接入。

## 7. 查询服务网点与保修

服务网点按当前城市或主动授权定位查询，核对公开地址、独立客服电话和服务范围。显示距离为位置估算，不是路程或上门时效保证，不进行持续位置追踪。

产品保修展示根据登记购买日期及政策等已有资料计算；缺日期或期限时会有未知提示，不自行推断剩余保修。延保结果以有效办理和审核为准，不能理解为全部维修免费；延保活动入口尚未开发。

## 8. 消息、协同与常见问题

消息提醒受渠道、模板、本人授权及实际发送结果影响，不能保证每次状态变化都会收到。未收到提醒时主动查看本人订单。微信订阅及短信接入的最终交付状态须单独核对，不把设计示意当作已送达。

联系客服时提供产品、订单编号、真实问题与可联系时间，不发送账号密码或无关个人信息。

### 找不到购买商品怎么办？

核对验证手机号与门店正式登记，联系客服核验；无有效码的申报需核实后才能取得对应资格。

### 产品已安装，能再申请安装吗？

有效安装或已有活动服务会阻止重复申请。新故障按维修条件处理，资料不明先核验。

### 助手回答代表官方免费承诺吗？

不代表。权益、费用及时间由适用政策、服务核实和实际确认决定。
