ROLE HANDBOOK

客服操作手册

面向客服主管与专员。使用 Web 管理后台“客服作业”视角，跟进服务工单、异常、完工审核、回访与投诉。具体环境开放情况须在交付时核对。

适用：客服主管与专员v0.1 · 2026-10-10业务复核稿

没有匹配内容，请调整条件或点击重置。

01

岗位权限与每日工作

任务 客服专员 主管／专项办理岗
工单查询、联系与异常跟进 按既有权限与范围办理 按授权办理
分站、跨站改派 默认不授 另授调度动作
完工审核 默认不授 另授审核动作
回访选单与结果登记 两个动作分别授权 两个动作分别授权
投诉跟进 按授权办理 按授权办理
投诉办结、取消恢复 另授 仍须具体动作权限

先看工作台待办，再进入“工单处理”“异常与投诉”“业务查询与知识库”。只读不包含办理；专员不默认显示调度与审核。待办局部更新受账号范围限制，编辑内容须按页面保存。

02

核验工单与服务资格

入口： “工单处理 → 服务工单”。消费者可信商品直接进入统一工单及现有分站策略，旧“服务受理”来源审核已退役。门店申请仍提交客服受理，在统一工单处理。

  1. 检索并打开工单，核对来源、类型、单件产品、联系人、完整地址和当前状态。
  2. 查询购买、安装与关联服务，确认需求和已有活动申请。
  3. 区分可信建单来源与权益：可信不等于保修、免费安装或费用资格已确认。手工申报且待核验商品不能直接取得可信商品权益。
  4. 记录联系与核实结果，缺资料明确由谁补，不虚构购买日期、费用或权益。
结果：

下个承接岗位可据明确资料办理。安装码查询只检索和看详情，不在该页发码或建单。

03

分站、改派与两级退回

前提： 已授调度动作，工单状态允许，目标站点适用且有承接条件。

  1. 查看当前站点、区域、预约与处理记录，确认未被他人更新。
  2. 使用已配置分站规则或授权人工选择，按要求记录原因。
  3. 保存后回读站点及状态，由服务站站内派人。分站不等于人员已接到消息。
  4. 服务站退回客服后，查看原因及履约、配件、费用影响，再按条件重新分站。

服务人员退回站点重新派人是第一层，服务站退回客服重新分站是第二层。状态、服务和配件限制须先处理，不能删除单据规避。

04

联系、预约与异常跟进

  1. 在“服务工单／异常工单”查看预约、沟通和异常，明确下一步责任人。
  2. 单次未接通留联系记录，持续无法联系再按异常处理。
  3. 对缺件、改期和再次上门协调客户与服务站，记录原因及后续安排。
  4. 取消或恢复由专项授权岗位按状态办理；服务人员取消后需恢复时联系服务中心核实。

交接： 工单、异常原因、客户意愿、已确认预约、配件费用影响、接收岗位及跟进时间。没有实际承诺不填写具体到达时间。

05

办理完工审核

入口： “工单处理 → 完工审核”。仅审核岗位办理，服务站不做完工审核。

  1. 打开待审核工单，核对服务处理、证据、客户确认和本次提交版本。
  2. 检查现场定位、材料完整性、实际配件耗用及报价／实收；远程指导不要求现场定位。
  3. 使用智能或 AI 审核时核对配置、保存的要求和辅助结果，缺项写清要补什么，不把建议当作事实。
  4. 按允许动作通过或退回补资料，填写原因并回读结果；旧版本材料不能覆盖新版本结论。
结果：

审核通过即办结；抽样回访独立，不增加第二次人为关闭。应收未完成会影响审核，当前免费场景也须核对适用政策。

06

抽样回访与消费者评价

入口： “工单处理 → 回访管理”，人工选单和结果登记分别授权。

  1. 选取符合条件的已办结工单，核对客户及服务背景，避免重复登记。
  2. 如实记录联系与反馈，未接通不填成满意。
  3. 问题需协同关联原工单交对应岗位，保留回访及业务处理记录。

消费者本人在审核办结订单评价一次。解决情况与评分独立；结合标签与文字查看，不能代消费者填写，也不能把回访当作评价。

07

跟进与办结投诉

入口： “异常与投诉 → 投诉管理”。状态“处理中 → 已办结”，跟进与办结分别授权，列表不展示建立投诉入口。消费者从本人订单提交，同单仅一条处理中投诉。

  1. 查看投诉及历史；原工单详情需另有工单读取权限。
  2. 联系相关岗位，记录处理情况与后续安排。内部备注不对消费者展示。
  3. 有办结权限且满足条件时登记办结说明；仅能跟进时交授权岗位。
  4. 回读状态、历史及消费者可见内容。消费者投诉首版不上传附件。
异常：

已有处理中投诉先查看原记录；退役责任认定动作不能当作办结权限。

08

费用、知识与查询协同

线下收费首版分别记录报价冻结版本、客户同意和实际收款，日常报价不增额外逐单审批。细则仍待确认，当前免费配置不等于正式收费生效。例外调价、减免、退款、纠正交专项岗；首版不含在线支付或服务商结算。

从“业务查询与知识库”查看购买、安装码与适用知识。技术问题交资料维护岗或站点，不要求消费者自行拆机。向客户说明当前阶段、负责岗位和需补信息；未经核实不承诺免费、保修或消息已送达。

09

交接与常见问题

方向 应交接信息
客服 → 服务站 工单、产品、需求、地址、预约及资格核实
服务站 → 客服 重新分站原因及履约、配件、费用影响
审核岗 → 服务人员 当前提交版本、缺项与退回原因
客服 → 总部／专项岗 投诉、政策、费用例外及依据
为什么没有服务受理？

消费者可信商品已直接建工单；门店申请在统一工单受理，不再使用旧来源审核菜单。

已办结但回访未完成，要再关闭吗？

不需要。办结和回访独立，继续办理回访，不改写工单结果。

为什么不能派单、审核或办结投诉？

这些是独立动作，核对职责、状态和数据范围后由管理员补授已确认需要的权限。
