# 配件档案基础资料独立系统首版

日期：2026-09-09
范围：A29 / PRT-001 的安全基础切片

## 需求与边界

- 配件是售后自有 `afs_part` 聚合，不复用或复制蓝鲸数字主系统业务页面与领域逻辑。
- 本切片维护配件编号、名称、工厂、备注、启停和适用品番；配件编号按大小写不敏感唯一。
- 适用品番引用售后自有 `afs_product.id`，采用多对多增量维护；不读取、复制或整行覆盖共享商品。该口径由 [商品与服务独立商品模型纠偏 V3](2026-09-10-商品与服务独立商品模型纠偏.md) 确认。
- 停用配件保留历史和适用品番，可以移除既有关联，不能新增关联；不提供物理删除。
- 图片上传依赖对象存储、文件类型/大小、病毒扫描与访问权限契约；价格涉及币种、精度、生效历史及计价责任；库存涉及不可变流水和并发。这三部分均不在本切片中预留或猜测字段。

## 实现

- 后端新增 `PartCatalogService` / `PartAppService`、命令与查询模型、MyBatis 白名单 SQL、`/api/afterSales/catalog/parts` 查询/详情/新增/编辑/启停接口和 `/{id}/products` 增量关联接口。
- 迁移 `database/20260909_part.sql` 只新增 `afs_part` 与 `afs_part_product`；2026-09-09 经明确授权已执行到测试库 `gaia_wh_init_wzy`，两张目标表创建成功且初始均为 0 行，未写业务数据或角色权限。
- 独立前端 `apps/after-sales` 新增配件档案真实页面，复用原生 `FaPageMain`、`EsSearch`、`EsListToolbar`、`EsTable`、Element Plus 和 `useListPage` / `useCrudDialog`。
- API 权限按 parts 根路径、单条写入、状态和 products 关联分别校验；商品搜索另需 products 查询权限。所有 ID 保持字符串，写命令使用字段白名单和最新 version。
