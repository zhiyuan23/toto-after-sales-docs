# 小程序通用 UI 与示例页面 Spec

- 状态：已验收
- 日期、版本：2026-09-07，v2
- 需求来源：用户于 2026-09-07 直接提出通用样式、布局、配色、登录页、首页、Demo 页、我的页面与 TabBar 导航需求
- 用户确认记录：2026-09-07；确认范围为小程序仓库内的通用 UI 基线与四个演示页面，不包含真实认证和售后业务接口
- 关联材料：`mobile/gaia-after-sales-uni/docs/design-system.md`

## 1. 目标与范围

建立可供后续页面直接复用的移动端 UI 基线，并以登录、首页、组件 Demo 和我的页面验证其完整性。

本期包含：语义化明暗主题、排版、间距、圆角、阴影、动效与通用组件样式；登录表单本地校验；登录提交后切换到首页；首页、Demo、我的三项代码渲染 TabBar；Demo 展示卡片、列表、按钮、标签、输入框与空态；我的页面使用微信头像选择和昵称填写能力，并展示功能菜单。

本期不包含：真实账号认证、Token、权限、接口、业务流程、业务数据、微信发布。

## 2. 角色、流程与页面

| 端与页面 | 使用者与操作 | 加载、空态、失败处理 | 对应验收项 |
| --- | --- | --- | --- |
| 小程序/H5 登录页 | 输入用户名与密码，点击登录 | 空字段就地提示；提交展示加载态；不发网络请求 | UI-01、UI-02 |
| 小程序/H5 首页 | 浏览设计系统介绍，进入组件示例 | 静态说明，不依赖业务数据 | UI-03 |
| 小程序/H5 Demo | 查看并操作通用组件样式 | 操作使用本地 Toast；空态包含下一步 | UI-04 |
| 小程序/H5 我的 | 选择头像、填写昵称、浏览功能菜单或退出登录 | 微信端使用原生填写能力；资料仅保留在当前页面；菜单未接业务时使用 Toast；退出后重置页面栈到登录页 | UI-07 |
| 代码渲染 TabBar | 在首页、示例和我的之间切换 | 当前项 MDI 图标、文字高亮 | UI-05 |

## 3. 接口、数据与权限契约

本期没有接口、服务端数据或权限变更。登录页明确标注为界面和导航演示；登录信息不得持久化或发送到网络。我的页面通过微信原生能力取得头像临时地址和用户主动填写的昵称，仅在当前页面内预览，不上传或持久化。

## 5. 验收场景

| 编号 | 前置状态与身份 | 操作 | 可观察的预期结果 | 验证层级 |
| --- | --- | --- | --- | --- |
| UI-01 | 打开应用 | 查看启动页 | 展示标识、标题、用户名、密码和登录按钮；布局适配安全区 | H5 视觉/微信构建 |
| UI-02 | 登录页字段为空 | 点击登录 | 两个字段分别出现明确错误；填写后提交进入首页 TabBar | H5 交互 |
| UI-03 | 首页 | 查看内容并点击组件样式入口 | 首页遵循全局令牌，入口切到 Demo Tab | H5 视觉/交互 |
| UI-04 | Demo 页 | 滚动并操作组件 | 展示色彩、卡片、按钮、状态、列表、输入框和空态，操作有反馈 | H5 视觉/交互 |
| UI-05 | 首页、Demo 或我的 | 点击 TabBar | 在三个顶级页面间切换并正确高亮 | H5 交互/微信构建 |
| UI-06 | 系统暗色或减少动态效果 | 打开页面 | 明暗主题可读，减少动态效果时移除非必要过渡 | 静态检查/H5 视觉 |
| UI-07 | 微信小程序我的页面 | 点击头像、昵称或退出登录 | 白色资料卡聚合头像与昵称，无区块标题和冗余表单控件；调用 `chooseAvatar` 与 `nickname` 原生能力；退出登录清空当前页面资料并通过 `reLaunch` 返回登录页 | 微信构建/H5 交互检查 |
