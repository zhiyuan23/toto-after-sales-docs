# 工作台导入导出任务抽屉

日期：2026-09-25。用户已确认执行；源码与本机研发验证完成，未提交 Git，未发布共享应用，不增加业务验收计数。本记录取代此前“导入导出任务固定侧栏底部”的展示方案。

## 交互与实现

- 总部、客服、服务站、门店四个工作台右上角提供低强调文字按钮「导入导出任务」，不占侧栏、不设置常驻状态徽标。
- 点击打开右侧 88vw、全高抽屉，标题与关闭按钮在顶部。关闭按钮、Esc 或遮罩关闭后，原工作台路由、筛选和办理状态保持，不产生新页签。
- 抽屉按需加载已有任务能力。复用 `EsSearch`、`EsTable` 和 `useListPage`；筛选区在上方，表格填满剩余高度、内部滚动，分页在底部。原列表已有通用组件，本次修复的是外层高度链，并拆分为 `index.vue + components + model + schemas`。
- 关键词、类型、状态查询，重置、分页、状态说明、结果文件下载继续使用原接口。单次筛选／重置／翻页只发一次列表请求；关闭不销毁列表，在同一工作台再次打开时保留草稿、已应用筛选和页码并刷新。离开或切换工作台后重新初始化，不做跨账号持久化。
- 权限加载失败或列表失败提供重试。下载同时检查资源下载权限和服务端行级 `actions`；成功和失败提示沿用通用顶部消息。
- 原 `/downloadCenter/task` 直达路由继续作为兼容入口，复用同一列表，仍受授权守卫。正常工作台操作不跳转该路由。

## 权限与菜单联动

任务功能仍是原 `afsDownloadTask`／`afterSales/downloadCenter/task`，四视角由侧栏分组引用改为 `contextCodes`。工作台按钮必须有认证菜单树返回的有效、精确功能授权；工作视角授权或管理员名称不自动授予任务能力。前端允许该隐藏内嵌模块参与授权解析，但缺失、停用、路径不匹配及无工作视角仍拒绝。后端权限和仅查看本人任务的数据范围不变。

测试库 `gaia_wh_init_wzy` 原任务模块 `2026090800000065` 的 `is_hide` 从 0 调整为 1，保持名称、路径、父级、ID、API、角色模块和按钮关系。已在事务前备份，回读验证完成，四组权限关系和身份字段摘要前后相等。
