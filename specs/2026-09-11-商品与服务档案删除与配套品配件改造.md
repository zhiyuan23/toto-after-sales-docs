- 日期、版本：2026-09-11 / V1
- 应用载体：Web 管理后台
- 角色视角：总部运营、管理员
- 业务模块：售后服务 / 商品与服务
- 入口与需求：A08 商品分类、A09 商品档案、A10 商品系列、A12 配套品档案、A29 配件档案
- 需求来源：`售后服务第二版.docx` 及 2026-09-11 用户补充确认
- 用户确认记录：按文档改；商品档案删除允许级联删除子数据；商品分类有下级分类时提示“请先删除下级分类”；商品系列的关联商品和启停仅从前端列表操作中去掉；新增 `delete` 权限并配置数据库。
- 关联材料：[商品与服务独立商品模型纠偏 V3](2026-09-10-商品与服务独立商品模型纠偏.md)

## 1. 目标与范围

本次在已完成独立商品模型基础上补齐第二版文档中的商品与服务变更：

- 商品分类、商品档案、商品系列增加物理删除入口，均要求二次确认。
- 商品分类存在下级分类时不允许删除，返回“请先删除下级分类”；分类下有关联商品时不允许删除，提示先删除关联商品。
- 商品档案物理删除时级联清理商品图片、故障及维修、安装手册、配套品关联、配件关联等售后子数据。
- 商品系列前端列表操作去掉“关联商品”和“启用/停用”，保留编辑后新增删除；后端原有关联和状态能力保留兼容，系列下有关联商品时不允许删除。
- 配套品管理调整为配套品档案，独立维护配套品主档和关联产品，不再沿用商品之间的配套关系。
- 配件档案补齐品牌、成本价、零售价、机型、包装尺寸、毛重、净重、功能说明、图片和关联产品页签。

本次不把写接口合并到菜单读取权限；删除仍使用按钮/API 权限控制。

## 2. 页面与业务行为

| 页面 | 本次行为 | 异常处理 |
| --- | --- | --- |
| 商品分类 | 列表操作新增删除按钮；点击后二次确认；成功后刷新列表。 | 存在下级分类时提示“请先删除下级分类”；存在商品档案时提示先删除关联商品。 |
| 商品档案 | 列表操作新增删除按钮；点击后二次确认；后端物理删除商品并级联售后子数据。 | 版本不一致、权限不足或记录不存在时按后端业务错误提示。 |
| 商品系列 | 列表操作只保留编辑和删除；去掉关联商品、启用/停用入口。 | 系列下有关联商品时提示先解除关联商品后再删除系列。 |
| 配套品档案 | 新增/编辑弹窗分为“基础信息”和“关联产品”页签；维护编码、名称、品牌、成本价、零售价、机型、包装、重量、功能说明、备注、图片和关联产品数量。 | 编码、名称、成本价、零售价必填；金额限制两位小数；关联产品数量为正整数。 |
| 配件档案 | 弹窗结构与配套品档案一致，文案使用配件；关联产品改为页签内统一维护。 | 同配套品档案。 |

关联产品弹窗支持按商品编码/名称、分类名称/编码、系列名称/编码筛选，可多选商品；加入后默认数量为 1，数量可编辑，行可删除。

配套品和配件的新增／编辑均复用 `EsFormDialog` 大尺寸响应式弹窗，基础信息与关联产品 Tab 固定在内容区顶部；图片统一使用 `EsImageUpload`，上传期间锁定关闭与提交，并保留进度、失败重试、预览、下载和删除交互。嵌套的关联商品选择器同样使用公共弹窗壳，不另设固定像素宽度或原始 `el-dialog` 例外。

## 3. 接口、数据与权限契约

| 方法与路径 | 用途 | 权限 |
| --- | --- | --- |
| `DELETE /api/afterSales/catalog/categories/{id}` | 物理删除商品分类 | `afsProductCategory.delete` |
| `DELETE /api/afterSales/catalog/products/{id}` | 物理删除商品档案并级联售后子数据 | `afsProduct.delete` |
| `DELETE /api/afterSales/catalog/series/{id}` | 物理删除商品系列 | `afsProductSeries.delete` |
| `GET /api/afterSales/catalog/products` | 商品选择弹窗列表，新增分类/系列关键词筛选 | 商品档案读取权限 |
| `POST/PUT /api/afterSales/catalog/bundles` | 保存配套品档案及关联产品 | 配套品档案写权限 |
| `POST/PUT /api/afterSales/catalog/parts` | 保存配件档案及关联产品 | 配件档案写权限 |

数据库迁移：

- `20260911_catalog_bundle_part_v2.sql`：新增 `afs_product_bundle_item`、`afs_product_bundle_product_relation`，并扩展 `afs_part`、`afs_part_product_relation`。
- `20260911_catalog_delete_permissions.sql`：将 `afsProductBundle` 菜单名称改为“配套品档案”，新增分类、商品、系列三个 `delete` 操作，并为超级管理员角色授予对应按钮权限。
- `20260911_catalog_delete_permissions.rollback.sql`：删除本次新增按钮授权和操作权限，菜单名称恢复为“配套品管理”。
