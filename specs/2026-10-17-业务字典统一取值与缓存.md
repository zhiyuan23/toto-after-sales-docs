## 1. 范围与数据边界

| STORE_BUSINESS_STATUS | 门店营业状态；与启用／停用分开 | 现有门店营业状态去重 |

工单／单据状态、服务类型与技能、收费／保修／派单规则、评价结果、标签独立模块及原因分类不在本次范围。街道原有字典节点与允许手工补充的规则保留；不将本次省市区统一称为全国完整街道数据迁移。

业务记录保留既有编码，不批量覆盖历史商品、门店、偏好或投诉快照。配置名称用于当前选项及展示；业务事件本身的历史主题／说明保持原记录。前端不再用旧偏好／投诉常量白名单拒绝新增字典编码；后端负责校验有效选择，前端继续校验响应结构、长度、重复值、账号和版本。

## 2. 读取、认证和版本

统一地址：`GET /api/afterSales/business-dictionaries?code=STORE_TYPE&version=<上次版本>`。

响应沿用 Gaia 包装，data 为 `code / version / unchanged / items`。每项包含 `code / name / parentCode / itemLevel / ordinal / enabled`；返回全部层级及停用项供历史展示，客户端新选择仅使用启用项。该读取独立于字典管理权限，仅向已认证调用者开放以上九个明确编码，不暴露任意平台或私有字典。

- 宿主精确地址使用 `afsDictionary` 认证过滤器：后台委托现有 Gaia 认证，两种小程序分别验证既有会话；拒绝匿名、失效会话及写方法。相邻地址继续走既有认证链。WAR／可执行 Jar 同步，Controller 在读租户数据前再次核对身份和租户；后台使用当前租户，小程序沿用既有单租户约束。
- 不增加匿名字典路由，不修改其他接口认证策略。消费者无需登录的商品发现详情在既有只读接口中投影颜色名称，不开放匿名字典查询。
- 版本由字典及所有字典项的编码、名称、排序、状态、层级和修订计算；相同版本只返回 `unchanged=true` 及空 items，客户端复用原快照。查询覆盖全部项，不沿用旧管理选项接口的100项上限。
- 服务端通过租户路由读数据库，不使用跨租户 JVM 静态缓存。版本与项快照在只读可重复读事务中读取。响应 HTTP `Cache-Control: no-store`，由受控客户端缓存管理有效期。

## 3. 客户端缓存与更新

Web 与两个小程序使用等价的纯缓存算法，内存保存，默认有效期30秒，同字典并发请求合并。Web 按登录凭据隔离；小程序按账号、会话和认证上下文隔离，服务人员切换企业额外立即清空。账号变化、退出和显式失效会清空快照及未完成请求；迟到响应不能恢复旧账号数据。失败不延长有效期，不缓存失败 Promise，可重试。

Web 字典写入取得成功响应后立即失效本窗口缓存，通过 storage 事件通知其他窗口；使用中的页面重新读取，窗口聚焦及可见期间每30秒检查版本。小程序恢复前台和处于前台时每30秒检查已使用字典；首次进入业务页按需加载。后台修改后，小程序在下一次有效期检查或重新进入页面时更新，不承诺跨设备零延迟推送。失败保留已有可读内容，新选择及保存仍受后端实时校验。

门店筛选、列表／卡片和会员分析图表的配置标签从响应式缓存读取，名称修改后随缓存刷新更新；统计人数仍按页面查询更新。表单提供选项加载／失败重试。平铺字典停用项不再作为新选择；已保存的停用值允许原值保留、展示和主动移除，不因编辑其他字段被清空。后台会员统计包含停用历史编码和新增编码，继续验证矩阵维度与计数一致性。

## 4. 配置保护与迁移

已经接入业务的九个字典编码及其既有字典项编码不能修改；字典及字典项不能物理删除，通过停用保留引用。名称、排序与启停继续可维护。对应管理列表不提供受保护项的删除动作，编辑时编码只读；服务端独立执行保护。

- 初始化脚本：[20261017_business_dictionary_integration.sql](../../../backend/gaia-after-sales/database/20261017_business_dictionary_integration.sql)。显式执行，可重复运行；不在启动时自动建表或写配置，不覆盖已维护名称、状态和排序，不写业务表。
- 行政区省直辖县级市会在市／区两级复用同一标准编码。字典内部以 `:DISTRICT` 区分同码区级节点，父子关系使用字典身份；对业务选择器和后端行政区校验仍输出原标准编码，避免改变现有地址契约。
- 已核实本地运行配置连接测试库 `gaia_wh_init_wzy`。执行前将原字典两表备份到已忽略 `.local/verification-artifacts/20261017-business-dictionaries/`。首次预执行发现跨层重复编码，在临时表阶段失败并回滚，修正后完成。
- 初始化后：9类／3386项；行政区3342、投诉8、产品兴趣7、购买计划5、使用场景3、颜色1、单位3、营业状态2、门店类型15。门店626条、商品13条保持；没有改写业务记录。
- 应用回退保留新增字典，不自动删除。确需数据恢复时依据备份对比新增项和层级修正，先核对后续引用及修改版本；不通过整表覆盖回退并发配置或业务数据。
