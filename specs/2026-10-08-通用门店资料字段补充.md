## 字段与映射

门店类型沿用 `storeTypeCode`，旗舰店／精品店均为类型取值。名称、省市、地址、GCJ-02坐标及营业状态沿用主档；电话、营业时间沿用对客配置。工商资料、归属与内部启用状态保留。

新增可选对象 `profile: StoreProfile`，落在售后自有 `afs_store` 的11列：

| API字段 | 数据列 | 官网来源／规则 |
| --- | --- | --- |
| starred | is_starred | stars：星级店标识；true/false/null，null表示未提供 |
| remodel | is_remodel | isRemodel：保留原始导入标识，不展示，不推导服务能力 |
| intro | store_intro | intro：门店简介，最多2000字符 |
| remarks | official_remarks | remarks：通用门店备注，最多2000字符，与到访说明独立 |
| fax | fax | 历史导入值保留，最多100字符；编辑和详情均不展示 |
| imageUrls | store_images | images：有序URL数组，JSON文本，最多20项，每项2048字符；独立于PDF资质附件 |
| mapAddress | map_address | map_address：最多500字符，与业务地址独立 |
| cityEn | source_city_en | city_en：最多100字符，内部来源查询标识，不展示，不代替行政代码 |
| sourceSystem | external_system | 内部追溯来源系统，最多50字符，不展示 |
| sourceStoreId | external_store_id | 原始store_id含后缀，最多100字符，不作为全局主键或唯一键，不展示 |
| sourceUrl | external_source_url | 内部追溯来源页面，最多2048字符，不展示 |

已有 `source=web` 保留创建／编辑入口含义，不覆盖为官网归属。图片URL接受HTTP/HTTPS或站内单斜杠路径；来源页面仅HTTP/HTTPS；拒绝脚本协议、协议相对URL和含用户密码的URL。后台文本按普通文字展示。

## 实现与边界

- 门店新增／编辑／列表／详情沿用现有权限、组织范围、事务与乐观版本。新字段参与版本指纹；不新增菜单或操作授权。
- 请求不含 `profile` 时，已有记录的门店资料保持；传入对象则整组替换，空对象显式清空。现有CSV主档导入不新增官网列，也不会清除已有门店资料。
- 通用资料合并到现有“基本信息”：经营属性展示星级店标识，地址与位置展示地图地址，简介／备注／图片统一维护；详情全部归入概览。去掉“官网资料”页签和品牌专用DTO，以 `profile: StoreProfile` 承接资料。传真及来源城市／编号／URL／Remodel不在日常表单或详情展示，常规编辑保留内部元数据；复用图片上传与相册，上传期间禁止保存及关闭，中英文同步。
- `closed`对应营业状态，与内部enabled不同；坐标继续按百度→高德转换；本次不重复新增已有字段。
- 迁移为 `gaia-after-sales/database/20261008_store_official_profile.sql`，仅增加可空列，应用启动不改表；旧记录不推断标识。应用回退保留列和新数据，见同目录rollback说明。
