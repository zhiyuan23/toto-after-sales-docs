1. 代理商有下级时不能修改层级或所属代理商。

3. 2026-09-11 首版地图能力只保留经纬度预览；2026-09-14 补充服务站单地点的地址搜索与地图选点，服务区域地图围栏仍属于后续版本。
4. 字典管理为售后自建模块，放到数据中心下，并配置菜单、角色和 API 权限。
5. 门店类型允许新增第 4 种，自建字典支撑；渠道页面仍按现有主体处理。
6. 服务区域与服务站关系改为在服务站侧维护，保留优先级字段。
7. 保留启用/禁用，同时新增物理删除按钮和后端受限删除。
8. 服务站满意度本期暂为空；家装公司本轮不改。

## 2. 实现摘要

- 后端新增/扩展代理商、门店、服务站、服务区域 CRUD、启停、物理删除、乐观版本和审计；代理商/门店切换为售后自有主档写入。
- 工商信息拆为结构化字段，代理商、门店、服务站共用附件表；证照类附件限制单个 PDF，其他附件可多个。
- 服务站新增热线、服务项目、行政区划、经纬度、工商信息、附件和服务区域优先级绑定。
- 代理商、门店、服务站和服务区域的省／市／区县统一为可搜索的单个级联控件，行政区快照首次展开时加载；街道保留字典选择和手工录入。
- 服务站可通过高德地图搜索建议、地图点击和拖动标记回填省市区、街道、详细地址与经纬度；父表单保留行政区、街道和详细地址修正，移除经纬度手输与重复的位置预览，仅在完成定位后显示紧凑坐标状态。未配置地图环境变量时保留地址手工录入，坐标允许未设置。服务区域保留省/市/区县/街道行政区域维护，不再从区域侧绑定服务站；由于当前表达的是覆盖范围且没有围栏几何模型，不接入会误导为覆盖范围的单点选择器。
- 新增数据中心 `字典管理`，接口前缀为 `/api/afterSales/data-center/dictionaries`，支持字典和字典项 CRUD、启停、删除、选项查询。

- 本地管理员 `data_auth_org_type=GLOBAL` 的组织数据范围已兼容渠道主档查询；非全局用户仍按 `sys_user_data_permission` 和 `afs_dealer_organization` 收敛。

## 9. 高德地图临时部署口径与上线前整改（2026-09-15）

- 当前开发及内部临时部署继续使用最快接入方式：仓库已跟踪的 `apps/after-sales/.env` 直接配置开发用 `VITE_AMAP_KEY` 与 `VITE_AMAP_SECURITY_JS_CODE`，同事拉取代码后无需创建本地环境文件即可启动或构建。两项配置会进入 Git 历史和浏览器可读取的前端产物，只允许使用可公开、可轮换且已限制适用域名的开发凭据，不得替换为生产凭据。
- `.env.local` 继续保持 Git 忽略，只用于个人的其他临时覆盖；当前地图能力不再依赖每台开发机或流水线单独分发高德配置。开发凭据可支持的访问域名仍以高德控制台的实际限制为准，部署到未授权域名时不能据此判断程序异常。
- 正式上线前必须完成 [TECH-20260915-01](../03-开发管理/07-后续开发与交互优化待办.md#tech-20260915-01)：生产 Web Key 绑定正式域名，Security Code 迁移至 Nginx／网关等服务端私有配置，前端通过同源 `/_AMapService` 使用代理，从已跟踪的 `.env` 移除开发凭据及前端 `VITE_AMAP_SECURITY_JS_CODE`，并轮换当前公开的开发 Security Code。正式产物不得包含 Security Code，且需复验地址搜索、地图选点、地理／逆地理编码及无地图时的手工录入降级。

- 本次只调整开发配置交付方式并同步上线前工作，不修改地图运行逻辑或业务完成度，也不构成正式生产安全验收。
