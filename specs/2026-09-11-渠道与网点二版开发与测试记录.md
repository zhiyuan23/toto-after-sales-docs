## 1. 确认口径

1. 代理商有下级时不能修改层级或所属代理商。
2. 工商信息页签均非必填；附件仅支持 PDF，上传逻辑参考既有知识库/通用附件能力。
3. 2026-09-11 首版地图能力只保留经纬度预览；2026-09-14 补充服务站单地点的地址搜索与地图选点，2026-09-15 将同一交互应用到代理商和门店；服务区域地图围栏仍属于后续版本。
4. 字典管理为售后自建模块，放到数据中心下，并配置菜单、角色和 API 权限。
5. 门店类型允许新增第 4 种，自建字典支撑；渠道页面仍按现有主体处理。
6. 服务区域与服务站关系改为在服务站侧维护，保留优先级字段。
7. 保留启用/禁用，同时新增物理删除按钮和后端受限删除。
8. 服务站满意度本期暂为空；家装公司本轮不改。

## 2. 实现摘要

- 后端新增/扩展代理商、门店、服务站、服务区域 CRUD、启停、物理删除、乐观版本和审计；代理商/门店切换为售后自有主档写入。
- 工商信息拆为结构化字段，代理商、门店、服务站共用附件表；证照类附件限制单个 PDF，其他附件可多个。
- 服务站新增热线、服务项目、行政区划、经纬度、工商信息、附件和服务区域优先级绑定。
- 代理商、门店、服务站和服务区域的省／市／区县统一为可搜索的单个级联控件，行政区快照首次展开时加载；街道保留字典选择和手工录入。
- 代理商、门店和服务站统一通过高德地图搜索建议、地图点击和拖动标记回填省市区、街道、详细地址与经纬度；父表单保留行政区、街道和详细地址修正，移除经纬度手输与重复的位置预览，仅在完成定位后显示紧凑坐标状态。未配置地图环境变量时保留地址手工录入，坐标允许未设置。服务区域保留省/市/区县/街道行政区域维护，不再从区域侧绑定服务站；由于当前表达的是覆盖范围且没有围栏几何模型，不接入会误导为覆盖范围的单点选择器。
- 新增数据中心 `字典管理`，接口前缀为 `/api/afterSales/data-center/dictionaries`，支持字典和字典项 CRUD、启停、删除、选项查询。
- 菜单与权限新增 `afsDictionary`，并补齐代理商、门店、服务站、服务区域、字典及字典项的按钮/API 权限。
- 本地管理员 `data_auth_org_type=GLOBAL` 的组织数据范围已兼容渠道主档查询；非全局用户仍按 `sys_user_data_permission` 和 `afs_dealer_organization` 收敛。

## 10. 公共售后主键生成职责修复（2026-09-15）

- 问题表现：新增代理商在业务字段校验和数据库写入前返回 `Unsupported after-sales ID sequence: afs_dealer`。该问题与请求内容、数据库数据及 Redis 序列高水位无关。
- 根因：商品目录策略 `CatalogPolicy` 错误继承公共 `IdGenerator`，其目录表白名单因而成为所有售后领域唯一的主键生成实现，代理商、门店、服务站、服务区域、字典、工单等非目录表会被确定性拒绝。
- 修正：解除 `CatalogPolicy` 与公共 `IdGenerator` 的继承关系；新增独立 `GaiaIdGenerator` 作为非目录售后领域的公共实现，统一委托 Gaia 按表 Redis 主键生成器，并只允许安全的 `afs_[a-z0-9_]+` 序列名。商品目录仍保留自身白名单、高水位检查和审计重试，不把非目录表逐项补入目录策略。
- 测试夹具同步提供独立的公共 `IdGenerator`，避免继续依赖目录测试策略隐式兼任公共主键组件。
