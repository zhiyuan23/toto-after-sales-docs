# 代理商与门店权威主档只读首版

> 2026-09-11 数据契约更正：代理商、门店及类型须使用售后自有主档和业务归属；Gaia/DWH 主系统主档只读方案已失效。 现源码已完成本项独立化并通过隔离研发验证，目标环境迁移及业务验收待完成；下文实现、迁移和验证仅记录原时点事实。最新约束与源码证据见[独立边界核查](2026-09-11-业务数据独立边界与已开发功能核查.md)。

- 日期：2026-09-09
- 对应入口：A03 代理商管理、A04 门店管理
- 需求依据：ADM-MD-001、ADM-MD-002
- 状态：部分开发中；权限范围内的查询、筛选、分页和详情闭环完成，写入、同步、完整状态与业务标识仍待确认

## 1. 已确认边界

1. 本次以售后独立系统为主，不复制或运行时导入蓝鲸数字主系统页面，也不调用同时暴露新增、修改、删除、启停的 legacy 主档 AppService。
2. 当前 Gaia 主数据制品和 Mapper 明确存在 `md_customer`、`md_store`、`md_store_type`；代理商、门店继续以这些 Gaia/DWH 主档为权威来源，不在售后新建副本表。
3. 售后首版只读：代理商支持 SAP 编号/名称、主档状态筛选、分页和详情；门店支持编号/名称、所属代理商、主档状态、权威营业状态原值筛选、分页和详情。
4. 每个请求先校验售后 GET API 权限和有效租户；SQL 再通过 `sys_user_data_permission → sys_organization_relation → md_customer` 限制当前用户组织数据范围。门店必须属于当前可见代理商；权限关系缺失时默认不返回。
5. BIGINT ID 全程使用字符串。筛选长度受限、通配符按普通字符转义；详情对“不存在”和“越权”统一返回 404，不暴露记录是否存在。
6. 不展示负责人手机号等敏感字段；缺少脱敏/可见范围契约时不以“详情页”名义扩大数据暴露。

## 2. 主动未实现

- 不新增、编辑、删除、启停或整行覆盖 `md_customer`、`md_store`。
- 不新增 DWH 同步任务、导入、冲突合并或人工覆盖字段。
- 不把截图出现的“取消授权、未营业、已营业、关店”等样例当作完整状态枚举；当前显示和筛选权威 `active_state` 原值。
- 不实现直营/经销、线上/线下/内购虚拟门店的完整分类语义、实体/非实体性质、送安一体和联系方式写入；这些字段责任和枚举仍需 DWH/主数据负责人确认。
- 不创建默认全部组织、万能角色、生产白名单或售后数据范围旁路。

## 7. 表格关联跳转增强（2026-09-10）

- 选定“门店管理”的“所属代理商”作为首个关联跳转：使用门店列表已有的字符串 `dealerId`，跳转命名路由 `afsDealer` 并携带 `dealerId` 查询参数，由代理商页打开既有只读详情弹窗，没有新增后端接口或虚构详情页。
- 只有代理商读取 API 已授权、代理商菜单可达且关联 ID 合法时才渲染真实链接；缺权限、缺菜单或缺 ID 时降级为普通文本。路由参数继续按字符串校验，避免 BIGINT 精度损失。
- 关闭详情后通过 `router.replace` 清除已消费参数；地址直达、刷新恢复、浏览器返回、键盘访问和新标签打开由真实路由链接语义支持。
- 通用表格新增声明式 `TableColumn.link`（`to`、`visible`、`ariaLabel`）和统一链接单元格，业务页面不得重复实现跳转样式或点击逻辑。约束已同步至 UI 规范和 AI 开发执行规范。
- 验证证据：79 项前端测试全部通过，`vue-tsc -b` 和 production build 通过；9013 隔离 H2 浏览器实测两条门店记录均展示真实代理商链接，点击 `dealerId=8001` 打开“华东服务代理商”详情，关闭后清参，浏览器返回恢复门店列表。共享环境无代理商/门店业务数据，因此未用共享数据重复该点击链路。
