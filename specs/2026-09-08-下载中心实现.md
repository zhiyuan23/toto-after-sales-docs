## 1. 目标与范围

本期在 Web 售后服务下新增“下载中心”分组，包含任务中心、模板管理、场景配置三个页面。功能参考 WMS 的导入导出中心，但不复制 RuoYi 菜单模型；Gaia 的 `sys_module` 与 `sys_module_operation` 仍是菜单和按钮的权威来源。

本期包含：当前账号任务列表和结果下载；模板新增、编辑、启停、版本上传、激活、下载；场景配置按售后菜单树动态展示二级及下级菜单，并把菜单或按钮绑定到模板管理维护的模板。

本期不包含：具体业务模块发起导入/导出任务、Excel 解析/生成引擎、自动清理任务、真实对象存储或杀毒扫描。后续业务页面接入下载中心时，再按场景调用模板与任务记录能力。

## 2. 角色、流程与页面

| 端与页面 | 使用者与操作 | 加载、空态、失败处理 | 对应验收项 |
| --- | --- | --- | --- |
| Web / 任务中心 | 管理或业务用户查看自己的导入导出任务，成功任务下载结果文件 | 无权限显示错误提示；无任务显示空态；失败任务显示说明 | A56 |
| Web / 模板管理 | 管理用户维护模板基础信息，上传 Excel 模板版本，设置当前版本 | 版本号重复、文件类型错误、无权限均由后端返回业务错误 | A57 |
| Web / 场景配置 | 管理用户在左侧售后菜单/按钮树中选择节点，右侧绑定启用模板 | 菜单树来自后端动态源；新增按钮随 Gaia 菜单按钮配置进入可选范围 | A58 |

## 3. 接口、数据与权限契约

| 方法与路径 | 调用端 | 请求与响应、类型及必填约束 | 错误语义 | 身份、租户与资源权限 |
| --- | --- | --- | --- | --- |
| `GET /api/afterSales/downloadCenter/permissions` | 三个页面 | 返回任务、模板、场景的按钮能力 | 未登录返回 4001 | 只读取当前登录身份 |
| `GET /api/afterSales/downloadCenter/tasks` | 任务中心 | `page/pageSize/keyword/taskType/taskStatus`，返回 `PageResponse` | 分页或枚举非法返回 422 | 后端只返回当前用户创建的任务 |
| `GET /api/afterSales/downloadCenter/tasks/{id}/download` | 任务中心 | 下载成功任务结果文件 | 非本人任务 404；未成功任务 409 | 需要任务下载 API 权限 |
| `GET/POST/PUT /api/afterSales/downloadCenter/templates` | 模板管理 | 模板编码、名称、备注；编辑带 `version` | 编码重复 409；版本冲突 409 | 模板读写权限分离 |
| `POST /api/afterSales/downloadCenter/templates/{id}/versions` | 模板管理 | `multipart/form-data`，字段 `file/versionNo/changeLog/active`；仅允许 xls/xlsx | 文件类型、大小、版本号非法返回 422 | 需要版本上传权限 |
| `PUT /api/afterSales/downloadCenter/templates/{id}/versions/{versionId}/activate` | 模板管理 | 设置当前模板版本 | 模板或版本不存在 404 | 需要版本维护权限 |
| `GET /api/afterSales/downloadCenter/templates/{id}/versions/{versionId}/download` | 模板管理/场景联调 | 下载模板文件 | 文件缺失 404 或 503 | 需要模板下载权限 |
| `GET /api/afterSales/downloadCenter/scenes/tree` | 场景配置 | 返回售后菜单和按钮树，节点合并已配置模板信息 | 菜单源不可用返回业务或数据错误 | 需要场景读取权限 |
| `PUT /api/afterSales/downloadCenter/scenes/configs` | 场景配置 | 保存所选菜单/按钮与模板的绑定；已有配置带 `version` | 节点不在当前动态树返回 422；模板停用返回 422 | 需要场景维护权限 |

新增表：`afs_download_template`、`afs_download_template_version`、`afs_download_scene`、`afs_download_task`。模板文件默认存储在 JVM 临时目录 `gaia-after-sales/download-center`，生产建议配置 `gaia.after-sales.download.storage-root` 到持久化磁盘。
