# Web 日语接入与现有界面翻译

- 编号／类型：TECH-20261014-I18N-JA-01／横向工程底座与界面国际化。
- 应用／视角／入口：Web 独立售后后台／跨视角／现有工程及界面，不新增业务入口。
- 来源／日期：用户确认基于新多语言架构接入日语、补齐现有后台界面、同步文档并验证；2026-10-14。
- 优先级／状态：P2／待验收（源码、研发验证与文档完成；正式环境业务验收及日语业务人员复核待完成）。
- 负责人：本轮研发由 Codex 实施；正式角色／共享环境及日语业务校对负责人待分配。
- 技术契约：[国际化架构与迁移规范](../02-技术设计/12-售后子系统国际化架构与迁移规范.md)。前序底座记录见[TECH-20261013-I18N-01](2026-10-13-Web多语言架构底座与遗漏收敛.md)，该记录中的“日语未接入”保留为当时事实。
- 共享发布：2026-10-14随Web`fc8e8e42`纳入完整测试发布`20261014174711-9484612a`，Web669项全部通过，资源摘要回查通过；未追加共享站日语视觉及业务人员校对，待验收状态保持。见[部署记录](../03-开发管理/09-测试服务器部署.md#release-20261014-current)。下方未部署为各实施时点事实。

## 1. 已确认范围

在 `frontend/gaia-ui/apps/after-sales` 按现有注册、资源生成、错误状态与偏好架构增加 `ja-JP`。简体中文仍为默认语言，保留原中英文资源和原有业务能力。已有全部资源域提供日语：登录、框架、导航、四视角工作台、商品、网络、服务资源、顾客与工单、库存、内容、业务配置、数据与系统管理、通知、下载及主数据导入导出；新增组件库补充域同样提供三语言资源。

本次不升级依赖，不修改业务接口、权限配置、菜单稳定代码、角色／租户范围、业务枚举、数据库、ID、版本及提交白名单；实施阶段不推送、不部署；用户随后授权仅提交本次相关代码与文档。源码仓库期间有其他任务独立提交和未提交内容，均原样保留；实施阶段验证为整合工作区结果；提交前另行导出仅本次暂存的独立快照验证，见第4节。代码基线为 `5c62fda2`（外部服务配置任务提交）；日语Web已于2026-10-14本地提交 `45c2ff8c2ac02f4d5d2ed4f281dbb5a7a157511c`（Committer：snow），未推送／部署。

## 2. 实现

| 能力 | 当前实现 |
| --- | --- |
| 语言注册 | `registry.json` 增加 `ja-JP`／自称 `日本語`，Element Plus、Day.js 均映射 `ja`，日期显示 `YYYY年M月D日`，品牌分行；默认 `zh-CN` 不变 |
| 全部资源 | 日语原有32模块／4499语义词条全部补齐；新增 `elementPlus` 51项补充后，每种语言共33模块／4550词条。生成文件由 `generate:i18n` 更新，普通页面不增加语言分支 |
| 官方组件包 | 以 Element Plus 官方日语包为主；项目补充包中仍为英文的51个关闭、日期、星期、分页及无障碍字符串。克隆后覆盖，保留官方已有译文；路径不存在则失败，不修改依赖文件、不维护整份复制包 |
| 消息标签 | Radix Toast 的区域／关闭按钮和 Sonner 公开标签通过现有词条翻译，不改变消息触发、权限或通知读写行为；调用方自定义标签按原公开接口保留 |
| 状态遗漏 | 服务站工作台原直接显示 `personnelAssignmentStatus`（例如 `FAILED`）；现复用既有 `personnelAssignmentLabel` 展示分配方式与状态，未知服务端原因仍原样显示 |
| 偏好与搜索 | 使用既有账号／租户隔离的偏好键。语言菜单、恢复、跨标签事件和授权菜单搜索由注册表扩展；只搜索已有授权导航，不通过全部词条暴露未授权入口 |
| 业务保护 | 不以语言作为组件 key。切换语言保留草稿、选中项、错误对象、业务日期、人民币币种、ID／版本及既有请求次数；校验只更新已显示的错误，已有 Toast 不重新发送 |
| 回归 | 新增日语格式、偏好、搜索、失败草稿、插值、运行时安装／恢复／跨标签卸载、官方包未被修改等行为回归。资源一致性测试覆盖所有注册语言，参数按名字集合比较 |

官方接口依据：[Element Plus 国际化](https://element-plus.org/en-US/guide/i18n.html)、[Day.js 语言接口](https://day.js.org/docs/en/i18n/instance-locale)。最终补充路径按本机已安装包核对，不以文档推断所有组件都已完整译为日语。后续组件库升级须复核补充路径和上游译文。

## 3. 日语术语与业务原文边界

| 项目术语 | 日语显示 |
| --- | --- |
| 商品分类／商品系列／配件 | 商品カテゴリ／商品シリーズ／部品 |
| 代理商／经销商／门店 | 代理店／代理店／店舗 |
| 服务站／服务人员 | サービス拠点／サービス担当者 |
| 工单／派单 | 作業指示／割当 |
| 保修／延保 | 保証／延長保証 |
| 购买登记／安装码 | 購入登録／設置コード |
| 排班／工作视角 | 勤務予定／業務視点 |
| 启用／停用状态、执行动作 | 有効／無効、有効化／無効化 |

品牌沿用既有 `Blue Whale Digital`，产品型号、姓名、组织、实际商品／服务站名称、中国行政区原值及用户输入保留；不擅自建立日本品牌名称或把中国省市区替换为日本行政区。AI、RFID、SLA、SMART 等技术标识保留。费用仍为人民币“元”，不随日语变为日元。

服务端未知业务说明、历史备注和业务内容不进行客户端猜译。智能审核说明中引用的原始判定词及默认“未使用配件”保留中文，因为仍参与现有业务判定。正式业务术语复核未完成，自动资源检查不等于母语审校。
