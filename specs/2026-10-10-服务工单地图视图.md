## 页面范围与数据契约

| 页面 | 实现入口／列表 API | 地图能力 |
| --- | --- | --- |
| 各视角服务工单 | `WorkOrderListPage`；`GET /api/afterSales/customer/work-orders` | 服务地址分布、详情及原分站／重新分站操作 |
| 安装申请查询 | 同一列表组件；`GET /api/afterSales/customer/appointments` | 安装申请服务地址分布及原详情 |
| 分配服务站 | `WorkflowListPage(dispatch)`；`GET /api/afterSales/work-order/dispatch` | 继承待派单默认筛选，可从工单进入分站 |
| 本站工单分配 | `workOrderAssignment/index.vue`；`GET /api/afterSales/work-order-assignment` | 继承站点及待分配默认筛选，保留分配人员／收回／退回客服 |
| 异常工单 | `WorkflowListPage(exceptions)`；`GET /api/afterSales/work-order/exceptions` | 原异常筛选、详情及获授权的异常处理／复开 |

完工审核、电话回访和实时待办保持原查看方式，不增加地图切换。工作视角不创造新数据范围；所有分页、详情及写操作仍经过原 API 的租户／组织／站点／门店范围和权限校验。地图仅展示已有可访问入口，不新增菜单或授权。

- 所有带地图切换的工单列表仅提供“表格／地图”，不缓存显示类型。2026-10-12 按用户最新确认，每次进入、刷新、关闭重开及返回仍打开的缓存标签页均默认表格；同页查看／关闭详情保留手动选择，不同入口互不影响。渠道与网点采用同一规则，商品目录继续保留表格／卡片持久偏好。旧工单／网络存储值不再读写，无须人工清除。详见[最新状态规则与验证](2026-10-09-渠道与服务网络地图视图.md#map-view-policy-20261012)。
- 地图使用已应用的筛选条件，跨表格分页收集完整授权结果，2026-10-15起工单地图增加2000条上限，超限停止并提示缩小范围，不显示部分分布；左侧结果另按每页20条展示。综合查询默认创建时间近30天，待办及异常不增加创建时间默认限制，行政区筛选见[第一阶段规则](#query-range-20261015)。筛选、重置、刷新后清理旧地图结果并隔离过期响应；显式单工单定位入口只显示该工单，不扩大为全部结果。切回表格保留原筛选和分页。
- 点位只取工单保存的服务地址经纬度。历史缺失、非数值、越界及无效零坐标保留在“未定位”列表；不以门店坐标、行政区中心或现场设备定位补点。同地址多张工单按工单 ID 保持独立，通过聚合点及左侧列表选择。
- 列表明确展示工单类型、状态和服务方式；远程指导的点代表登记服务地址，不表示需要人员上门。图例为“工单服务地址”，已关闭工单不套用网点停用含义。
- 左栏选中行原位展开地址、联系人、期望服务时间、服务站及人员摘要；正文内部滚动、动作可换行，地图尺寸保持。点位与列表双向选择，详情复用原弹窗；办理按钮复用原权限、状态、`actions`、版本与提交流程，不新增地图独立写入口。
- 业务列表失败时不展示已加载的部分分布，提供重试；底图失败与业务数据失败分别沿用公共地图反馈。地图仅在访问过且当前可见时加载，隐藏／缓存页面取消未完成读取。

## 实现与兼容性

`WorkOrderMapPanel` 将工单适配为公共 `NetworkMapPanel`／`NetworkMapCanvas` 点位，保留原工单对象供详情和业务动作使用。公共面板最小增加行元信息、动作插槽及可选点位说明／图例；渠道与服务网络继续使用原默认行为。`EsListViewToggle` 增加可选卡片可用性，旧页面默认保持卡片按钮。

服务站专用列表此前只返回地址文本、未返回保存的坐标。`PersonnelAssignmentMapper.orderColumns` 补齐 `serviceMode`、省市区街道及经纬度查询投影，坐标以字符串返回、空值为空串；列表范围与状态限制不变，详情和原写接口不变。普通工单、安装申请、分站与异常接口已有这些字段。无需数据库迁移、菜单配置或小程序改动。

### 已确认查询规则

1. 服务工单、安装申请综合查询进入页面时，创建日期默认为含今天的近30个本地自然日（今天减29天至今天）。例如2026-10-15对应2026-09-16至2026-10-15。创建日期位于可见筛选首项，与原“期望上门／服务日期”独立。用户可调整或清空创建日期后点击筛选查历史；重置恢复近30天并清除地区等自选条件。按用户2026-10-15追加确认，查询条件下方不显示近30天的小字提示，默认范围仅由创建日期控件呈现；不隐式因关键词或手机号改变时间口径。
2. 分配服务站、本站工单分配、异常工单及既有待办入口不增加默认创建日期条件，原待派单／待分配默认状态及其他状态规则保持。历史未处理、未解决异常继续可见；超过地图上限时仍可在原表格分页查询。原按工单ID关联定位走精确授权读取，不受综合列表日期影响。
3. 五类带地图工单列表复用已有行政区单选控件，支持选择省、市或区县任意层级。表格和地图共用已应用条件；切换视图不偷偷增加地区条件，地区改变后点击筛选才查询。服务地址行政区缺失时不伪造归属；未选地区仍可查这些历史记录，缺坐标但行政区匹配的工单不被排除。
4. 工单地图收集上限为2000张，包含已定位与未定位工单。沿用每页100条的分页API，首个分页返回总数超过2000即停止后续读取，清空旧点位并提示实际匹配数量、上限及缩小条件方式；不将前2000条当成完整地图。恰好2000条完整收集，集合变化、重复或分页失败继续按原失败规则处理。渠道／网点共享地图没有增加这一工单业务上限。
