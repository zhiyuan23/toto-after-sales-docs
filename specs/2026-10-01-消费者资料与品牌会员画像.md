## 1. 消费者填写与保存

沿用[个人资料持久化契约](2026-10-01-消费者个人资料持久化.md)。账号以独立消费者身份持有，不依赖手机号；绑定／更换临时手机号不移动或清空本人资料。

| 信息 | 编辑和用途 |
| --- | --- |
| 头像、姓名 | 沿用头像私有上传与姓名失焦保存；姓名供服务联系与档案展示 |
| 手机号 | 本期沿用绑定链路；MANUAL_TEMP 不作为微信正式验号，正式换号二次验证待后续 |
| 省市区、详细地址 | 沿用三级选择和地址失焦保存；定位逆解析仅作为显示／选择器起点，必须用户确认地区后才保存 |
| 性别 | 选填“不填写／男／女”；存储空字符串／MALE／FEMALE，确认后自动保存，可清空 |
| 出生年份 | 选填1900年至当前年，选“不填写”可清空；只用于粗略年龄段，不采集完整生日 |

个人信息页无统一保存按钮、无成功背景提示；失败显示就近重试，串行队列按服务端版本提交且只应用已确认字段。新增两字段进入已有按环境／租户／账号隔离的24小时失败草稿，不夹带尚未失焦的姓名或地址。退出／身份失效按既有规则清理。

`PUT /api/afterSales/mobile/consumer/profile` 增加字符串 `gender`、`birthYear`；GET／保存／头像响应也返回两字段。显式空字符串清空，旧客户端未传或传 null 保留已有值；出生年份需四位且1900～当前年。头像更新保留人口资料。409版本冲突、422校验错误、审计事务等规则不变；审计不记录个人信息快照。

前端明确提示“性别、出生年份为选填，用于品牌服务统计，可随时修改或清空”。通知偏好、会员标签、营销人群未在本期实现。

## 2. 品牌会员档案与访问范围

既有 `afsMember` 路由由占位页接入真实页面，按用户追加授权在总部“会员运营 → 会员档案”正常显示；管理员通过总部视角进入。列表可按姓名／账号／手机号后四位、性别和省份筛选；详情为只读资料及分页产品、服务记录。

接口统一前缀 `/api/afterSales/members`：

| GET 路径 | 契约 |
| --- | --- |
| `/permissions` | read、detail、statistics 三项独立能力，进入账号授权快照 member 域 |
| 空路径 | 消费者档案列表，page／pageSize及keyword／gender／provinceCode |
| `/accounts/{id}` | 单个启用消费者资料及关联计数；不存在／停用返回404 |
| `/accounts/{id}/products` | 关联产品分页，登记／扫码来源、商品、分类、唯一码、实际核验状态 |
| `/accounts/{id}/orders` | 关联服务分页，工单号、类型、状态、时间及该消费者评价 |
| `/statistics` | 品牌会员汇总 |
| `/statistics/buckets` | 固定维度 GENDER、AGE、PROVINCE、CATEGORY、REGISTRATION_MONTH，其他值422 |

每次读数据先核验精确接口权限，再强制配置的单租户与请求上下文一致，再核验启用平台账号具有管理员标志或 `afsWorkspaceHeadquarters` 模块授权；仅持会员旧菜单／接口授权的门店、服务站不满足此条件。详情子接口同时核验详情与子接口权限。统计分组使用自己的精确路径授权；档案 `/accounts/*` 不覆盖统计接口。

首版沿用项目单品牌／单数据库消费者账号边界；其他租户上下文403，未配置／多租户模式不可凭此实现扩大范围。后续多品牌必须另行定义品牌归属，不从产品关系推断当前授权范围。

品牌个人资料白名单：消费者编号、姓名、性别、出生年份、省市区、脱敏手机号及绑定／正式验证状态、注册／最近活跃／资料更新时间、产品／服务／评价关联计数。不返回 OpenID、会话、完整手机号、详细地址、私有头像路径。即使旧库 `mobile_masked` 实际存完整手机号，查询也主动变为前三后四的脱敏形式；不能识别的非空值只返回四个星号。手机号检索只匹配末四位，不检索完整号码及中间片段。

## 3. 数据来源与统计口径

人口及地区均来自消费者已确认保存的资料；临时经纬度及默认逆解析地区不参与品牌统计。启用消费者账号为总人群，未填写资料也计入，停用账号不计入。最近活跃取会话最后活动时间，注册月份取账号创建时间。

| 指标／维度 | 口径 |
| --- | --- |
| 会员总数 | 启用消费者账号数；不能解释为已购买／已核验顾客数 |
| 绑定人数／正式验证人数 | 非空绑定号码；其中只有 WECHAT 且正式验证时间非空计为微信验证，MANUAL_TEMP不计 |
| 已填联系资料人数 | 姓名与区县均非空；不要求填写人口资料 |
| 产品／服务／评价关联人数 | 各自存在关联的不同消费者人数；接口另返回评价关联人数，页面六项主指标展示至服务关联人数 |
| 性别／年龄段 | 未填单列；当前年减出生年得到近似年龄，分为18岁以下、18～29、30～39、40～49、50～59、60岁以上；不表示精确生日年龄 |
| 省份 | 已保存省份；未填写单列 |
| 产品类别 | 每类按消费者去重；一人可跨多个类别，比例分母为全部会员，因此各类人数不可相加推算会员数 |
| 注册月份 | 账号创建月份；不等同产品购买月或服务月 |

关联产品复用消费者现行 ACTIVE 商品关系，排除合并实例；登记产品保持原购买核验状态，扫码来源标记 NOT_ASSESSED，界面明确不代表购买核验。有效登记与扫码同唯一码去重。服务关系从商品对应工单与消费者扫码工单取并集，同一工单关联多个产品也只计一次；不是把创建人当作消费者。评价只取当前消费者评价，不能用他人评分。

页面复用 FaPageMain、EsSearch、EsTable、useListPage 与 Element Plus；详情和统计具有加载、无权限、失败及重试状态，取消过期请求。统计与档案分别授权，仅统计权限不显示个人列表。
