## 1. 已确认的反馈规则

可见列表、状态和回填内容已经表达结果时，移除普通成功 Toast。字段错误在字段旁显示并定位第一个错误；页面加载失败提供重试，后台刷新失败保留旧数据并说明未能更新；上传失败留在对应照片旁。自动保存失败只由保存状态区承担反馈，同一问题不叠加 Toast 或弹窗。

普通操作失败使用一次轻提示，长文案不自动升级为弹窗。需要用户决定、可能丢失未提交内容、必须重新登录及部分成功等提醒继续保留。主动取消定位、选图或请求，不再追加错误 Toast。

内部解包、版本、请求号、文件引用及错误码改为可理解的说明。原始诊断保留在 `RequestError.originalMessage`，`kind`、`statusCode`、鉴权、幂等与校验不改变；草稿版本冲突恢复继续使用原始诊断。读取失败可以重试，写入结果不明先核对记录，不宣称失败或引导直接重复提交。

## 2. 排查项与最终处理

| 编号 | 场景 | 最终处理 |
| --- | --- | --- |
| A01 | 消费者手机号绑定／修改 | 移除正式成功与同步 Toast；绑定后按原导航刷新商品。 |
| A02 | 消费者同步商品 | 移除正式刷新成功 Toast，列表更新承担结果。 |
| A03 | 服务人员登录 | 普通成功不提示；微信未绑定仍说明下次需手机号及密码。 |
| A04 | 切换企业 | 删除成功 Toast，由当前企业／服务站及数据变化表达结果。 |
| A05 | 扫码添加商品 | 删除成功 Toast，回首页选中新商品；本人已有商品仍进详情，归属拒绝保留。 |
| A06 | 安装／维修／指导申请 | 正常提交回首页显示服务状态；照片失败的单独结果分支保留。 |
| A07 | 评价／投诉提交 | 删除成功 Toast；评价跳转失败保留已提交说明及记录，投诉保留完成结果和防重复提交。 |
| A08 | 联系／预约／编辑／任务动作 | 删除普通保存成功 Toast，关闭面板并刷新详情；取消任务仍保留必要结果提示。 |
| A09 | 签到／远程服务开始 | 删除成功 Toast，更新任务并开放处理表单。 |
| A10 | 领退料／撤销／完工／补充重提 | 删除成功 Toast；领退料进单据详情，跳转失败显示已提交及查看入口，重试只跳转；撤销刷新状态；完工／补充成功回首页并切到“审核中”列表，避免默认待处理分类隐藏结果。 |
| A11 | AI 摘要回填 | 删除带入报修的成功 Toast，由描述回填体现结果。 |
| B01 | 检测／处理结果必填 | 仅字段错误，返回处理步骤并定位。 |
| B02 | 必需照片不足／未上传完 | 仅证据区错误，切至证据步骤并定位。 |
| B03 | 客户确认必填 | 仅确认区错误，切至对应步骤并定位。 |
| B04 | 处理／补充页上传失败 | 仅照片失败状态及重试／移除操作，无逐张失败 Toast。 |
| B05 | 自动保存失败 | 仅顶部保存错误与重试，保留输入；配件区不重复展示；提交时保存失败定位保存区，手动暂存成功也不再 Toast。 |
| B06 | 完工提交失败 | 仅提交区错误并定位，不叠加弹窗；已成功而导航失败仍保留审核回执。 |
| B07 | 配件与单据刷新失败 | 仅页面或列表尾部说明，保留旧数据及重试。 |
| B08 | 隐私政策加载失败 | 仅政策区错误及重新加载，提交定位政策区，不要求点击禁用的确认项。 |
| B09 | AI 摘要复制 | 删除自定义复制成功 Toast，保留平台自带轻提示；客服页的摘要说明承担上下文信息。 |
| C01 | 解包／校验／下载错误 | 共同展示转换为产品、资料、照片、任务等操作对应的加载／下载说明。 |
| C02 | 写入结果不明 | 按服务、投诉、任务或单据记录引导核对；扫码添加结果不明先刷新我的产品。 |
| C03 | 技术异常透传 | 版本提示刷新，请求号提示核对，引用提示重新上传；后端异常细节不直接显示，原始诊断保留。 |
| C04 | 无记录／无访问范围 | 统一“暂时无法查看这条记录，请返回列表重新进入”，不披露他人数据。 |
| C05 | 身份异常页 | 分账号未关联、未分配服务站、停用和加载失败说明；不拼接错误码，需管理员处理时不提供无效重试按钮。 |
| C06 | 登记／服务联系校验 | 姓名、手机号、地区、地址、日期、时间及确认项分别提示；“行政区域”改为“所在地区”。 |
| C07 | 领退料选择／数量／工单 | 就近提示数量需为 1 或更大的整数、最多 100 项、工单不可用；库存调整提醒继续保留。 |
| C08 | 密码校验 | 区分空值、纯空格、过短、过长、与旧密码相同及两次不一致，放字段旁并定位。 |
| C09 | 企业切换确认 | 无草稿直接切换，有草稿明确确认未提交内容会被清除，隔离和清理规则不变。 |
| C10 | 定位失败／取消 | 失败给权限检查方向；坐标已得但地址不可用如实说明；主动取消不额外 Toast，设置引导保留。 |
| C11 | 长错误弹窗／技术说明 | 移除按字数弹窗规则；开始服务、补充资料、取消任务说明改为用户语言，业务确认框保留。 |
| C12 | 未开放能力／资格说明 | 正式个人资料不再允许编辑不可保存的字段，偏好入口隐藏且直接页禁用；资格说明使用普通语言，安装／确认页不再声称所有申请都要先进入旧待核验步骤。 |

消费者演示分支的模拟提示不作为生产能力验收。未增加头像、姓名、地址或偏好保存接口，未将待确认的权益写成免费服务或已核验。

## 3. 实现入口与同步

共同 `feedbackMessage.ts`、`operationFeedback.ts`、`revealField.ts`、请求错误及 `AppState` 已双端同步。各业务页决定由字段、状态或轻提示负责反馈。两仓设计说明及共同底座说明同步记录；UI 规则见[两端 UI 规范](../02-技术设计/16-两端小程序UI样式与验收规范.md#9-提示与错误反馈2026-10-01)。

正常完工与补充重提仅进入“审核中”，不将提交审核表达为服务完成。领退料成功导航失败保留单据 ID，后续点击不重发创建请求；切换身份清除该结果与旧提示，迟到的导航失败不会回写原企业结果。原有会话代次、草稿恢复、撤销确认、退出确认、高分未解决评价确认、库存和服务权限限制保留。
