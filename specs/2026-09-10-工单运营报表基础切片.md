## 本次可查询事实与口径

查询按工单创建日期选取队列，含首尾日期，最多 93 天，默认最近 30 天。支持创建日期、服务类型、建单来源、服务省份、当前服务站、门店、商品七个维度；同组内按工单 ID 去重，工单关联多个商品时可计入多个商品组，因此禁止跨商品组合计为工单总数。商品和门店名称取业务快照；站点显示当前关联主档名称。

输出工单数、当前已关闭数、当前已取消数、有投诉的工单数。关闭／取消是查询时的状态，不是日期范围内发生的关闭／取消事件。有关联投诉的工单计一次，多个投诉不重复累计；不将投诉条数当工单投诉率。列表明确显示此口径，不输出未经确认的满意度、一次完工率或外部接口成功率。

权限与租户和工单查询一致；日期范围强校验，统计维度为白名单，SQL 不接受自由字段／SQL 表达式。只读业务事实，不产生业务状态变更，无新统计主表。

## 契约与依赖

`GET /api/afterSales/reports/permissions` 与 `GET /api/afterSales/reports/work-orders`；接口定义见后端 `docs/report.openapi.json`，配置见 `database/20260910_report_permissions.json`。报表依赖已存在的工单、购买登记、商品实例、服务站以及本次投诉表；部署时需先应用投诉迁移。缺表按错误响应，不用假零代替。

### BUG-20260910-01：报表服务名称导致聚合宿主启动失败

- 类型／优先级／严重程度／状态：缺陷／P0／阻断本地启动／待验证。
- 应用／角色／模块与入口：Web 管理后台／跨视角／A54 工单基础报表及本地全栈启动；关联本 Spec、FS-045。
- 来源／日期／负责人：用户反馈 `yarn dev:afs` 控制台报错；首次提出及最后更新 2026-09-10；Codex 实现，验收负责人待分配。
- 环境与复现：macOS、JDK 21、Gaia 聚合宿主；包含售后报表模块时，在 `gaia-ui` 执行 `yarn dev:afs`。Maven 构建成功，Spring 创建旧模块 `codeReportApi` 时失败，9010 前端未启动；预期 Redis、后端及售后前端全部就绪。
- 原因：售后 `ReportAppService` 默认注册为 `reportAppService`，旧模块 `CodeReportApi` 的同名 `@Resource` 字段优先按名称找到售后 Bean，而其期望类型为 `CodeReportAppService`，触发 `BeanNotOfRequiredTypeException`。JDK 代理只是错误中显示的实际类型，不是需要修改全局代理配置的依据。
- 修复：售后服务显式命名为 `afterSalesReportAppService`；售后 API 继续按 `ReportService` 接口注入，旧模块恢复按自身类型解析。未修改旧模块、宿主代理策略、数据库或权限。
- 研发证据：新增 `ReportBeanWiringTest`，使用生产注解推导 Bean 名称，覆盖旧模块同名 `@Resource` 字段与售后 API 共存；连同 `ReportIntegrationTest` 共 3 项通过（0 失败／错误）。完整启动验证结果同步于[本地联调记录](../local-development.md#本次验证与边界)。此记录不代表 A54 业务验收完成。
