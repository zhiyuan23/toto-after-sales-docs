## 实施契约

1. 清空旧售后页面、业务 API、登录演示、C 编号源码映射、旧 Demo/设计系统及自定义 TabBar；保留通用技术栈、基础主题、反馈、分页和构建上传能力。
2. 正式应用只含中性首页、设置、404；原生 Tab 配置由一份路由元数据生成。示例为单独条件编译分包，正式构建与上传拒绝混入示例/Mock。
3. 租户与环境分离；`pnpm build`／`pnpm build:h5` 未指定租户时默认 `TOTO`，未指定环境时默认 `test` 并使用 profile 中已确认的当前测试地址，显式目标仍可使用 `<TENANT> <ENV>`。production 必须显式提供独立 API 地址，不回退开发／测试地址。当前无已确认生产 API。
4. 提供可注入/可取消请求内核，认证状态和安全回跳、缓存作用域及脱敏诊断。真实身份、Token/响应协议和服务端权限由业务接入。
5. 新建中性列表→详情→编辑参考流程，覆盖固定数据、分页/刷新、异常重试、提交保护和登录回跳；不代表售后业务实现。
6. 统一 check 包含全部必要规则测试；补 doctor、双端冒烟、CI 作业入口及失败日志/截图。实际 Codeup 启用、真机、微信账号配置和发布需独立证据。
7. 清理并收敛 AI 事实入口与过期引用，保留用户其他任务的文档/后端变更。默认不提交、不推送、不上传。

- 预期结果：上传代码包保留路由定义模块，体验版与开发版使用同一路由表正常启动。

## BUG-20261006-01 长时间保存重编译的 Node 内存放大

- 日期／范围／优先级／负责人：2026-10-06；消费者与服务人员共同编译链；P1；实施与研发验证 Codex。
- 触发与预期：用户反馈开发监听连续保存后 Node 占用达到 4～5GB，曾达到 10GB；预期保留正常增量编译，内存周期回收，不随保存无界增长。
- 历史核对：知识库能定位宜宝消费者项目，但未找到该次内存修复记录或万达山车载映射；直接核对 `dicp-wmhy-member-wechat` 与 `wondersun-car`，两者当前开发命令已有 2048MB 老生代预算、128MB 半空间及暴露 GC 选项。当前 TOTO 启动链未继承该预算。没有证据证明这些历史参数消除了泄漏，未照搬全部参数。
- 当前证据：TOTO 两端 `vite.config.ts` 无条件使用 Terser，微信监听每次保存也压缩。Node 24.21.0 默认堆总预算约 4288MiB，设置老生代 2048MB 后约 2240MiB；工作线程、原生分配、年轻代和外部内存另计。已有数小时 H5 进程 physical footprint 约 515／652MiB；刚启动微信进程也不能用于否定历史高峰。
- 实施：双端开发监听 `minify: false`，单次构建保留 Terser；仅 watch 命令追加默认 `--max-old-space-size=2048`，保留已有其他 Node 选项及显式堆预算。未增加定时 GC、自动循环重启或更高堆上限。
- 连续保存另暴露产物竞态：Vite 5.2.8 与当前 UniApp 都在 `BUNDLE_END` 异步调用结果 `close()`；原租户插件 `closeBundle` 写相同 `.gaia-tmp` 文件，快速下一轮清空目录可造成 `ENOENT` 并退出。校验与元数据写入迁至 Rollup 等待的 `writeBundle`，不在异步清理阶段写产物。回归覆盖缺失文件拒绝和连续成功写入。
- 研发检查：最终修改覆盖在两仓 HEAD 的隔离副本，双端 `pnpm verify` 通过；消费者租户／单元／路由／审计策略测试为 40／272／4／12，服务人员为 38／250／5／12，微信与 H5 development 环境的生产方式构建均成功。当前工作区消费者全量检查曾遇并行页面 `service-flow.scss` 重复选择器错误，未改该任务文件；服务人员当前工作区最终完整 verify 也通过。文档影响检查通过。
- 压力验证：Node 24.21.0／pnpm 10.34.5，在独立临时源码副本每轮修改 `App.vue` 脚本注释，收到实际编译完成后才触发下一轮；不接真实接口、不改运行中的源码。原配置和仅关闭开发压缩的 GC 对照各有约 60 次采样，RSS 峰值分别约 3279／1128MiB，后者另遇原产物竞态。最终双端各完成 120 轮正常 GC 重编译（各 121 次初次／增量编译完成），无编译错误；消费者 RSS 峰值 1759MiB、人员 1654MiB，`vmmap` 的物理占用峰值约 1.8／1.7GB，堆周期下降。连续密集保存未再触发产物写入竞态；原进程及本轮副本均由 `vmmap -summary` 复核 physical footprint，不能把虚拟地址空间计为实际内存。
- 过程脚本、内存采样和完整日志仅保存在忽略目录 `.local/verification-artifacts/2026-10-06-watch-memory/`，不纳入 Git。复测可使用本地保存的 `reproduce.mjs <仓库绝对路径> <新临时目录> 120 natural`；它复制源码、共享只读依赖并只修改副本。团队成员也可启动 `pnpm dev TOTO`，连续修改保存全局 Vue 文件，核对同一 UniApp PID 的堆／physical footprint 周期回落、连续编译与 `tenant-build.json` 输出。
- 限制：没有复现用户报告的 10GB 峰值，也未证明上游编译缓存完全无泄漏；本次针对已复现的开发压缩放大和产物竞态。本轮已恢复两端微信编译监听并应用新预算；标准入口当时等待其他任务持有的共享后端启动锁，恢复会话复用同一租户启动逻辑，仅跳过该次后端准备，不修改启动脚本。其他原常驻 H5 会话的启动参数须下次重启才生效；未推送、上传或发布，不改变业务入口或验收计数。
