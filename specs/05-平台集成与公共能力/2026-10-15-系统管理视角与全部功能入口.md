## 功能契约

| 项目 | 规则 |
| --- | --- |
| 工作视角 | 保留四个业务视角，末尾“系统管理员”为全功能管理视角；视角切换位于左上角系统名称右侧，直接显示当前视角并以下拉展开，个人菜单不再重复提供入口 |
| 管理身份 | 复用真实菜单快照中的 `afsNavigationAdministrator` 及准确路径；不按角色名称、本地缓存或客户端参数识别管理员 |
| 管理员导航 | 顶部依次为系统管理、服务运营、基础资料、配件库存四模块，系统管理左侧首项为工作台；左侧按分组和页面展示，单页分组直接进入页面，空分组／模块隐藏。客户与会员及运营配置归服务运营，字典与模板归基础资料；系统管理只保留管理员专属系统功能 |
| 四个业务侧栏 | 不再追加系统管理或系统运维；原业务分组、工作台、任务抽屉和业务办理保留 |
| 管理员默认页 | 首次默认管理员视角时进入 `/dashboard/administrator` 独立工作台；已有岗位视角偏好及四岗位首页保留。工作台复用现有日志／外部配置读取和任务抽屉，不新增业务统计接口或授权节点 |
| 导航样式与检索 | 顶部沿用项目默认导航组件、图标、间距、品牌及搜索样式；删除“全部功能”按钮、抽屉、专用搜索与跳转代码、三语文案；功能检索继续使用原导航搜索 |
| 跳转归属 | 管理员导航内打开业务页面仍保持管理员视角，内部使用原页面对应的业务请求上下文；共用页面沿原规则保持有效业务上下文。普通业务视角之间的归属规则不变 |
| 完整授权 | 管理员切换任一视角继续使用账号完整授权，不与岗位做交集，不额外请求授权快照；后端接口、行 actions、状态和组织／租户数据边界保持 |
| 直达与失败 | 普通账号不能通过直达或本地视角提示取得管理员视角；跨视角跳转复用未保存确认、提交保护和失败恢复；取消或失败不清除表单与标签 |
| 入口限制 | 全局用户、角色、菜单、日志继续遵守独立非 iframe 及身份管理开关；禁用时不进入系统默认页候选或管理员导航 |

左上角切换入口仅真实管理员且具有至少两个可切换视角时显示，选项按实际视角授权展示，当前项勾选且不可重复选择；普通岗位沿原业务授权，同位置只读显示当前视角，不显示管理视角切换器。业务字典与模板的管理页面从总部导航转入管理员视角，业务表单使用字典选项、导入导出等仍沿用原独立接口权限。本次没有新增或撤销数据库角色绑定，也没有把前端隐藏视为服务端撤权；既有 API 鉴权保持。权限模拟、代登录、角色降权或跨组织范围模拟均未实施。

## 管理员模块组织

| 顶部模块 | 左侧分组与页面 |
| --- | --- |
| 系统管理 | 工作台（左侧首项直接进入）；账号与权限；系统运维（日志查询、外部服务配置） |
| 服务运营 | 工单管理；服务处理；客户与会员（顾客购买记录、会员档案、会员分析）；质量与分析；运营配置（服务设置、评价标签、用户协议、首页轮播、首页精选）；岗位工作台（四个原工作台） |
| 基础资料 | 商品资料（含配件档案）；销售渠道；服务网络；人员与排班；服务知识库（直接进入）；字典与模板（业务字典、导入导出模板） |
| 配件库存 | 库存查询；入库与领退料；调拨与盘点 |

同一功能 code／路由在管理员导航只出现一次。综合工单与服务站工单、四个岗位工作台分别保留原页面，仅管理员导航标题区分；不合并业务接口或修改全局页面名称。

## 实施边界

- `manifest.views` 四业务视角逐字段保持；`manifest.systemView` 复用既有管理员授权，`administratorModules` 只描述展示分组，不生成权限树节点。
- 导航仅从既有授权日常入口集合编排。`navigationViewId` 决定管理员／岗位菜单；原 `viewId`、页面缓存键及 `X-After-Sales-Workspace` 继续使用原业务上下文，不让管理员展示状态改变工单查询或页面动作。
- 管理员有效菜单模式为顶部＋左侧；业务视角读取原保存偏好。派生布局不覆盖保存的菜单模式，退出管理员自动恢复。账号／租户限定的sessionStorage视角提示只作展示偏好，恢复时重新校验真实授权。管理员模块直接聚合既有授权日常入口，任务抽屉及上下文入口不加入日常导航。
- 统一权限快照仍按账号／租户缓存，导航切换不刷新；数据请求携带原业务视角或已有后端支持的 `administrator` 上下文，不改变真实操作者。
- 菜单交付生成器同时纳入四业务视角与系统视角计算显隐；对比变更前后全部80个稳定模块和管理员授权清单必须一致。本轮对比开始时与结束时的四业务视角、全部角色推荐选择、80个稳定模块和数量均完全相同；交付包只是审阅材料，不自动写库。
- 仅复用本机9010子系统与8080宿主，不启动／重启服务，不修改后端或数据库；主系统／iframe不在本次界面验证范围。
