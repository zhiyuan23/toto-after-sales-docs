## 系统管理与系统运维分组（2026-10-15）

- 编号：OPT-20261015-SYSTEM-OPERATIONS；来源：用户确认「系统管理／系统运维」方案并要求实施，业务字典与导入导出模板继续留在系统管理。
- 范围：独立子系统四视角的侧栏投影、三语菜单文案和图标；本次不验证主系统或iframe入口。
- 状态：本机已实施；未提交、推送或共享发布，不增加业务验收。

| 同级分组（顺序） | 总部完整授权时的子菜单 |
| --- | --- |
| 系统管理 | 用户管理、角色管理、菜单与权限、业务字典、导入导出模板 |

客服、服务站、门店视角的系统管理继续按原授权展示用户／角色／菜单；系统运维仅展示已授权日志，不增加外部服务配置入口。两个分组按该顺序置于末尾，部分授权时也保持顺序；空分组隐藏。业务字典与模板保持独立业务授权，不附加管理员门槛；外部服务配置继续要求管理员资格及精确菜单授权，日志继续使用原Gaia模块、精确API与数据范围。

仅移动 `manifest.views` 中外部服务配置的展示分组，并将动态全局日志入口投影到系统运维。功能code、路径、稳定注册父级、显隐、按钮、API、角色绑定和业务规则均保持。对比修改前后的菜单交付包，80个稳定模块及数量完全一致，未操作数据库。既有菜单包测试仍停留在外部服务配置新增前的61功能／79节点，已根据同一HEAD基线的62功能／80节点修正计数夹具，没有调整发布失败基线或放宽断言。

## 名称与权限边界

- 五项功能更名：`afsCustomerArchive` 购买记录、`afsServiceSurvey` 评价标签、`afsReport` 服务报表、`afsHomeBanner` 首页轮播、`afsHomeFeaturedProduct` 首页精选。导航、页签／标题、相关页面提示、中英文和菜单管理映射同步；「用户管理」未更名。
- `manifest.json` 为共用注册源；只调整总部 `views`，其余三个视角的分组、代码顺序与上下文列表和 HEAD 完全一致。功能名称因同一 code 复用而统一显示，不制造视角专用别名。
- 功能 code、稳定路径、注册父级、显隐、API 清单、按钮和角色绑定保持。侧栏新增的内容运营不建为 Gaia 权限树节点；菜单管理仍按稳定注册树展示。
- 安装码仍注册、仍保留既有后端读权限和历史数据。仅总部普通岗位的导航及页面直达不再开放；兼具客服视角和相应功能授权的管理员访问时归客服视角。购买记录和工单原检索关系保持，不代表后端安装码 API 已撤权。
- 内容运营的分组不增授权限：总部测试岗位保持只读，测试管理员按原独立动作授权维护，客服／服务站／门店拒绝内容管理接口。窜货统计同样按实际模块授权：总部测试岗位可读，现有测试管理员账号未获该项授权，本次没有为凑齐菜单扩权。
