# 三端技术资料与官方样例贯通

- 日期：2026-09-26
- 需求来源：用户要求列出涉及位置、完成后台上传和服务人员／消费者查看，并上传可直接阅读的资料。
- 研发切片：FS-20260926-MATERIALS；关联 A09、A23、W13、C18 及消费者“我的”资料入口。
- 状态：源码及研发验证完成；真实附件上传与各端文件打开受测试存储容量阻塞，未完成端到端验收。

## 涉及位置与实现边界

| 位置 | 本次处理 |
| --- | --- |
| Web 商品档案 → 产品资料（原安装手册页签） | 统一上传 PDF／Office／图片／视频，选择服务人员、消费者或双方可见，并填写资料版本；新建商品随整单保存，编辑商品上传立即生效，删除撤下 |
| Web 服务知识库 → 服务站知识 | 沿用站点、类别／商品、多附件及启停维护；服务人员资料库读取当前站点已启用附件 |
| Web 服务知识库 → 消费者问答知识 | 沿用单独的草稿、发布／撤回、生效期及正文管理，不把内部知识附件当作消费者问答正文 |
| 服务人员“我的 → 技术资料” | 替换“暂未开放”，增加真实分页查询、关键词／品番／版本筛选、重置、重试及预览／下载 |
| 服务人员任务／处理页 → 本产品技术资料 | 保留本人任务与商品关联查询；统一人员可见范围，补齐视频播放和 H5 文档打开 |
| 消费者“我的 → 产品说明与资料” | 查看明确对客公开的启用商品资料，支持相同筛选及文件打开；不要求购买关系即可查看公开说明书，但仍需消费者登录 |
| 消费者“我的产品”详情 | 增加“查看产品说明与资料”，携带当前型号筛选公开资料 |
| 消费者智能助手 | 保留现有按本人商品、有效站点关系、发布状态和有效期筛选知识的规则 |

延保资料 W12 的项目来源、有效期和维护规则仍未确认，不合并为技术资料，也不生成延保承诺。

## 数据与访问规则

- `afs_product_manual_file` 增加 `audience`（PERSONNEL／CONSUMER／BOTH）和 `edition`。历史两份手册默认为 PERSONNEL，不自动对客公开。
- 新资料最多 200MB；支持 PDF、Office、JPG／JPEG／PNG／WebP、MP4／WebM／MOV。平台文件上传白名单、容量限制和存储服务仍是最终约束。
- 对客发布校验平台上传记录的当前用户归属与真实文件大小；后台仍使用原有商品资料维护权限。
- 服务人员全局列表包含人员可见商品资料及当前服务站已启用知识附件；消费者仅包含消费者可见商品资料。停用商品或站点知识不可继续经资料接口读取。
- 新接口为 `/api/afterSales/mobile/{consumer|service-personnel}/materials` 及 `/{source}/{id}/content`。身份通过各端会话头获得，客户端不传入账号或站点作为授权范围。
- 列表不返回存储 URL；下载时重新核验身份、可见范围和当前启停状态。内容响应禁止共享缓存和 MIME 嗅探；下载权限错误使用对应 HTTP 状态，避免将 JSON 错误当作文件。
- 小程序通过鉴权下载后调用文档／图片／视频能力；H5 使用下载所得本地地址打开。没有新增依赖或更改共同认证内核。
