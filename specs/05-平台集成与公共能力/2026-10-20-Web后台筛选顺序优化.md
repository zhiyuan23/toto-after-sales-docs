## 公共日期快捷项（2026-10-20）

本续轮在公共 `EsSearch` 增加字段属性 `dateShortcuts`，统一通过 Element Plus 日期面板的内置快捷栏展示；未配置字段保持原样。日期计算由 `components/common/EsSearch/date-shortcuts.ts` 提供，各业务页只显式选择场景，不复制算法。

| 配置 | 快捷项 | 使用范围 |
| --- | --- | --- |
| `history` | 今天、近7天、近30天、近90天、本月、上月 | 工单创建时间、购买日期、库存入库／领退料／耗用／盘点创建时间及购买历史 |
| `report` | 近7天、近30天、近90天、本月、上月 | 服务报表、服务质量、防窜货统计 |
| `logs` | 今天、昨天、近7天、近30天 | 系统日志、开放接口日志 |
| `schedule` | 本周、下周、未来14天、本月、下月 | 排班日期 |
| `expected` | 今天、明天、本周、下周、未来30天 | 工单／安装申请、派单／异常／完工审核的期望日期 |

- 本轮显式配置14处源码中的16个日期筛选定义；退役受理列表不单独修改。日／周／批量排班编辑表单已有快捷项继续沿用，不扩大到业务编辑表单。
- 滚动近N天为含今天的N个自然日，未来N天同样包含今天；本周／下周按周一至周日，自然月按完整月份。每次点击时计算本地日期，以本地正午Date交给既有 `YYYY-MM-DD` 格式控件，避免UTC和夏令时导致日期偏移。初始默认范围及重置规则保持。
- 选择快捷项只更新草稿，不调用查询；原已应用条件、表格及分页不随草稿变化。点击“筛选”才按既有映射应用区间。后端程序、参数与权限均未修改；系统日志最多31天的契约保持，不显示近90天。
- 中英日三语已补齐13个快捷项文案。新增日期测试覆盖闰日、跨月／跨年、完整自然月、周一起点、跨午夜实时计算；同组5项在 `America/New_York` 时区复验通过。
- 完整 `pnpm --ignore-workspace check` 通过，854项测试无失败／跳过，包含公共组件选择快捷项不自动查询、草稿与已查询值隔离和重置只查询一次。完整check通过后复用结果执行标准构建余下步骤 `vite build --mode production` 及 `check-bundle-size.mjs`，生产构建与308项JS／CSS包体门禁通过，最大JS约1384.3 KiB。日志仅在 `/private/tmp/toto-date-shortcuts-check.log` 与 `/private/tmp/toto-date-shortcuts-build.log`。
- 复用既有9010服务的公共浏览器夹具，不新增服务：选择近90天后查询次数仍为0，点击筛选后为1，再选近7天仍为1且已查询区间保持近90天；重置后查询次数为2、重置次数为1，日期清空。真实日志、排班、工单期望日期及服务报表的快捷菜单已逐类复核，五种场景配置均正确；报表近90天、期望日期明天／未来30天及排班下月均为对应面板选项。

## 日期快捷项样式完善（2026-10-20）

- 参考[Ant Design预设列表样式](https://github.com/ant-design/ant-design/blob/master/components/date-picker/style/index.ts)的纵向列表、圆角行、留白及悬停底色，在既有Element Plus快捷栏内完善呈现；继续使用原生日历、快捷选择、关闭及键盘行为，不新增按钮体系。
- 公共筛选快捷栏宽144px、内边距12px，选项高32px、间距4px、内圆角6px、字号14px。浅色背景分隔预设区与日历，悬停整行反馈，键盘焦点使用2px主题色轮廓；颜色全部复用主题变量，深浅色保持。
- 根据当前筛选草稿的两个日期精确匹配快捷项，匹配行显示浅主题色背景、中等字重主题蓝文字和同色勾选；手工修改、重置或清空后重新匹配，不保存已经失效的“最后点击项”。范围重合时仅标记列表中首个匹配项。
- 样式通过专用 `es-search-date-picker` 容器类限定在已配置快捷项的公共日期区间面板，同时保留业务自定义 `popperClass`；不覆盖单日期、排班编辑表单及其他日期面板。
- 完整 `pnpm --ignore-workspace check` 通过，855项测试无失败／跳过；新增回归覆盖手动区间、空值／重置、跨场景上限及重合范围的匹配状态。末次仅给现有公共夹具增加深色URL参数和主题变量后，夹具定向lint通过。原始输出仅在 `/private/tmp/toto-date-shortcut-style-check.log`，本样式续轮未重新生产构建。
- 复用9010：实际报表面板测得快捷栏144px、选项32px、字号14px，近90天草稿匹配标记正确；公共组件独立深色夹具选择近30天后查询次数仍为0，深色选中背景与文字清晰，Tab移至近90天出现2px焦点框且查询次数保持0。未改用户主题偏好。临时预览不纳入Git证据。

### 同日：选中项使用主题蓝色

按用户确认，选中文字和勾选统一使用主题蓝色阶，文字由600改为500字重，浅蓝底保持。蓝色按55%主题色与45%正文色混合，为加深后的主题蓝、并非原始 `--el-color-primary`；2026-10-20用户询问色深时已说明，提交本次修改时保留该效果。混色兼顾浅色对比度及深色明度；悬停规则降低优先级，避免覆盖选中项的蓝色。仅变更公共快捷项样式，查询行为保持，不新增复述颜色的测试。

验证：完整前端检查通过，855项测试无失败／跳过；最终仅调整混色比例后定向ESLint通过。复用9010实际报表与独立深色夹具，选中文字和勾选颜色一致、字重500，浅色文字对选中底色对比度4.88:1、深色8.46:1；深色夹具查询次数保持0。文档校验通过。未提交、推送或部署。
