- [x] **Step 1：实现分页加载与完整性检查。** 每页 100 人，顺序读取到 total；人员按 ID、班次按 ID、工单按 ID 去重。`publishedOnDuty` 是全站计数，只取一份不能相加。空中间页或最终唯一人员数与 total 不符时抛出加载不完整错误，不能把遗漏显示为未排班。检查 AbortSignal，每次弹窗重新加载。

```ts
const first = await request({ stationId, dateFrom, page: 1, pageSize: 100 }, signal)
const pages = [first]
for (let page = 2; (page - 1) * 100 < first.total; page++) {
  signal?.throwIfAborted()
  const next = await request({ stationId, dateFrom, page, pageSize: 100 }, signal)
  if (!next.personnel.length || next.total !== first.total) throw new Error('排班人员已变化，请重新加载')
  pages.push(next)
}
```
