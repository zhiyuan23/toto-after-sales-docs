## 边界

“隐私与账户”“我的问卷”在当前原型仅显示反馈文案，并无独立屏幕。电话无配置号码、微信客服无已接通状态；安装为探索；申请与登记的成功结果不能由没有真实接口的正式构建伪造。原型中的 `DEMO-*`、虚构地址、网点及问答知识仅用于隔离开发环境的视觉核验。

## 已发现的文档时点差异

- [消费者开发进度](../03-开发管理/05-消费者小程序开发进度.md) 仍写有“v0.11 交互为开发基线”和当时的 29 屏历史口径；当前运行的 v0.13 脚本实际注册 32 屏。本次 UI 只按上述 32 屏实施，不用旧数量推断范围。
- v0.13 增加了 C09 电话／微信客服评审页与当前页渠道抽屉、C18 两屏及其分支，且网点三屏仍存在；旧进度段落不能用于删减这些屏幕。
- 原型中的安装申请仍为设计探索，“隐私与账户”“我的问卷”仍为提示动作；它们不能因本次 UI 开发变成正式可办理业务或新增页面。
