# 导入导出配置整合至菜单与权限

日期：2026-09-25。用户确认后实施；代码、测试库权限收敛及本机运行验证已完成，共享应用未发布，正式岗位业务验收未执行。

## 已确认行为

管理员在“系统管理 → 菜单与权限”左侧选择页面，右侧使用“基本信息／操作权限／导入导出配置”页签。取消总部“业务配置”中的独立场景配置入口。菜单编辑、操作定义、模板文件及版本、场景绑定继续沿用原有接口和模型；不合并底层数据表，不改变普通业务页面的导入、导出、模板下载或任务记录逻辑。

当前真正消费场景绑定的八个主数据导入操作可配置：代理商、门店、服务站、服务区域、商品分类、系列、档案及配件档案。已有配置的其他菜单／按钮继续可维护，以兼容原有绑定；没有接入或没有历史绑定的普通按钮不展示配置表单。导出文件仍按既有业务处理器生成，绑定模板不会自动增加导出能力。

## 权限契约

- 前端页签须同时满足真实导航授权中的管理员标记 `afsNavigationAdministrator`、菜单管理 `sys_module_list`，以及后端返回的场景读取权限；当前工作视角不参与管理员判定。
- 后端通过 Gaia 当前用户模块授权，核对启用且路径匹配的管理员标记和可见菜单管理节点；只依据角色名称或持有历史场景 API 权限不足以通过。
- 场景树读取和保存分别继续要求原 `GET /api/afterSales/downloadCenter/scenes/tree` 与 `PUT /api/afterSales/downloadCenter/scenes/configs` 权限。管理员仍可配置为只读；配置 API 在读取模板绑定、初始化默认场景或写入之前拒绝非管理员。
- 普通总部、客服、服务站、代理商和店员无法访问配置；业务导入导出使用原业务 API 授权，不要求管理员标记。`downloadTemplate` 业务消费路径不加入配置管理员限制。
- 旧 `/downloadCenter/scene` 链接仅允许管理员且有菜单管理权限的账号通过前端守卫，随后跳转 `/system/menu?section=transfer`；后端配置权限仍独立校验。普通账号旧链接拒绝，不能借跳转获取配置权限。

没有为了新页签扩大任何账号的菜单管理权。当前测试库四个保留场景授权的管理员角色中，仅具备菜单管理授权的账号能够使用此页签；缺少菜单管理权的管理员角色需按岗位需求另行授权，不能因为“管理员”名称就自动获取全局菜单编辑权。

## 实现与交互

前端位置：`gaia-ui/apps/after-sales/src/views/system/menu/`。配置表单以组件嵌入菜单详情，复用现有 `downloadCenterApi`；只按所选稳定菜单 ID 匹配场景，继续提交稳定节点标识和版本。启用时要求选择模板，停用允许空绑定；模板选项按原分页接口读取。只读用户能切换查看配置对象，不能修改表单。

保存中防止重复提交和离开；切换菜单、配置对象、详情页签、工作视角或路由时提示未保存变更，取消后保留草稿及原树选中项。组件销毁或菜单切换后的过期加载结果不回填。异常显示重试入口；模板绑定的乐观版本检查保持原后端契约。

后端位置：`gaia-after-sales` 的 `DownloadSceneAppService`、`GaiaDownloadSceneSource` 和 `DownloadCenterApi`。新增配置专属权限判断，任务、模板和主数据处理器不扩大管理员限制。
