# 服务知识库独立系统全栈

- 状态：待验收
- 应用：Web 管理后台，客服／总部视角
- 入口与需求：A23、CS-012；本次用户要求完成除三个工作台外的剩余功能，包含原二期候选。
- 负责人：Codex（实现）；业务验收负责人待分配。

## 范围与契约

支持按标题、故障、处理指引和适用品番检索，分页、详情、新增、修改、启停、生效时间及不可变版本历史。正文按纯文本保存和显示，避免未经清洗的 HTML。适用品番引用 Gaia 商品 ID，不复制商品主档。每次内容／适用范围修改生成新版本，保留旧正文、产品关联和操作者时间。并发更新使用行锁和版本校验；写入和版本记录处于同一事务。

API 位于 `/api/afterSales/knowledge`，列表、详情、版本、商品选项分别鉴权，新增、修改和启停分别授权；租户沿用 Gaia 数据源路由。此知识为租户内共享的产品服务资料，不保存顾客或工单个人信息。权限缺失不查询，不借用商品维护权限。

## 数据与实施

售后新增知识主表、内容版本表、版本商品关系表；当前共享开发库为 `gaia_wh_init_wzy`。显式迁移先在隔离 H2 数据库实际执行；共享库执行需针对最终脚本另获授权，不自动改表。回退应用保留版本和关系数据。

复用独立子系统 `FaPageMain`、`EsSearch`、`EsListToolbar`、`EsTable`、`useListPage`、`useCrudDialog`。保留 `afsKnowledgeBase` 菜单 code 和路径。
