# 渠道与服务网络地图视图

日期：2026-10-09。状态：代码已分仓提交，版本v0.23.34；已完成本机研发验证，未推送、未部署、未业务验收。

## 契约

- 代理商、门店、服务网点提供表格／卡片／地图切换；沿用已有筛选、权限和详情编辑入口。地图展示当前筛选下全部授权记录，不受表格当前页限制。缺少有效坐标的记录明确计数并可查看，不以行政区中心代替实际位置。
- 服务区域提供表格／卡片／区域地图；地图展示行政边界，列表与边界联动，保留关联服务网点及优先级信息。
- 销售区域默认展开全国已保存销售范围，顶部整体筛选联动左侧代理商／门店树与右侧地图。选择主体高亮其全部已保存范围，选中行在左侧列表原位展开范围摘要和操作；范围维护进入独立弹窗并保护未保存修改。未配置下级不继承绘制父级范围，只有进入编辑时可按原契约建议上级范围草稿。代理商与门店地址分布归其自身页面。
- 统一支持鼠标滚轮缩放：鼠标位于地图画布内时缩放地图，画布外正常滚动页面／结果列表；保留可键盘操作的缩放按钮。销售范围总览使用相同交互。
- 代理商、门店、服务站、服务区域共用独立的表格／卡片／地图偏好，按账号与租户持久缓存并跨页面同步；与商品原表格／卡片偏好分开。销售区域按本节契约保持地图展开。首次进入地图加载底图与结果，切换后保留筛选及地图状态；结果刷新后清除失效选择。
- 复用高德 JS API，按行政编码精确查询边界；省、市、区支持边界，街道或无法精确匹配的区域明确提示不可用，不降级成更大范围。加载、空结果、部分边界失败、SDK 失败均有明确反馈和重试。
- 不更改业务范围计算、后台数据权限、授权菜单或数据库；不新增地图专属权限。复用现有授权列表 API 分页加载，撤销／离开及筛选变化隔离过期响应。

## 实现

共享能力位于 `gaia-ui/apps/after-sales/src/views/network/shared/maps/`：全量分页加载、结果面板、地图画布、行政边界及选中列表行原位摘要。`EsListViewToggle` 仅增加可选地图入口，商品原表格／卡片偏好保持原有类型，网络四类列表另用同一store的独立三种模式与账号缓存键。详情／编辑继续进入原页面动作，采用列表 API 的 `actions`；服务区域和服务站选择后按需读取详情补充关联资料。页面缓存切换、筛选变化和卸载均隔离过期业务响应。

点位复用高德 MarkerCluster；多行政区域使用官方 DistrictLayer.Province，批量加载省级矢量数据并按已解析编码／层级匹配覆盖面，避免为数百条业务区域逐条请求边界。单个范围、选中区域及适配视角按需使用 DistrictSearch，严格核对返回编码。共同上级几何仅用于适配视角，不绘制为业务覆盖。公共几何缓存不包含账号业务数据。主题 HSL 色值转换为高德支持的 RGB／hex；摘要样式与已有选点弹窗隔离。销售主体树现有接口批量附带每个主体自身的已保存层级与范围，保留原权限、筛选与上下文祖先结构；上下文祖先覆盖不进入地图，不逐主体请求。

边界 API 依据：[高德 JS API 2.0 官方文档](https://a.amap.com/jsapi/static/doc/index.html#districtsearch)。地图展示是业务配置的辅助视图，业务范围仍以保存的行政范围记录为准。
