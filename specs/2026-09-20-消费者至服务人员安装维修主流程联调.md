## 已确认的状态链

本人添加产品仅建立产品关系。自行申报的购买保持 `USER_REPORTED / PENDING`，安装或维修申请先进入 `CONSUMER / PENDING_VERIFICATION`。有权限的后台人员核对购买凭证，并分别确认当次安装资格或维修受理范围后，工单才能进入 `PENDING_DISPATCH`。分站后进入 `PENDING_ASSIGNMENT`，按人员归属、技能、排班与容量派人后进入 `PENDING_COMPLETION`。服务人员提交完整材料进入 `PENDING_REVIEW`；后台审核通过进入 `PENDING_FOLLOW_UP`，不自动表示已回访或已关闭。客户端请求号、版本和服务端活动单检查分别阻止重复登记、重复申请、旧版本派单及重复完工／审核。

## W04 私有服务证据接口切片

服务人员拍照／相册上传从 Gaia 后台的 `/api/sys/commontools/uploadFile` 改为本人任务 `POST /api/afterSales/mobile/service-personnel/tasks/{id}/evidence`。移动会话须能读本人当前站任务且任务允许保存草稿或补资料；服务端只接受不超过 5MB 的 JPG／PNG／WebP 文件内容。相同任务、人员和 `clientRequestId` 的同一图片重试返回同一引用，不同内容复用请求号返回 `409`。文件落在独立私有目录，不进入 Gaia `public` 文件类型；引用为 `/api/afterSales/work-order/completion-reviews/{id}/evidence/{key}`，审阅读取经现有 Web 完工审核权限和工单范围校验，移动读取须持本人会话。租户 ID 与工单 ID 同时参与存储隔离，响应为 `no-store`、`nosniff`。默认本地目录位于系统临时目录，部署前仍须配置持久的 `gaia.after-sales.task-evidence.storage-root` 并确定备份与孤儿文件清理规则。

接口定向测试 3 / 3 覆盖本人上传、重复重试、跨人员拒绝、跨租户不可读、无审阅权限拒绝、非处理状态、伪图片以及 Spring HTTP 异常响应；本地 8080 已重装新接口，无效移动令牌和匿名审阅地址均在真实宿主返回业务 `4001`，没有返回图片字节。服务人员 H5 本人会话和页面读路径已复核，浏览器点击输入通道当前超时，真实相机／相册、上传、私有预览和同一单完工审核仍未完成目标环境验证。因此此项只记源码与隔离测试，不提升 W04 完整入口或业务验收。
