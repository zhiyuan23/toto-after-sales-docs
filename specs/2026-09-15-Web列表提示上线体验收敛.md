# Web 列表提示上线体验收敛

## 1. 目标

面向正式上线体验，收敛管理后台列表页长期占据首屏的信息提示。提示是否保留不按“开发阶段／线上阶段”区分，而按用户当前是否需要据此决策区分：

- 架构边界、数据归属、一期范围、后续规划和页面功能复述退出业务列表页，转由项目文档、操作指南或按需帮助承载。
- 与具体记录、字段或操作有关的限制，放到对应表单字段、操作确认或结果反馈附近；前端提示不能替代后端校验。
- 隐私告知、权限阻断、当前错误和高影响操作后果继续显式展示。
- 报表统计口径属于理解数据所必需的信息，但默认不占用列表首屏，改为工具栏按需查看。

## 2. 本次处理

- 移除渠道与网点、服务资源、库存、安装码、客户及客服流程、数据字典等列表页的常驻说明条。
- “已有下级代理商时不能修改层级或所属代理商”仅在编辑到受限记录时出现在层级字段旁，并说明需要先处理下级关系；后端限制保持不变。
- 服务人员停用影响合并进停用确认，排班发布规则继续保留在发布确认中。
- 报表页增加“统计口径”按需入口；注册隐私、采购核验警告、权限／错误和流程高影响确认不做弱化。
- 修正服务站负责人说明，使其与当前“仅维护业务联系人、账号及所属服务站在服务人员中维护”的实现一致。
