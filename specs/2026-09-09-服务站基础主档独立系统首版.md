# 服务站基础主档独立系统首版

日期：2026-09-09

范围：A06 / ADM-MD-004 的安全基础切片

## 需求与边界

- 本切片以独立售后系统为主。现有 Gaia `sys_organization` 只确认承担通用权限组织树职责，缺少已确认的服务站类型、状态和售后关系，因此不复用蓝鲸数字主系统的服务站业务逻辑，也不整行维护通用组织表。
- 新建售后自有 `afs_service_station` 基础主档，只维护服务站编码、名称、备注和启停；编码按大小写不敏感唯一，停用保留主档及审计历史，不提供物理删除。
- 负责人账号、技能/服务能力、服务区域、行政区/围栏、重叠优先级、服务人员绑定、排班容量和派单规则会改变数据关系与授权边界，均不在本切片中预留或猜测。
- 当前能力面向总部售后管理权限。未来开放服务站自身账号维护前，必须先确认服务站级数据范围，不能用当前菜单权限替代业务接口授权。

## 实现

- 后端新增 `ServiceStationService` / `ServiceStationAppService`、命令和查询模型、参数化 MyBatis Mapper，以及 `/api/afterSales/network/service-stations` 下的权限、查询、详情、新增、编辑和启停 API。
- 写入复用 Gaia 身份、租户路由、事务和主键机制；BIGINT ID 以字符串返回。编辑和启停要求最新 version，事务内锁定并写独立审计；新增/编辑使用字段白名单和大小写无关编码唯一校验。
- 迁移 `database/20260909_service_station.sql` 只建立基础主档和审计表；2026-09-09 经明确授权已执行到测试库 `gaia_wh_init_wzy`，两张目标表创建成功且初始均为 0 行，未写业务数据或角色权限。
- 独立前端 `gaia-ui/apps/after-sales` 新增真实服务站页面及路由，复用原生 `FaPageMain`、`EsSearch`、`EsListToolbar`、`EsTable`、Element Plus 和 `useListPage` / `useCrudDialog`；支持查询、筛选、重置、分页、新增、编辑、启停、失败保留输入、重复提交保护和操作后刷新。
- API 契约升级为 `catalog.openapi.json` 1.6.0，明确基础字段、字符串 ID、版本和权限能力，不包含未确认关系。

## 验证

- 后端：`mvn -B -o -pl gaia-after-sales-api -am test` 通过，core 2 项、API 27 项，共 29 项；覆盖生命周期、大小写无关唯一、字面 `%` 筛选、版本冲突、启停、权限、租户隔离、字符串 ID、审计和审计失败事务回滚。
- 前端：65 项测试、`vue-tsc -b` 和 Vite production build 通过；构建产物包含独立 `serviceStation` chunk。当前 Node 26.7.0 不符合仓库要求的 `>=22.23.1 <23`，需在固定 Node 22.23.1 下复验正式工具链；Vite 既有配置兼容提示和大 chunk 警告仍存在。
- 宿主：售后制品本机离线安装后，`gaia-saas-web-jar` 离线打包通过并生成 `gaia-web.jar`；未启动受真实 MySQL 连接问题影响的 8080。
- 隔离 HTTP：使用临时 18082、合成身份和独立 H2，验证权限、查询/筛选/分页、新增、编辑、过期版本 `409`、启停和 BIGINT 字符串 ID；验证后关闭 18082，既有 18081/9013 保持运行。
- 浏览器：按本轮“大模块拆分、阶段复盘”的决定，本阶段暂不执行服务站浏览器页面验证；不能把构建或 HTTP 结果表述为浏览器验收。
