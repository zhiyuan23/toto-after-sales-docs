## 故障选项切片

`GET /api/afterSales/mobile/consumer/products/{instanceId}/faults` 要求有效消费者会话，仅按当前账号的 `CONSUMER + ACTIVE` 产品关系、未合并／未退回实例及启用商品读取目录故障。响应只包含故障 ID、名称和摘要，不输出内部故障详情、维修级别、处理方案、配件或审计字段。其他账号和未知实例均返回空列表；接口重复读取不写数据。消费者维修表单从该 API 选择 `faultId`，无选项或加载失败时不能继续维修申请。

聚合宿主的 WAR 与可执行 Jar 均只对该精确移动路径放行 Gaia 登录过滤；消费者服务仍逐请求验证独立会话和本人关系，不因宿主 `anon` 放宽业务访问。

字段、错误及范围契约见[源码仓库接口说明](../../../backend/gaia-after-sales/docs/consumer-mobile-faults.md)。

当前后台工单创建对 `REPAIR` 强制要求故障 ID 属于选定商品；本切片保持该约束。正式页面的远程指导也采集并校验非空使用地址，以满足现有工单入库的地址加密要求；视觉评审场景保持 v0.13 原型状态。正式端的媒体区明确提示未开放上传：压缩、失败重试、存储归属与内容安全检查未形成完整契约前，不接收媒体或显示伪成功。C07 正式维修／指导入口继续导向 C09 客服，未接入消费者建单 API，不会伪造申请回执或服务资格。

隔离验证：`CustomerIntegrationTest#independentConsumerReportIsScopedAndCanBeVerifiedByWeb` 在 H2 覆盖本人可读、他人／跨租户及未知实例为空、重复读取结果一致和响应白名单；`ConsumerPurchaseServiceTest`、`ConsumerSupportChannelsTest` 通过。后端全量 `CustomerIntegrationTest` 在本机测试 JVM 异常退出，因此本次仅声明目标方法通过。聚合宿主 WAR／可执行 Jar 受影响模块编译通过；消费者端 `pnpm verify`（含检查与微信／H5 development 构建）通过；微信模拟器、真机、真实上传和申请提交未验。接口是只读切片，暂无写入幂等动作；重复读取已验证。

本机宿主忽略配置指向共享测试库 `gaia_wh_init_wzy`。只读查询确认 `afs_purchase_registration` 和 `afs_consumer_product_relation` 已存在，但 `afs_consumer_account`、`afs_consumer_session` 以及 `owner_consumer_account_id`、`account_kind` 两个增量列均不存在。`20260920_consumer_mobile_identity.sql` 和 `20260920_consumer_mobile_business.sql` 尚未迁入；本次未执行任何 DDL 或业务写入。

本地启动脚本传入单租户 ID `1001`；当前库的 `tenant_info` 中未找到 ID `1001`，`tenant_data_source` 也没有它的映射。仅凭这两张表不能断言移动单租户 ID 的正式归属，需由租户配置责任人确认 TOTO 的实际租户 ID 与目标库关系后再联调。该值未在本次改动中调整。

## 2026-09-20 C07 待核验受理与后台放行切片

用户确认待核验购买可先提交维修／指导申请，后台核实后才派单。正式端 C10 本人产品进入 C07 三步表单；维修仍必须从本人商品故障选项选取 `faultId`，远程指导也填写产品使用地址。提交调用 `POST /api/afterSales/mobile/consumer/products/{instanceId}/services`，以账号会话和活动实例关系鉴权，服务端加密联系人、手机号和地址，按账号与请求号幂等，锁定实例并拦截重复活动申请。结果为 `CONSUMER / PENDING_VERIFICATION`，不自动派站、不确认预约时间、不授予免费服务资格；回执和 C10／C02 本人服务记录可刷新读取。媒体仍只显示未开放提示，不向接口发送伪造引用。接口字段、状态与错误见[后端源码契约](../../../backend/gaia-after-sales/docs/consumer-mobile-service-intake.md)。

## 2026-09-20 安装入口与待核验受理

用户确认本人已添加、购买仍待核验的产品可先提交安装申请；后台核实购买及安装资格后才进入派单。正式首页与产品详情开放安装入口，服务 Tab 可前往本人产品选择；三处均进入现有三步表单。当前工单结构及放行核验按单实例处理，正式端每次只选一件本人产品，页面明确说明；v0.13 视觉评审多选演示不作为真实建单规则。提交 `INSTALLATION / ONSITE`，安装需求选填，联系人、手机号、使用地址和期望时间必填。账号与实例鉴权、请求号幂等、活动申请冲突、PII 加密和回执／本人列表沿用 C07 同一接口；成功只生成 `CONSUMER / PENDING_VERIFICATION`，不自动派站、预约或授予免费安装资格。安装申请不需要维修故障 ID。
