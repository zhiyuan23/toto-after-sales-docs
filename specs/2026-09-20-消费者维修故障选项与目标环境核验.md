## 故障选项切片

`GET /api/afterSales/mobile/consumer/products/{instanceId}/faults` 要求有效消费者会话，仅按当前账号的 `CONSUMER + ACTIVE` 产品关系、未合并／未退回实例及启用商品读取目录故障。响应只包含故障 ID、名称和摘要，不输出内部故障详情、维修级别、处理方案、配件或审计字段。其他账号和未知实例均返回空列表；接口重复读取不写数据。消费者维修表单从该 API 选择 `faultId`，无选项或加载失败时不能继续维修申请。

聚合宿主的 WAR 与可执行 Jar 均只对该精确移动路径放行 Gaia 登录过滤；消费者服务仍逐请求验证独立会话和本人关系，不因宿主 `anon` 放宽业务访问。

字段、错误及范围契约见[源码仓库接口说明](../../../backend/gaia-after-sales/docs/consumer-mobile-faults.md)。

当前后台工单创建对 `REPAIR` 强制要求故障 ID 属于选定商品；本切片保持该约束。正式页面的远程指导也采集并校验非空使用地址，以满足现有工单入库的地址加密要求；视觉评审场景保持 v0.13 原型状态。正式端的媒体区明确提示未开放上传：压缩、失败重试、存储归属与内容安全检查未形成完整契约前，不接收媒体或显示伪成功。C07 正式维修／指导入口继续导向 C09 客服，未接入消费者建单 API，不会伪造申请回执或服务资格。
