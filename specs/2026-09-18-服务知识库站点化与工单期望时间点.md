# 服务知识库站点化与工单期望时间点

- 编号：FS-20260918-01
- 状态：测试环境已发布，待真实站点角色业务验收
- 应用：Web 管理后台（客服作业、服务站作业）
- 关联入口：A17 服务工单、A23 服务知识库
- 最后更新：2026-09-19

## 已确认范围

1. 左侧“业务查询”分组更名为“购买信息”，使用前端内置的 `lucide:clipboard-list` 图标。
2. 客服创建服务工单的“期望上门时间”改为一个必填的年月日时分时间点；页面不再输入结束时间，也不保存秒。历史区间记录只保留原开始日期和开始时间，结束值不再向接口和页面暴露。
3. 服务知识库废弃原“标题、故障、处理指引、版本历史、多个适用品番”的业务模型，当前入口改为服务站维度的知识附件条目。
4. 每条知识必须归属一个当前用户数据权限内的服务站，必须填写关键词；最多选择一个商品类别和一个商品。选择商品类别后，商品下拉只显示该类别下的启用商品；服务端再次校验，不能靠前端绕过。
5. 一个条目可上传 1 至 20 个图片、文档或视频附件。停用后只能在编辑中恢复；删除为物理删除知识记录和关联文件，不新增“恢复”按钮。

## 页面与数据权限

### 服务知识库

- 查询条件：服务站（编号／名称，可模糊检索）、关键词、适用商品类别（编号／名称）、适用商品（编号／名称）、状态。
- 服务站选项、列表、详情和写操作均以当前登录人的服务站数据权限为边界；有权限的第一个站作为默认筛选值。无可用服务站时不请求列表。
- 列表显示服务站编号、服务站名称、关键词、类别、商品、附件数、是否启用、更新时间；支持预览、编辑、停用和物理删除。
- 新增／编辑使用宿主标准文件上传接口，持久化接口返回的文件 `id` 与 `access` 地址。仅允许 jpg/jpeg/png/gif/webp、pdf、doc/docx、xls/xlsx、ppt/pptx、txt、mp4/webm/mov，单文件最大 200 MB。

### 服务工单

- 创建弹窗使用分钟精度的日期时间选择器，提交前拆分为 `expectedDate=YYYY-MM-DD` 与 `expectedTimeWindow=HH:mm`。
- 服务端拒绝空值、过去日期和不符合 `HH:mm` 的时间；现有数据迁移将原区间统一保留开始时刻。
- 工单列表、详情、派单与人员分配等统一只显示这一时间点。表中保留 `expected_date_to` 仅为旧库列兼容，应用不再读取或写入结束值。

## 数据、接口与文件清理

新增独立表：

- `afs_service_knowledge`：站点、关键词、单个类别／商品、启停、乐观锁修订号和审计字段。
- `afs_service_knowledge_attachment`：一个知识条目的有序多附件；`knowledge_id + file_id` 唯一，并以外键级联删除关系记录。

迁移脚本为 `gaia-after-sales/database/20260918_service_knowledge_v2.sql` 和 `20260918_work_order_expected_visit_time.sql`；回退边界见同目录的 `20260918_service_knowledge_v2.rollback.md`。接口权限迁移为 `20260918_service_knowledge_v2_permissions.sql`，其执行结果记录在同名 JSON。旧知识库表不删除，仅停止供当前页面读取，避免直接破坏历史审计资料。

接口基址保持 `/api/afterSales/knowledge`，新增站点、类别、商品选项接口以及详情、创建、编辑、停用、物理删除。删除及编辑替换附件时，领域服务先删除知识关联，再通过宿主文件服务删除不再关联的二进制文件；新上传文件必须属于当前操作用户且访问地址匹配标准上传地址，防止引用他人附件。

## 权限与上线前置

- 菜单继续使用 `afsKnowledgeBase`；读、创建、编辑、停用、删除及三个选项读取接口必须分别登记到对应的 `sys_module_operation.api_list`，不能把写接口合并到菜单读取权限。
- 发布前先执行两份后端 SQL，再同步本功能 API 权限，最后发布售后后端、主系统前端与售后子系统前端。
- 真实验证至少覆盖：不同服务站账号的数据隔离、类别商品不匹配拒绝、附件所有权拒绝、停用后编辑恢复、删除后二进制文件不可访问、历史区间工单只显示开始时间。
